🔴 버그 발견·수정(2026-09-17):
1. 중첩 zip(source_type="blend") 처리 코드가 안의 실제 파일 이름을 항상 "scene.gltf" 기본값
   으로 찾고 있었다 — .blend일 때는 inner_blend cfg 키로 실제 이름을 받도록 일반 수정.
2. "//Santana.png" 상대경로 이미지가 파일을 열자마자는 has_data=True였는데, 파이프라인
   중간(원인 정확히 못 좁힘)에 데이터가 사라져 image.save()가 "does not have any image
   data"로 죽었다. reload()도 안 먹혀서, 파일을 연 직후 모든 FILE 소스 이미지를 즉시
   pack()해 파일 참조 없이 메모리에 고정하도록 일반 수정 — 앞으로 .blend 소스 전부에 안전.
