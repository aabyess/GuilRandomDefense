# GuilRandomDefense — 게임 기획서 (GDD) v0.2

> 상태: 리서치담당 원작 분석 반영 완료. 확정 항목은 ✅, 미정은 ❓ 표기.

## 1. 한 줄 비전

**"랜덤으로 뽑은 유닛을 조합해 밀려오는 웨이브를 막는, 혼자서도 30분이 순삭되는 3D 랜덤 디펜스."**

- 레퍼런스: WC3 유즈맵 원랜디 (원피스 랜덤 디펜스)
- 차별점: 오리지널 캐릭터 IP, 3D, 싱글플레이 우선, 데이터 드리븐 밸런싱
- 플랫폼: PC (Mac/Windows), 마우스+키보드

## 2. 코어 루프 (플레이어가 1라운드 동안 하는 일)

```
[라운드 시작] → 몹 웨이브가 레인을 따라 진입
      ↓
[골드 획득] 몹 킬 / 라운드 클리어 보상
      ↓
[뽑기] 골드 소비 → 랜덤 등급 유닛 획득
      ↓
[조합] 같은 유닛 N개 → 상위 등급 / 레시피 조합 → 특수 유닛
      ↓
[배치·조작] 레인 근처에 배치, 필요 시 이동·스킬 사용
      ↓
[라운드 종료] 필드 몹 수가 한계 초과 시 패배 / 최종 보스 처치 시 승리
```

핵심 긴장감: **"지금 뽑기를 돌릴까, 조합 재료를 모을까"** 의 매 라운드 선택 + 랜덤성이 주는 도파민.

## 3. 게임 규칙 ✅ (리서치담당 원작 분석 반영, 2026-08-27)

원작(WC3 유즈맵 "원피스 랜덤 디펜스", 4인 협동, 나무위키 기준)과 MVP 축소안 비교.
출처 있는 값은 [원작], 문서 미기재로 추정한 값은 [추정] 표기.

| 항목 | 원작 | MVP 확정값 |
|---|---|---|
| 총 라운드 | 75 [원작] | **25** |
| 라운드당 시간 | 미기재 [추정 30~60초] | **28초** |
| 보스 라운드 주기 | 10라운드마다 (신세계 이후 5) [원작] | **10라운드마다** |
| 패배 조건 | 필드 몹 70 초과(4인 기준) [원작] | **필드 몹 25 초과** (1레인 솔로 축소) |
| 등급 수 | 8단계+ (흔함→...→제한됨) [원작] | **4단계**: 일반/희귀/전설/신화 |
| 뽑기 확률 | 특수함 3%, 상위트랙 17% [원작 부분] | 일반 60% / 희귀 30% / 전설 8% / 신화 2% |
| 조합 공식 | 동일 등급 3개 + 재화 → 상위 1개, 상위일수록 재료 증가(피라미드) [원작] | **동일 등급 3개 → 상위 등급 1개** (재화 소모 없음, 단순화) |
| 초기 골드 | 미기재(초고속모드만 1000) [추정] | **400** |
| 뽑기 비용 | 나무 1개(환율 불명) [원작] | **60골드/회** |

**패배 조건은 3중 구조를 유지**: ① 필드 몹 수 초과 ② (MVP는 스토리 퀘스트 없음 → 제외) ③ 보스 제한시간 내 미처치.

### 재미의 핵심 3가지 (반드시 유지)
1. 가챠 도박성 긴장감 + 내가 만든 조합에 대한 애착
2. 등급업 재료 판단 자원관리 퍼즐 ("무엇을 합칠지")
3. 실시간 스킬 마이크로 + "몹 쌓이면 진다"는 압박감 — **배치만 하는 오토배틀러 아님**, WC3식 조작이 정체성의 핵심

### MVP에서 제외 (원작 대비)
- 4인 협동 멀티, 스토리 퀘스트 패배조건, 랭킹/공식대회
- 초월/불멸/영원함/제한됨 등 8단계+ 최상위 등급 트리 (4단계로 압축)

참고 상용 게임: Random Dice: PvP Defense (뽑기→합성→라인방어 루프 유사)

## 4. 시스템 설계 (MVP 범위 ✅)

### 4.1 유닛 조작 — `Assets/Scripts/Units/`
- 좌클릭 선택 / 드래그 박스 다중 선택 / 우클릭 이동 (NavMeshAgent)
- 자동 공격: 사거리 내 가장 가까운 적 타겟팅
- 스킬: 단축키(Q/W/E) 1~2개, 쿨다운 기반
- Input System 패키지 사용 (구 Input Manager ✗)

### 4.2 웨이브/레인 — `Assets/Scripts/Waves/`
- `WaveSpawner`: `WaveData` 목록을 순서대로 실행, 라운드 타이머
- 몹: Waypoint 배열을 따라 순환 이동 (NavMesh 또는 단순 Waypoint 이동 — ❓ 성능 비교 후 결정)
- `EnemyCounter`: 필드 몹 수 → 패배 판정

### 4.3 뽑기/조합 — `Assets/Scripts/Data/` + `Assets/Scripts/Units/`
- `GachaTable` (SO): 등급별 확률 + 등급별 유닛 풀
- `CombineRecipe` (SO): 입력 유닛 목록 → 출력 유닛
- `Inventory/Board`: 소유 유닛 관리, 조합 가능 여부 하이라이트

### 4.4 데이터 드리븐 — `Assets/Scripts/Data/`
- `UnitData` (SO): 이름, 등급, HP, 공격력, 사거리, 공속, 이동속도, 스킬 참조, 프리팹
- `SkillData` (SO): 쿨다운, 범위, 효과 타입(데미지/슬로우/버프), 수치
- `EnemyData` (SO): HP, 이동속도, 골드 보상, 보스 여부
- `WaveData` (SO): 라운드 번호, 스폰 목록(EnemyData × 수량 × 간격)
- 밸런싱은 SO 값만 바꾸면 되도록 — 코드에 수치 하드코딩 금지

### 4.5 UI — `Assets/Scripts/UI/`
- HUD: 라운드/타이머/골드/필드 몹 수
- 뽑기 버튼, 조합 버튼, 선택 유닛 정보 패널
- 승리/패배 화면 + 재시작

### MVP에서 제외 ✗
- 멀티/협동, 랭킹, 도전과제, 세이브, 메타 진행(영구 강화), 맵 다수, 인게임 맵 에디터
