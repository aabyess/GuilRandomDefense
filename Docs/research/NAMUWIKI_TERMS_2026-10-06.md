# 원랜디 용어 — 나무위키 「원피스 랜덤 디펜스」 3.3~3.11절 (PM 정리, 2026-10-06)

## 딜·역할 분류 (전설·히든·상위패 공통)
| 용어 | 뜻 |
|---|---|
| 물딜 / 마딜 (물뎀·마뎀) | 물리 피해 조합 / 마법 피해 조합. 전설은 「내 조합 빌드에 맞나」로 나눈다 |
| 깎 (방깎) | 적 방어력 감소. 물딜은 상위패들의 깎을 **합쳐서** 일정 수치를 넘겨야 클리어(루피 초월 원딜 기준 120~130깎). **같은 스킬 이름의 깎은 중복이 안 되고 낮은 레벨 쪽이 적용**된다 |
| 암브 (아머브레이크) | 평타마다 방어 감소가 **중첩**되는 깎. 중첩 수에 따라 피해도 늘어나는 유닛이 있다(징초). 「보조암브」 = 보조 아머브레이크 |
| 단일 | 공격 중인 적의 **현재 체력 비례** 피해. 대부분 방어 무관 → 마뎀으로 분류. **보스에겐 비례가 아니라 스킬마다 정해진 소량 고정 피해**(그래서 보잡이 따로 있다) |
| 끝딜 | 공격 중인 적의 **최대 체력 비례** 또는 **잃은 체력 비례** 피해. 단일로 깎인 적을 마무리. 대부분 방어 무관. 잃퍼뎀(잃은 체력)은 단일처럼은 못 쓴다 |
| 범퍼뎀 | **범위 안 적 전체**에 체력 비례 피해(라인딜). 보유 유닛이 드물고 후반일수록 강하다 |
| 퍼뎀 / 전퍼뎀 / 잃퍼뎀 | 체력 비례(%) 피해 / 최대(전체) 체력 비례 / 잃은 체력 비례 |
| 라인딜 / 스플(스플래시) | 레인 적 여럿을 같이 치는 딜 / 평타 범위 피해 |
| 보조딜 | 부족한 딜을 채우는 유닛(물뎀=평타 스플, 마뎀=어느 정도 딜) 또는 딜 말고 능력이 없는 유닛 |
| 깡딜 / 깡뎀 | 다른 옵션 없이 고정 피해 수치 |
| 증폭 (도킹) | 적이 받는 마법 피해 증가. 이름은 「파이러츠 도킹 5」에서 왔다 |
| 마방깎 | 적 마법 방어 감소. **도킹·마방깎은 각각 최대 25%까지만 중첩** — 같은 계통을 겹쳐 올리지 않는다 |
| 폭발뎀 / 폭발뎀증 | 11버전에 생긴 피해 분류. 단일·끝딜 대부분이 폭발형이 돼 도킹·마방깎의 영향을 안 받는다. 폭발뎀증 = 그 폭발형용 깎·증폭 |
| 방무뎀 | 방어 무시 피해 |
| 공증 / 공속 | 아군 공격력 증가 / 공격 속도 증가 버프. 「액티브 공증」 = 눌러서 켜는 공증 |
| 마나젠 | 주변 유닛 마나 회복 증가 오라(브릴리언스 오라 같은 것). 마나스킬 유닛 보조 |
| 마나스킬 / 체력스킬 | 마나가 다 차면 터지는 스킬 / 체력(게이지)이 차면 터지는 스킬 |

## 유틸
| 용어 | 뜻 |
|---|---|
| 스턴 | 적 정지. 물뎀은 이감을 거의 최대로 잡은 상태에서 **1.5스턴**, 마뎀은 **2스턴**이 이상적. 딜이 충분하면 1스턴도 된다 |
| 단일스턴 | 한 대상 스턴. 8.9b부터 **보스에겐 범위 스턴·범위 이감 효율이 크게 떨어짐** → 보스 전담 단일스턴. 보잡 대부분이 단일스턴을 갖고 있어 지금은 덜 필수 |
| 이감 | 적 이동속도 감소. 「매우 느림」까지 잡는 게 목표(필요 수치는 버전마다 다름). 깎처럼 **같은 스킬 이름이면 낮은 레벨이 적용** |
| 홀딩 | 스턴·이감으로 레인 적을 붙잡아 두는 것. 「스턴이 샌다」 = 홀딩이 풀림 |
| 보잡 | 보스 잡이 특화. 보스에게만 단일 피해가 폭증하거나 보스 체력을 현재·최대 비례로 깎는다. 상위패에 보잡이 없으면 하나는 반드시 만든다(보스사 방지) |
| 광폭화 (전담) | 신세계 뒤 나오는 광폭화 몹 — 레인 몹에 체력 재생·방어·마방 증가 오라. 보스 취급이 아니라 보잡만으로는 안 되고, 잡으면서 오라를 지우는 유닛이 있다 |
| 순간이동 / 공중이동 / 바다이동 | 일반 유닛이 못 가는 구역(숨은 적·크립)에 가는 능력. 2단계 크립은 해적선을 얻는 주 경로. 없으면 남이 꺼내 준 크립에 마나 500 버스터콜 |
| 탐색 | 맵을 밝혀 숨은 것을 보는 기능(건물 탐색과 별개 쿨이 있는 유닛도 있다) |

## 등급 메모 (3.3~3.8 요약)
- 흔함은 매 라운드 랜덤위습 1개로 얻는다. 15~20라까지는 쓸 만하고, 후반은 **재료 관리**가 핵심.
- 희귀함: 전설 1 = 희귀 3 + 나무 3. 도박으로 얻는 가장 높은 등급, 팔 수 있는 가장 높은 등급.
- 특수 유닛(희귀 위습 3%): 아이스버그·모건·블고리·페루·오타마·베티 — 팔 수 없고 재료가 아님. 공통 공중이동.
- 전설: 1인분의 시작, 평가 기준 단위. 히든: 채팅 명령어 조합, 나무를 직접 요구하지 않음.
- 초월: 10라운드 펑크해저드 → 초월 위습(한 판 1개) → 쿠마 초월로 만든다. 보통 전설 2 + 추가 재료. 조합법은 대사(채팅)로.
- 랜덤전용<제한됨>: 조합 때 골드 1만·목재 7·행운의 토큰 1. 한 판에 하나.

## 상위 4종 차이 (3.8~3.11)
- **초월**: 쿠마 초월(초월 위습, 한 판 1개) + 보통 전설 2. 대사 입력(채팅). 비교적 싸고 성능 좋음, 레벨 시스템.
- **불멸**: 전설 **3** + 나무 **10**(재료 포함 총 나무 19). 가장 비싸고 단일 유닛으로 가장 강해야 하는 군. 대사 입력.
- **영원함**: 종잡을 수 없는 특이 재료(아이템·변이·배·압살롬 등) + 오리지널은 **세이브 횟수**(R에서는 사라짐). 대사 입력. 이펙트가 화려하다.
- **제한됨**: 특이 재료지만 **명령어 없이** 게임 안 조합표에 공개(레드필드 제외), 세이브 불요, 비교적 싸고 단독보다 **보조로 최고의 가성비**. 레드필드는 41라운드 전만.
- 압살롬 = 모리아 특별함이 만든 좀비로만 조합 → 「압불멸」(압살롬 도박에 나무가 불멸값만큼 든다는 농담).

## 우리 해석과 다른 점 (사장님 확인 필요)
- **범퍼**: 나무위키 「범퍼뎀」은 **범위 안 적 전체** 체력 비례다. 우리는 지금 「범퍼(현재체력N%)」를 **평타 확률·단일 대상**으로 구현했다(신문철 사고뭉치·박민석 흑인 등, memory transcend-spec-glossary). 사장님께 여쭤 정정 여부를 정한다.
- **단일**: 나무위키는 「현재 체력 비례, 보스엔 소량 고정」. 우리 사양의 「단일(전체체력, 보스)」 표기는 사장님 쓰임새를 따른다.
- **영원함 조합 방식**: 나무위키는 초월·불멸·영원함 셋 다 「대사(채팅) 입력」, 제한됨만 조합 버튼. 우리 채팅 전용은 지금 히든·초월·불멸·다른세계(사장님 10-06, CombineSystem.IsChatOnly) — 영원함이 빠져 있다. 사장님께 확인.
- **유닛회유**: 나무위키 수치는 0.8%. 불멸 설계표 값과 대조할 것.
