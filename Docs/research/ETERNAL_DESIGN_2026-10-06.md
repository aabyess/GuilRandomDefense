해석: **토토 = 도박(베팅)**, 「Style : 김영원」 = 김영원만의 방식. 효과가 한 줄뿐이라 사장님 뜻을 정확히 모르는 게 가장 큰 유닛이다.
제안(가, 권장): **아주위험한게임** — 평타 10% 확률로 「베팅」: 한 번 던져 **50% 성공 → 대상 최대체력 12%(방무, 보스 포함) + 스턴 1.5초 / 50% 실패 → 자기 스턴 1초(위험 대가)**. 평균 평타당 0.6%·최대체력(R49 일반 46k · R50 보스 1.05M · 실패 땐 0).
(나) 보상형: 평타 1/10으로 「잭팟」 — 성공 시 엔 보너스(도박소 룰렛과 같은 계열) / (다) 액티브 버튼: 누르면 라운드 시작 베팅. **약함/셈 판정**: 스킬이 하나뿐이라 딜 책임이 크다 — 공격력 27.5k는 영원 중 최저(조세민·최상호 70k)이므로 (가)의 12%가 모자라면 실측 뒤 올린다.
새 코드: **새 효과 하나**(`SkillEffectKind.Gamble`? 성공/실패 갈래) — 또는 기존 확률 효과 둘(성공 효과 = 확률 5% 발동, 자기 스턴 = 확률 5%)로 **코드 0**으로 근사(권장 최소형: 평타 5% 최대체력 12%+스턴 / 평타 5% 자기 스턴 1초 — 같은 타 독립이라 「한 번 던져 둘 중 하나」는 아님).
질문: **Q1** 토토의 뜻(가·나·다)과 실패 대가 · 「악마와의계약」 재료가 제한 김민규(commandId limited)가 맞는지.

질문: **Q2** 180초 뒤 생성의 의미(조합 지연 맞나 / 한 판에 180초가 지나야 조합 가능?) · **Q7** 꺼지지않는열기의 정체와 「레벨업×Lv」 수식.

## 4. 구현 순서 제안(승인 뒤)

1. 윤현모(이름만 · 재료 맞음 — 가장 작음) → 2. 최상호 킹카(틀 복사) → 3. 이지원 → 4. 김정래(회유는 불멸과 순서 맞춤) → 5. 문필환 → 6. 조세민(지연 생성) → 7. 김영원(토토 사양 확정 뒤) → 8. 서민성(대).
각 유닛마다 Apply(`EternalXxxApply.cs`) + 탐침 + 신 모드 gameshot 실측 + 설계표 갱신 + 커밋. 입력말은 Apply가 `chatPhrase`로, 재료 교체는 commandId 대조로.
