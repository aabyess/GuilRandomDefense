# 제한됨 8종 설계표 (2026-10-06, 구현담당2)

사장님 원문: `Docs/research/SPEC_IMMORTAL_ETERNAL_OTHERWORLD_LIMITED_2026-10-06.md` 「제한됨」 절. 방침(초월과 같음): 칭호 없는 재료 = 기본 유닛 · 수치는 신 기준 · 끝딜 규칙(확률=최대체력·마나=잃은체력·처형) · 모르는 것은 질문.
**코드·에셋은 아직 안 건드림 — PM 확인 뒤.** 재료 이름 해석은 로스터 `unitName`·에셋 이름을 스크립트로 일치시켜 뽑았다.

## 1. 대상 8종 ↔ 로스터

사장님 8종: 김강민 · 이유범 · 전법규 · 박성호 · 임준성 · 김민규 · 강보명 · 이충민. 로스터 `제한_*` 9기: 위 8종 + **`제한_최영민`**(사장님 사양에 없음 — ❓질문1). 식(조합식 에셋) 8개는 이미 존재.

## 4. 질문 목록(PM → 사장님 웹 질문지)

1. 로스터에만 있는 **`제한_최영민`**은 이번 사장님 8종에 없다 — 그대로 두나?
2. 박성호 식의 **「분실된지갑」** 아이템: 새 아이템으로 만들면 **어떻게 얻나**(스토리·도박·적 드롭·상점 중?) — 얻는 길이 없으면 식이 영영 안 된다. 효과는 재료로만 쓰이면 되나?
3. 김강민 4개 스킬 **효과**: 컨셉은곧나자신 · 안심은금물 · 확고한믿음의공포 · 합의금이 각각 무엇을 하나?
4. 전법규 끝딜 「**분신4%**」의 뜻(분신이 별도 4% 피해? 6%+4%?)
5. 김민규 쿨스킬 「**반경1000 보물위치공개**」: 보물찾기 이벤트의 어떤 표시로 공개하나?
6. 김민규 **유닛회유(팔기가능)**: 적 일반 유닛을 아군으로 데려오는 새 기능 — 대상 조건(보스·스토리 제외)·확률·판매가?
7. 강보명 **암브 수치 · 멀티샷 발수 · 광폭화 효과/지속**
8. 이충민 **마나 스킬 보상 5종 확률·수량 · 스킬발동확률증가 배율 · 스킬 이름 3개 짝짓기**
