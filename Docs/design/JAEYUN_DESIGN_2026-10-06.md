## 4. 종이비행기 유물 (스토리 7)

사장님 지시(PM 큐): 스토리 7의 버스터콜 자리를 종이비행기가 대신한다. 원작 확률 1/20(`Story07_메가스터디.itemDropChance 0.05`) 그대로, 드롭 아이템만 교체(버스터콜 지령서 에셋은 지우지 않는다 — 스토리 7 보상에서만 뺀다, `BrokenMirrorApply`와 같은 방식). 효과: **적 하나(보스 포함) 영구 정지 + 전체 적 체력 25% 감소 · 1회 · 아이템은 남음 · 영구 정지된 보스는 끝까지 멈춤**.

| 항목 | 설계안 |
|---|---|
| 아이템 에셋 | `ItemData_R002_종이비행기`(isRelic, 아이콘 없음 — 글자만), 능력 설명은 버스터콜 지령서(I00L)를 복사하지 않는다(효과가 다르다) — 툴팁에 새 효과를 적는다 |
| 사용 방식 | ❓질문5. 기본안: **인벤토리 칸을 눌러 쓴다**(새 `ItemUseKind.PaperPlane`, 맨 뒤). 누르면 가장 체력이 큰 적(보스가 있으면 보스) 하나를 영구 정지시키고, 그 순간 필드의 모든 적 현재체력을 25% 깎는다. **한 번 쓰면 이 유물로는 다시 못 쓴다**(아이템은 인벤토리에 남아 「사용 완료」 표시 — 「아이템은 남음」) |
| 영구 정지 | `EnemyDummy`에 `FrozenForever` 상태(맨 뒤 필드): 이동·공격·스킬 정지, 스턴 면역/해제와 무관하게 유지. **영구 정지된 보스는 끝까지 멈춤**(보스 패배 규칙·라운드 종료에 어떻게 반영할지는 ❓질문6) |
| 전체 체력 25% | 현재체력 × 0.75(보스·스토리 적 포함 여부 ❓질문6) |
| 멀티 | 호스트가 판정(`NetHudAction`에 한 줄 추가) — 구현담당1이 만진 NetCommands는 건드리지 않고 호스트 쪽에서만 처리 |

## 5. 질문(PM → 사장님께)

1. 「김경현」 재료는 어느 유닛? 로스터에 김경현이 `안흔함_김경현`(unitName 「김경현」) · `희귀함_김경현`(야구부주장 — 지금 재료) · `초월_김경현_AP`가 있다. 기본안: 이름만 쓰였으니 `안흔함_김경현`(unitName이 정확히 「김경현」인 것).
2. 체육특기생(재윤) 「현재체력 단일」은 노태현 체력스킬과 같은 **체력 게이지 50타째 · 현재체력 25%(보스 300,000)** 로 해도 되나? 끝딜 분류로는 현재체력은 끝딜이 아니라서 마나·확률 중 다른 발동을 원하는지.
3. 91사단의지휘자(공격력 오라 +25%)와 긍정의힘(디버프 해제)의 범위 = 같은 레인 **맵 전체**(range 5000)로 맞나? 공격력 +25%를 맵 전체에 주면 장혁(반경 850과 같은 값)보다 강해지는데 그대로 둘지.
4. 내면의악 수치(방어 −10 · 이속 −30%, 둘 다 제안값)와 「유닛 카운트」 = **내 레인의 적 수**가 한계(70, 난이도별)에서 −10 ~ 한계일 때 맞나?
5. 종이비행기를 **어떻게 쓰나**: 인벤토리에서 눌러 한 번 쓰는 방식(기본안)이 맞나, 아니면 도움소 버스터콜을 쓸 때 추가로 터지는 방식인가? 「아이템은 남음」 = 쓴 뒤에도 인벤토리에 남는 것(재사용은 불가)으로 이해했다.
6. 영구 정지 대상은 **어떤 적**(가장 체력 큰 적 / 직접 고르기 / 무작위)이고, 보스를 정지시키면 그 판의 보스 시간 제한·패배 규칙은 어떻게 되나? 전체 체력 25%는 보스·스토리 적도 깎나?
