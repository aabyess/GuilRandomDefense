# 초월 유재헌 「앰생파조장」 설계표 (2026-10-06, 구현담당2)

사장님 원문(큐 §22): 「유재헌 앰생파조장 — 타이핑: 영겁의도망꾼 / 재료: 김민규 미래를보는눈 · 홍인창 고슴도치 · 유재헌 토토교수 · 이은엽 드럼신동 / 스킬: 소환수(스턴, 보조딜), 골드획득량증가, 몹이감+18, 순간이동, 도박(금화, 목재, 위습)33% / *이감이높을수록 금화·목재 획득량 증가 / 스킬 이름: 토사장의어둠의수하들, 돈벌이, 현상수배, 도망자의삶, 토토」.
사장님 답(체크리스트, 「전부 추천안」, PM 전달): 소환수 2기 상시(평타 10% 스턴 0.5초 · 공격력 본체 30%) · 도박 = 버튼 1,000엔 → 33% 확률로 금화 3,000엔 / 목재 1 / 위습 1 중 하나 · 이감 1%당 골드·목재 획득 +1% · 골드 획득 +20% · 순간이동 = 배성령과 같은 「버튼 눌러 고른 곳으로」 틀(구현담당3, 공유).
**코드는 아직 안 씀.** 수치는 신 난이도 기준.

| 필요한 것 | 있나 | 위치 | 새로 만들 것 |

## 4. 신 난이도 기준 확인

| 스킬 | 신 기준 평가 |
|---|---|
| ① 소환수 공격력 본체 30% | 본체 DPS 비율 — 난이도 무관(소환수는 평타 딜 보조) |
| ② 골드 +20% / ③ 목재·골드 +1%당 | 배율 — 난이도 무관(신에서 적 체력이 크지만 보상 비율은 그대로) |
| ⑤ 도박 1,000엔 → 3,000엔(성공 33%) | 기댓값 = 0.33 × 3,000 = 990엔 ≈ 투자액 — 금화만 보면 거의 본전, 목재·위습 쪽이 이득. 사장님 수치 |

## 5. 질문(PM → 사장님께, 웹 질문지)
