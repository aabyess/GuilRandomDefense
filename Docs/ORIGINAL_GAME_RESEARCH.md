# 원작 원랜디 조사 자료 (2026-08-28, 리서치담당)

## 1. 라운드/웨이브
- **총 라운드**: 어려움 미만 60라운드 종료(신세계 미돌입) / 어려움 이상 신세계 진입, 65라운드에 신세계 보상 지급, 문서 서술은 75라운드까지 [원작]
- **라운드당 적 수**: "보스 라운드를 제외한 매 라운드마다 **35마리**의 라인 유닛이 등장" [원작 원문]
  - 라인당인지 전체인지는 **미기재** → 4레인 구조상 라인당일 가능성 [추정]
- **라운드 시간 / 스폰 간격**: **미기재**
- **보스 주기**: 매 10라운드, 신세계 진입 후 5라운드마다 [원작]. 보스 라운드 잡몹 동시 출현 여부 **미기재**
- **신세계 보스**: "라인 왼쪽에 무적 상태 건물로 2개의 추가 게이지를 가지고 등장" [원작]
- **난이도별**: 지옥은 41라운드부터 최대 카운트 60/55(신)/50(악몽)으로 감소.
  악몽은 시작 시 초월8·불멸4·제한됨2·영원1이 무작위 밴 [원작]

## 2. 적 유닛
- **개별 이름 목록**: **미기재** ("라인몹" 등 일반 명칭만)
- **스탯 경향**: "난이도가 높아질수록 체력·이속 등 전반적 스펙이 오른다. 필요한 이동속도 감소 디버프의 양이 증가하며, 방어력도 높아져 요구 방깎도 증가" [원작]
- **특수 적**: "광폭화 몬스터는 등장과 동시에 라인몹에게 체력 재생, 방어력 증가, 마법방어력 증가 등 버프 오라" [원작]

## 3. 보스
- **이름 목록**: **미기재**
- **제한시간**: "신세계에서 보스 등장 후 20초 이내 처치 시 풀카운트 보너스 200점" [원작]
  → 이건 보너스 조건이고, "N초 내 미처치 = 패배"의 구체 수치는 **미기재**

## 4. 아군 유닛
- **등급 체계 (13단계, 낮은→높은)** [원작]:
  흔함 → 안흔함 → 특별함 → 희귀함 → 특수함 → 전설 → 히든 → 랜덤전용(이세계)
  → 랜덤전용<제한됨>/신비함 → 초월함 → 불멸 → 영원함 → 제한됨
- **빌드 3분류** [원작]:
  - 물뎀: 방어력에 감폭당함, 후반엔 방깎 필수
  - 마뎀: 방어력 무시, 스킬딜로 처리
  - 방무뎀: 물뎀·마뎀 중간, "클리빙 어택"
- **역할 예시** (IP 이름 제외, 포지션만): 물리 단일딜러 / 이속감소+마뎀 / 공증·방깎·공속 버프 서포터 /
  스턴+방깎+이감+아머브레이크 복합 / 보스 특화 딜러(일반 딜러는 보스전 딜로스 있어 별도 필요) [원작]

## 5. 조합
- **등급마다 규칙이 다름** — 통일 공식 **미기재**
- 확인된 조합식 [원작]:
  - 전설 = 희귀 3개 + 나무 3
  - 불멸 = 전설 3개 + 나무 10
  - 영원함·제한됨 대부분 = 나무 5 (재료 유닛 수 명시 부족)
  - 초월 = 전용 "초월 위습" 소모 (일반 조합과 별개 시스템)
- **레시피형 조합 있음** [원작]: 히든은 특정 유닛 보유 후 채팅 명령어 입력.
  예) 영원함 1종 = 초월 1 + 전설 1 + 희귀 1 + 안흔함 1 + 특수 아이템 + 목재 5
- **확률 요소**: 희귀 리롤 한 판 최대 2개 제한(9.3버전~), 도박은 5번 초과 실패 시 비용 증가 [원작]

## 6. 경제

- **나무 소모**: 배 제작 9개, 랜덤전용 지정뽑기 12개, 조합 3/5/10개 [원작]

- **패널티**: "정해진 라운드까지 클리어 못하면 전원 패배" [원작]. 부분 감점 등 추가 패널티 **미기재**

## 8. 맵/구조
- **레인 개수 / 플레이어 배치**: **미기재** ⚠️
  - "4인 협동"은 확인되지만 **"레인 = 4개"를 명시한 문장은 못 찾음**
  - → GDD에 "원작 그대로"라고 쓰면 부정확. "다인용 레인 구조를 4인에 맞게 채택"이 정확
- **맵 구역**: "스토리존", "크립존" 언급. 전체 구조도는 **미기재**

## 9. 패배·승리 조건
- **데스카운트** [원작 원문]: "라인의 유닛 카운트가 **70 이상**이 되면 데스카운트가 **10**에서 하나씩 줄어들고, **0이 되면** 방어 실패로 패배"
  → 즉 **1회 초과 = 즉시 패배가 아니라, 초과 상태가 반복되며 10번 깎여야 패배**
- **난이도별**: 지옥 이상 41라운드부터 최대 카운트 60/55/50으로 감소. 신세계 진입 시 데스카운트 **1로 고정** [원작]
- **승리 조건 추가 규칙**: **미기재**

## 10. 기타

## ⚠️ 우리 GDD와의 차이 (기획 판단 필요)

1. **패배 조건 구조가 다름**
   - 원작: 라인 카운트 70 초과 시 데스카운트 10→0으로 차감, 0에서 패배 (**다단계 유예**)
   - 현재 MVP: 필드 몹 25 초과 시 **즉시 패배** (1회 초과형)
   - → 원작 감각을 살리려면 데스카운트 개념 재도입 필요. 단순화 유지할지 기획 판단.

2. **4레인 = 4인 매핑에 원작 근거 없음**
   - 문서에 "레인 4개"를 명시한 문장이 없음. GDD 표현을 "원작 그대로"에서
     "다인용 레인 구조를 4인에 맞게 채택"으로 바꾸는 게 정확.

3. **등급 13단계 vs 우리 4단계**
   - 원작은 13단계, MVP는 4단계로 압축. 확장 시 원작 순서 참고 가능.

4. **조합이 등급마다 다른 규칙**
   - 원작은 통일 공식이 없고 등급별로 재료·재화가 다름 + 레시피형 조합도 병존.
   - 현재 MVP는 "동일 3개 → 상위 1개" 단일 규칙. 확장 시 CombineRecipe 도입 필요
     (구현담당2가 이미 확장 대비해 로직 격리해둠).
