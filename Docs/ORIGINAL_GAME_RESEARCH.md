# 원작 원랜디 조사 자료 (2026-08-28, 리서치담당)

> 표기 규칙: **[원작]** = 문서 확인됨 / **미기재** = 문서에 없음 / **[추정]** = 추론
> ⚠️ 유닛/캐릭터 이름은 전부 원피스 IP라 **우리 게임에 사용 불가**. 구조·포지션 참고용으로만 볼 것.

## 1. 라운드/웨이브
- **총 라운드**: 어려움 미만 60라운드 종료(신세계 미돌입) / 어려움 이상 신세계 진입, 65라운드에 신세계 보상 지급, 문서 서술은 75라운드까지 [원작]
- **라운드당 적 수**: "보스 라운드를 제외한 매 라운드마다 **35마리**의 라인 유닛이 등장" [원작 원문]
  - 라인당인지 전체인지는 **미기재** → 4레인 구조상 라인당일 가능성 [추정]
- **라운드 시간 / 스폰 간격**: **미기재**
- **보스 주기**: 매 10라운드, 신세계 진입 후 5라운드마다 [원작]. 보스 라운드 잡몹 동시 출현 여부 **미기재**
- **신세계 보스**: "라인 왼쪽에 무적 상태 건물로 2개의 추가 게이지를 가지고 등장" [원작]
- **난이도별**: 지옥은 41라운드부터 최대 카운트 60/55(신)/50(악몽)으로 감소.
  악몽은 시작 시 초월8·불멸4·제한됨2·영원1이 무작위 밴 [원작]

## 2. 적 유닛
- **개별 이름 목록**: **미기재** ("라인몹" 등 일반 명칭만)
- **스탯 경향**: "난이도가 높아질수록 체력·이속 등 전반적 스펙이 오른다. 필요한 이동속도 감소 디버프의 양이 증가하며, 방어력도 높아져 요구 방깎도 증가" [원작]
- **특수 적**: "광폭화 몬스터는 등장과 동시에 라인몹에게 체력 재생, 방어력 증가, 마법방어력 증가 등 버프 오라" [원작]

## 3. 보스
- **이름 목록**: **미기재**
- **제한시간**: "신세계에서 보스 등장 후 20초 이내 처치 시 풀카운트 보너스 200점" [원작]
  → 이건 보너스 조건이고, "N초 내 미처치 = 패배"의 구체 수치는 **미기재**

## 4. 아군 유닛
- **등급 체계 (13단계, 낮은→높은)** [원작]:
  흔함 → 안흔함 → 특별함 → 희귀함 → 특수함 → 전설 → 히든 → 랜덤전용(이세계)
  → 랜덤전용<제한됨>/신비함 → 초월함 → 불멸 → 영원함 → 제한됨
- **빌드 3분류** [원작]:
  - 물뎀: 방어력에 감폭당함, 후반엔 방깎 필수
  - 마뎀: 방어력 무시, 스킬딜로 처리
  - 방무뎀: 물뎀·마뎀 중간, "클리빙 어택"
- **역할 예시** (IP 이름 제외, 포지션만): 물리 단일딜러 / 이속감소+마뎀 / 공증·방깎·공속 버프 서포터 /
  스턴+방깎+이감+아머브레이크 복합 / 보스 특화 딜러(일반 딜러는 보스전 딜로스 있어 별도 필요) [원작]

## 5. 조합
- **등급마다 규칙이 다름** — 통일 공식 **미기재**
- 확인된 조합식 [원작]:
  - 전설 = 희귀 3개 + 나무 3
  - 불멸 = 전설 3개 + 나무 10
  - 영원함·제한됨 대부분 = 나무 5 (재료 유닛 수 명시 부족)
  - 초월 = 전용 "초월 위습" 소모 (일반 조합과 별개 시스템)
- **레시피형 조합 있음** [원작]: 히든은 특정 유닛 보유 후 채팅 명령어 입력.
  예) 영원함 1종 = 초월 1 + 전설 1 + 희귀 1 + 안흔함 1 + 특수 아이템 + 목재 5
- **확률 요소**: 희귀 리롤 한 판 최대 2개 제한(9.3버전~), 도박은 5번 초과 실패 시 비용 증가 [원작]

## 6. 경제
- **골드 획득 방식**: **미기재**
- **나무(목재) 획득**: 특정 유닛 스킬 연계 사례만 확인 (60% 골드 / 40% 목재). 일반 획득 경로인지 불명 [원작 부분]
- **나무 소모**: 배 제작 9개, 랜덤전용 지정뽑기 12개, 조합 3/5/10개 [원작]
- **상점 구조**: **미기재**

## 7. 스토리
- **개수**: 최소 13개 이상 확인. 11번째(드레스로자), 12번째(홀케이크아일랜드), 13번째(와노쿠니) [원작]
  총 개수가 13개로 끝인지는 **미기재**
- **진행 규칙**: 지옥은 41라운드까지 11번째 격파, 신 이상은 12번째까지 격파 후 5분 뒤 13번째 등장, 5분 내 격파 [원작]
- **패널티**: "정해진 라운드까지 클리어 못하면 전원 패배" [원작]. 부분 감점 등 추가 패널티 **미기재**

## 8. 맵/구조
- **레인 개수 / 플레이어 배치**: **미기재** ⚠️
  - "4인 협동"은 확인되지만 **"레인 = 4개"를 명시한 문장은 못 찾음**
  - → GDD에 "원작 그대로"라고 쓰면 부정확. "다인용 레인 구조를 4인에 맞게 채택"이 정확
- **맵 구역**: "스토리존", "크립존" 언급. 전체 구조도는 **미기재**

## 9. 패배·승리 조건
- **데스카운트** [원작 원문]: "라인의 유닛 카운트가 **70 이상**이 되면 데스카운트가 **10**에서 하나씩 줄어들고, **0이 되면** 방어 실패로 패배"
  → 즉 **1회 초과 = 즉시 패배가 아니라, 초과 상태가 반복되며 10번 깎여야 패배**
- **난이도별**: 지옥 이상 41라운드부터 최대 카운트 60/55/50으로 감소. 신세계 진입 시 데스카운트 **1로 고정** [원작]
- **승리 조건 추가 규칙**: **미기재**

## 10. 기타
- **게임 모드 3종**: 일반 / 변질됨 / 초고속 [원작] ("변질됨" 상세는 미조사)
- **커뮤니티 용어**: "풀카운트"(라인몹 한 마리도 안 보내고 클리어), "노보상"(신세계 보상위습 미사용 클리어) [원작]

## ⚠️ 우리 GDD와의 차이 (기획 판단 필요)

1. **패배 조건 구조가 다름**
   - 원작: 라인 카운트 70 초과 시 데스카운트 10→0으로 차감, 0에서 패배 (**다단계 유예**)
   - 현재 MVP: 필드 몹 25 초과 시 **즉시 패배** (1회 초과형)
   - → 원작 감각을 살리려면 데스카운트 개념 재도입 필요. 단순화 유지할지 기획 판단.

2. **4레인 = 4인 매핑에 원작 근거 없음**
   - 문서에 "레인 4개"를 명시한 문장이 없음. GDD 표현을 "원작 그대로"에서
     "다인용 레인 구조를 4인에 맞게 채택"으로 바꾸는 게 정확.

3. **등급 13단계 vs 우리 4단계**
   - 원작은 13단계, MVP는 4단계로 압축. 확장 시 원작 순서 참고 가능.

4. **조합이 등급마다 다른 규칙**
   - 원작은 통일 공식이 없고 등급별로 재료·재화가 다름 + 레시피형 조합도 병존.
   - 현재 MVP는 "동일 3개 → 상위 1개" 단일 규칙. 확장 시 CombineRecipe 도입 필요
     (구현담당2가 이미 확장 대비해 로직 격리해둠).

## 11. 라운드 구성 상세 조사 (2026-09-02)

> PM 요청: 75라운드 적 데이터가 전부 임시(플레이스홀더)라, 언제 뭐가 나오는지 근거가 필요함. 기존 "1. 라운드/웨이브" 섹션에 이미 있는 내용은 재조사하지 않고, PM이 요청한 것 중 그동안 안 채워졌던 항목(체력·공격력 상승 곡선, 라운드 사이 대기시간, 특수 라운드)에 집중함. 나무위키(WebFetch로 원문 재확인), 디시인사이드 검색을 시도했다.

### 재확인된 것 (기존 섹션 1과 동일, 새 발견 없음)

| 항목 | 내용 | 태그 |
|---|---|---|
| 총 라운드 | 어려움 이상 75라운드, 어려움 미만 60라운드 종료 | [원작] (나무위키 원문 재확인) |
| 라운드당 적 수 | 보스 라운드 제외 매 라운드 35마리 | [원작] (동일) — 라인당/전체 구분은 여전히 **[미기재]**, 라운드 진행에 따라 마릿수 자체가 늘어나는지도 **[미기재]** |
| 보스 주기 | 매 10라운드, 신세계 진입 후 5라운드마다 | [원작] (동일) — 정확한 회차 숫자 나열(10,20,30...)이나 신세계 진입 시점의 정확한 라운드 번호는 여전히 **[미기재]** |

### 이번에 새로 확인하려 했으나 못 찾은 것

**1) 체력·공격력의 라운드별 상승 곡선 — [미기재], 벽에 부딪힘**

나무위키 원문(WebFetch로 재확인)엔 "난이도가 높아질수록 몬스터들의 체력·이속 등 전반적인 스펙이 오른다"는 **정성적 서술만 있고, 수식·배수·퍼센트는 전혀 없다.** 디시인사이드에서 "몹 체력 증가 공식", "몹 스펙업 배수" 등으로 검색했지만 관련 게시글 자체를 찾지 못했다. 원작이 2023년 9월 서비스 종료·맵 삭제된 뒤라, 이런 밸런스 수치는애초에 유저가 역산해서 커뮤니티에 정리해둔 사례가 없었을 가능성이 높다 — **원작에 존재하지 않는 정보라기보다, 유저 레벨에서 공식화된 적이 없는 종류의 정보로 보인다** [추정].

**2) 라운드 사이 대기시간 — [미기재]**

디시인사이드에 "원랜디 한판 시간 얼마나 소요됨?"이라는 질문 게시글(https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=87071)이 있다는 것까지는 확인했으나, **WebFetch로는 게시판 목록만 보이고 게시물 본문·댓글 내용이 렌더링되지 않아 답변을 확인하지 못했다.** 나무위키 원문에도 라운드 간 대기시간을 명시한 문장이 없다.

**3) 특수 라운드(백수생활 외) — [미기재]**

"이벤트 라운드", "함정" 등으로 검색했으나 관련 서술을 찾지 못했다. 나무위키 원문에도 백수생활류 대기 구간 외에 다른 특수 라운드 언급이 없다.

**4) 보스 라운드에 잡몹이 동시에 나오는지 — [미기재]**

기존 섹션 1에 이미 "미기재"로 남아있던 항목인데, 이번에도 확인하지 못했다.

### 라운드 표 — WaveData로 옮길 수 있는 형태로 정리

원작 수치가 부족해서 표 대부분이 "원작 확인 불가 → 자체 설계 필요" 상태다. 억지로 숫자를 채우지 않고, **어디까지가 원작이고 어디부터 우리가 정해야 하는지**를 표로 명확히 구분했다:

| 항목 | 원작에서 확인됨 | 우리가 정해야 함 (원작 근거 없음) |
|---|---|---|
| 총 라운드 수 | 60(어려움 미만) / 75(어려움 이상) [원작] | 난이도 시스템을 도입할지, 도입한다면 어느 값을 기준으로 할지 |
| 라운드당 마릿수 | 35마리(제외: 보스 라운드) [원작], 라인당/전체 여부 미기재 | 라인당인지 전체인지 확정, 라운드 진행에 따른 증가 여부·증가폭 |
| 체력/공격력 곡선 | 없음 — "오른다"는 정성적 서술뿐 [원작] | **전부 자체 설계.** 선형/지수/구간별 중 선택, 실제 수치 |
| 보스 주기 | 10라운드마다, 신세계 이후 5라운드마다 [원작] | 신세계 개념을 도입할지, 도입 안 하면 10라운드 고정으로 갈지 |
| 라운드 대기시간 | 없음 [미기재] | 전부 자체 설계 (몇 초로 할지) |
| 데스카운트 | 70 초과 시 10→0 차감, 0에서 패배. 신세계는 1 고정 [원작] | 데스카운트 시스템을 도입할지(현재 MVP는 즉시패배형, 기존 GDD 차이 섹션 1번과 동일 이슈), 도입한다면 70·10 수치를 그대로 쓸지 |
| 특수 라운드 | 백수생활(스토리 연동, 별도 조사됨) 외 없음 [미기재] | 필요하면 자체 설계 |

### 확인 못한 항목 (`[미기재]`)

- 체력·공격력이 라운드에 따라 오르는 정확한 수식/배수/곡선 — 원작 원문에 정성적 서술만 있고, 커뮤니티에서도 역산된 자료를 못 찾음
- 라운드마다 적 마릿수가 라운드 진행에 따라 늘어나는지, 35마리가 라인당인지 전체인지
- 보스 라운드의 정확한 회차 목록(10, 20, 30... 인지), 신세계 진입 라운드 번호
- 라운드 사이 대기시간 — 디시인사이드에 질문 글은 있으나 답변 내용을 못 봄
- 데스카운트가 라운드마다 리셋되는지 누적되는지 (조건형 서술로 리셋 쪽으로 추정만 됨)
- 보스 라운드에 잡몹이 동시에 나오는지
- 백수생활 외의 특수 라운드/이벤트 존재 여부

### 결론

**이번 조사는 대부분 벽에 부딪혔다.** 기존에 확인됐던 것(총 라운드/35마리/보스주기/데스카운트)을 재확인한 것 외엔 새로 나온 게 없다. 특히 PM이 가장 필요로 한 **"체력·공격력 상승 곡선"은 원작에 아예 수치화된 적이 없는 것으로 보인다** — 나무위키도 정성적 서술만 하고, 유저 커뮤니티도 이걸 공식화한 자료가 없다. **원작을 더 파도 안 나올 가능성이 높다 — 이 부분은 처음부터 자체 밸런싱(선형이든 지수든)으로 가는 게 유일한 현실적 경로**로 보인다. 위 "라운드 표"의 오른쪽 칸("우리가 정해야 함")이 실질적으로 다음 작업 범위다.
