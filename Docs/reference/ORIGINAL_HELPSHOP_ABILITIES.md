# 도움소(`h08A`) 능력 11종 전수 — 「100만 고정데미지」 포함

조사: 리서치담당 / 2026-09-06

## 구조

도움소는 **유닛 `h08A` 「도움소」** 하나이고, 능력 11개를 `uabi`에 직접 들고 있다.
```
h08A.uabi = A0QT, A0JR, A0P2, AOeq, A0IE, A0ID, A0IC, A0IB, A0B1, A0IA, A0I9, Avul
```
전부 **플레이어가 직접 쓰는 액티브**이고, 자원은 **마나**로 낸다(골드가 아니다).
6개는 `Trig_Absolb1_Actions`가 `GetSpellAbilityId()`로 분기해 처리하고, 5개는 **w3a 필드만으로** 동작한다.

> 📌 **도움소는 툴팁이 정확하다.** 11종 전부 툴팁과 필드·트리거가 맞았다.
> 오늘 하루 툴팁이 일곱 번 틀렸는데 여기만 예외다 — **플레이어가 직접 쓰는 액티브라 제작자가 관리한 것**으로 보인다.

## 🔴 PM이 물은 「100만 고정데미지」 — 트리거에 있었다

```jass
Trig_Absolb1_Func006C:  GetSpellAbilityId() == 'AOeq'
  → ForGroupBJ(GetUnitsInRangeOfLocMatching(625.00, 시전지점, …), Trig_Absolb1_Func006Func003A)

Trig_Absolb1_Func006Func003A:
    call SetUnitAbilityLevelSwapped('AIsr', GetEnumUnit(), 현재 + 5)     ← 마법 피해 증폭 +5
    call RRD(GetTriggerUnit(), GetEnumUnit(), 1000000.00, 1.00, 1.00,
             ATTACK_TYPE_CHAOS, DAMAGE_TYPE_UNIVERSAL)                   ← ★ 100만
```

**`Oeq1 = 0.12`은 건물 피해 배율이고 유닛 피해와 무관하다**(어제 판정 그대로).
실제 피해는 트리거의 `RRD 1,000,000`이다. **툴팁의 세 항목이 전부 맞는다**:
- 「625범위」 = `ForGroup` 반경 625 ✅
- 「100만의 고정데미지」 = `RRD 1,000,000` ✅
- 「2.5초간 이동속도 85% 감소」 = `adur 2.5` · `Oeq3 0.85` ✅
- 「마법데미지 5% 증폭」 = `AIsr` 레벨 **+5** ✅ ← **`AIsr`이 그 축이라는 게 여기서 확인된다**

### ⚠️ 레벨 2면 **두 번 터진다**

```jass
Trig_Absolb1_Func006Func005C:  GetUnitAbilityLevelSwapped('AOeq', 시전자) == 2
  → e0NF 소환 + 625범위 두 번째 ForGroup → RRD(1,000,000, …) 한 번 더
```
`AOeq`의 `alev = 2`다. → **레벨 1은 100만, 레벨 2는 100만 × 2 = 200만.**
툴팁은 100만만 적어놨다 — **툴팁이 레벨 1 기준**이다.

`A0JR` 버스터콜도 같은 구조다: `udg_item_Bustercall_bool`(아이템 보유)이면 추가 분기가 붙는다.

## 남은 `[미확인]` 1건

`A0ID` 해루석 툴팁의 **「초당 2,500,000 데미지」**가 필드에도 트리거에도 없다.
트리거는 **첫 타격 최대체력 7%**만 낸다. `Amls` base의 스톡 필드에 있을 수 있으나 맵 파일로는 못 뽑는다.
→ **「첫 타격 최대체력 7%」만 확정으로 쓰고, 초당 250만은 `[미확인]`으로 남긴다.**

## 우리에 옮길 때

- **자원 단위가 마나다.** 골드가 아니다. 우리 도움소가 골드로 되어 있으면 축이 다르다.
- **`A0QT` 지진은 피해가 0이다**(스턴 3초만). 600범위 스턴을 피해로 넣으면 안 된다.
- **`A0I9` 흡수는 즉사이고 보스·스토리엔 안 통한다.** 실패 시 마나가 환급된다 — 그 환급이 없으면 원작보다 나빠진다.
- **`AOeq`·`A0JR`은 레벨/아이템에 따라 두 배가 된다.** 레벨 1 기준으로만 옮기면 과소가 된다.
