# 원작 하위 등급 스킬 전수 — **흔함 0건 확정 · 안흔함 6종** (2026-09-06, 리서치담당)

> **① 흔함(32종)에 전투 스킬은 하나도 없다. 「0건」이 확정이다** — 우리 흔함 88.9%는 전부 걷어내는 게 맞다.
> **② 안흔함(14종)에는 실제 전투 스킬이 6종 있다.** 우리 안흔함 0%를 여기서 채운다.

## ⓪ 먼저 — 내 등급 추출기에 오래된 버그가 있었다 (뿌리 ⑲)

이번 스캔의 첫 판에서 **안흔함 14종이 전부 「흔함」으로 잡혔다.**
**「흔함」이 「안흔함」의 부분문자열**이라, 라벨 목록을 앞에서부터 훑고 첫 매치를 반환하면 **「안흔함」이 영영 안 나온다.**

```python
for L in ORDER:                 # ← 첫 매치 반환. '흔함'이 '안흔함'을 먹는다
    if L in nm: return L
g=[L for L in ORDER if L in nm]; return g[-1]   # ← 마지막 매치. 더 긴 라벨이 이긴다 (올바름)
```

**사다리 집계 때는 `g[-1]`을 써서 맞았고, 이번 스캔에서만 첫 매치로 썼다.**
→ **같은 개념을 두 번 구현하면 한쪽만 맞을 수 있다.** 등급 판정은 함수 하나로 고정해야 한다.
