## 해왕류 — 상세 (구현담당2 완료)

- **위치**: 맵 왼쪽 [원작]
- **접근 조건**: 순간이동/공중이동/바다이동 유닛만 접근 가능 — 폐문(에니에스로비)과 같은 패턴, 우리 `UnitSpawner.ComputeAreaMask`의 Sea 마스크 구조와 정확히 일치 [원작]
- **보상**: **경험치 하나만 확인됨.** 경험치는 원작 WC3 그대로 레벨업 시스템(힘/민첩/지능, 스킬 획득)으로 이어진다 [원작] — 우리 게임엔 경험치·레벨업 개념 자체가 없어 대체 자원 설계가 필요하다.
- **⚠️ 정정(구현담당2 재조사)**: 처음엔 "2단계 크립 보상"을 해왕류가 주는 것처럼 요약됐으나 **틀렸다** — **크립은 해왕류와 완전히 별개의 독립 시스템**이다. 스토리 맵 아래쪽의 특수 몹으로 1/2/3단계가 있고, 2단계가 (목재7) 또는 (목재3+해적선)을 랜덤 지급한다. 접근 조건(공중이동/긴사거리)이 해왕류와 비슷해서 뭉뚱그려 설명됐을 뿐, 원문에 둘을 직접 연결하는 서술은 없다. **해왕류의 직접 보상은 경험치뿐이다.**
- **⚠️ 확률표 정정**: `GAMBLING.md` 4차 조사에서 "고도 확률표와 안 맞는 정체불명 표"로 남아있던 **"초월함6.98%/전설18.55%/희귀24.24%/특별50.22%"가 실은 해왕류 아이템 드랍표(1/6 확률로만 발동)**였다는 게 확인됐다 — `GAMBLING.md`에 이미 정정 반영함.
- **안 잡으면**: 시스템적 페널티 서술 없음. "무단으로 잡으면 욕먹는다"는 건 커뮤니티 매너 관습(경험치를 팀 전체가 나눠 가지므로 독단 처치를 자제하라는 것)이지 게임 시스템이 아님.
- **미기재**: 정확한 등장 라운드/조건, "경험치"를 우리 게임 무슨 자원으로 대체할지.

## 보물 — 상세 (구현담당2 완료)

- **획득**: "탐색"(F1 단축키로 추정)으로 발견 [원작]
- **일반 모드 개방 조건 확인됨**: **"10라운드 보스를 잡은 후 F1을 눌러 100초마다 탐색"** [원작]. 우연이 아니라 10라운드 보스 처치가 선행 조건인 반복 가능 행동이다.
  - **⚠️ 흥미로운 대응점**: 이 조건이 `GAMBLING.md`의 **500엔 도박 해금 조건("10라운드 보스 처치")과 정확히 같은 트리거**다 — 원작에서 10라운드 보스가 도박·보물 등 여러 시스템을 동시에 여는 **공용 게이트**였을 가능성이 있다. 우리 게임에서 500엔 도박 해금 조건을 확정할 때 이 공용성을 참고할 만하다.
- **"초고속" 게임모드**: 1라운드부터 생성 + 탐색도구 기본 지급(일반 모드보다 빠르게 시작). **원작은 "초고속" 모드가 도박·보물 등 여러 시스템을 동시에 앞당기는 구조인데, 우리 게임엔 모드 선택 개념이 없다.**
- **나미(전설) 보유 시 보상 2배** [원작] ("하위 패인"이라는 표현의 정확한 뜻은 미기재, 오타로 추정)
- **미기재**: 탐색 성공 확률, 정확한 조작 방식(F1을 누르면 무슨 일이 일어나는지), 탐색 가능 범위(커뮤니티에서도 미해결 질문으로 남아있었음 — dcinside no=50889), 정확한 보상 내용물(자원류로 추정만 가능).

## 해적단(→해적선?) · 크립 · 탐색 — 상세

- **⚠️ "해적단"의 정체가 불확실하다.** 부가 퀘스트 목록에 이름만 있고 상세 서술이 없다. 대신 실제로 서술되는 건 **「해적선」** — **크립**(해왕류와 별개의 독립 시스템, 스토리 맵 아래쪽, 1/2/3단계) 2단계 몹 처치 시 (목재7) 또는 (목재3+해적선) 랜덤 보상으로 얻는 숨겨진 유닛이다. **사장님이 말씀하신 "해적단"이 이 「해적선」을 가리키는지 확인이 필요하다.** 우리 게임의 뽑기 섬 특수 칸 「배(상붕카)」와 같은 것일 가능성도 있으나 근거는 약하다 [추정, 낮음].
- **크립 상세**(구현담당2 추가 확인, 출처 dcinside no=7820): 1단계=목재1+소량골드, **2단계=목재7 또는 목재3+해적선**(우선순위 최고 처치 대상), 3단계=목재+골드. 잡으려면 블링크거리1500 이상/공중이동/긴사거리 유닛 필요.
- **탐색**: 플레이어 건물에서 쿨타임마다 돌리는 기능 + "모건" 유닛이 100초마다 별도로 추가 탐색(건물 쿨타임과 별개). 이동 능력이 숨겨진 콘텐츠 접근 조건으로 쓰인다 — 우리 `MovementAbility` enum(Flying/WaterWalk/Teleport)이 이미 이 축을 갖고 있어 구현 시 바로 연결 가능.

## 와포루·거프 — 사장님 확인 필요

**두 구현담당이 각자 독립적으로 조사했는데 둘 다 이름조차 못 찾았다.** 원작 원피스에서 와포루(드럼 왕국 왕)·거프(몽키 D. 가프)는 실존 캐릭터지만, **원랜디 게임 안에서 이 이름이 무엇을 가리키는지** 확인이 안 된다. 우리 게임의 적 75종은 전부 오리지널 이름이라 원작 보스명과 대조도 안 됐다.

**→ 원랜디 콘텐츠가 맞는지 자체가 불확실하다. 사장님께 "원랜디의 무엇을 가리키는 건지" 직접 여쭤보는 게 가장 빠르다.**

## 조사 한계 (공통)

- `ordsearch.net`이 가장 유력한 추가 출처로 보이나(특히 `tips/2` "기타 유닛(재료) 얻기") **HTTP 403으로 자동 조회가 계속 막혔다** — 세 조사자 전부 동일. 사람이 직접 브라우저로 열어봐야 뚫릴 수 있다.
- 나무위키 본문을 직접 조회하면 "부가 퀘스트" 절 자체가 안 나온다(검색 스니펫에만 잡힘) — 문서가 길어 조회 도구가 매번 다른 구간을 요약하는 현상, 또는 접히는 문단일 가능성. 사람이 직접 보면 더 나올 수 있다.
- 서비스 종료(2023-09) 3년 가까이 지나 자료가 계속 이 벽에 부딪힌다 — 황금조각·등불·스모커·해적단의 발생조건·보상 수치는 더 파도 안 나올 가능성이 높다.

## 확인이 필요한 것 (종합)

1. **와포루·거프가 원랜디 콘텐츠가 맞는지** — 사장님 확인 최우선
2. **"해적단"이 「해적선」을 가리키는지**
3. **"보물"·"500엔 도박" 둘 다 원작은 "10라운드 보스 처치" 또는 "초고속 게임모드"로 묶여 있는데, 우리 게임에 모드 개념을 도입할지 vs 이미 있는 500엔도박처럼 라운드 조건으로 통일할지** — 특히 **10라운드 보스가 두 시스템의 공용 게이트였을 가능성**이 새로 확인돼, 500엔 도박 해금 조건을 확정할 때 보물 탐색도 같이 묶는 설계가 원작에 가까울 수 있다.
4. **해왕류·보물의 보상을 우리 게임 어떤 자원(골드/목재/위습)으로 대체할지** — 원작의 "경험치·레벨업" 프레임이 우리 게임에 없어 그대로 못 옮긴다.
5. **황금조각·등불의 발생조건·보상** — 리서치로는 한계에 도달, 사람이 `ordsearch.net`을 직접 열어봐야 뚫릴 가능성
6. **해왕류·크립·보물탐색을 맵 어디에 배치할지** — 원작 "맵 왼쪽"·"스토리 맵 아래쪽"이 우리 맵 어느 구역에 대응하는지 별도 판단 필요(지금 우리 맵엔 물범·펑크해저드뿐)
7. **"크립"을 우리 게임에 별도 시스템으로 만들지, 생략할지** — 원작엔 있지만 사용자가 아직 언급 안 한 개념
