## 함정 — 첫 조회 때 실제로 걸렸던 버그

처음엔 `"AIsr"+"isr2"`(objectId 접두사를 붙인 문자열)로 검색했다가 **레벨 29~36을
"엔트리 없음"으로 오판**했다. 원인: `war3map.w3a`가 레벨이 일정 개수를 넘어가면 필드
엔트리 앞에 objectId 접두사(`AIsr`/`Aegr`)를 안 붙이고 필드명만 단독으로 쓰는 구간이
있다(이유는 불명 — 에디터가 레벨을 늘릴 때 저장 방식이 바뀐 것으로 추정, 확인 안 함).
**bare 필드명만으로 검색**해야 전체 레벨이 다 잡힌다. 아래 스크립트는 이 함정을 피한
버전이다.

## 추출 스크립트

```python
"""
Aegr(Def5)/AIsr(isr2) 레벨별 원문 배열 추출기 — 2026-09-06, 리서치담당
사용법: war3map.w3a와 같은 디렉터리에서
        python3 extract_level_axes.py 'Def5'
        python3 extract_level_axes.py 'isr2'
처럼 필드명 하나만 인자로 주면 그 필드의 레벨별 값을 전부 덤프한다.
주의: 반드시 "objectId 접두사 없는 bare 필드명"으로 검색해야 한다(위 함정 참고).
      다른 능력의 레벨-비례 필드를 조사할 때도 이 스크립트를 그대로 재사용할 수 있다 —
      필드명만 바꿔서 돌리면 된다.
"""
import struct
import sys

def dump_all(data, tag):
    out = []
    start = 0
    tagb = tag.encode()
    while True:
        p = data.find(tagb, start)
        if p == -1:
            break
        hdr = data[p+4:p+16]
        if len(hdr) == 12:
            typ, level, dataId = struct.unpack('<iii', hdr)
            valb = data[p+16:p+20]
            fval = struct.unpack('<f', valb)[0]
            out.append((p, level, fval, typ, dataId))
        start = p + 1
    return out

if __name__ == '__main__':
    field = sys.argv[1] if len(sys.argv) > 1 else 'Def5'
    data = open('war3map.w3a', 'rb').read()
    for p, level, val, typ, did in dump_all(data, field):
        print(f"pos={p} level={level:3d} val={val:.6f} typ={typ} dataId={did}")
```

## 부호 방향 (② PM 질의 — `isr2` 증폭이냐 감소냐)

- `AIsr` 리터럴이 등장하는 JASS 23곳 전부 `SetUnitAbilityLevelSwapped('AIsr', 대상, GetUnitAbilityLevelSwapped('AIsr',대상)+N)` 형태의 **레벨 증가 호출뿐**이다 — `isr2` 값을 직접 읽어 데미지 계산에 곱하거나 부호를 뒤집는 JASS 코드는 어디에도 없다(엔진 네이티브 자동 적용, 즉 트리거가 개입할 지점 자체가 없다).
- `anam`(툴팁 이름) = "마법 데미지 증폭" — 명시적으로 "증폭"(증가)이라고 이름 붙어 있다.
- `TARGET_SIDE_AXES.md`에 이미 있던 실측 교차검증: "+5 = 도움소 대지진(`AOeq`) → 툴팁 「마법데미지 5% 증폭」과 정확히 일치" — **레벨을 5 올리면(=`isr2`가 0.05만큼 더 음수가 되면) 실제 툴팁이 "5% 증폭"이라고 말한다.** 즉 **음수가 커질수록(0에서 −0.25로 갈수록) 증폭(더 받음)**이라는 게 이름과 실측 둘 다에서 일치한다.
- **결론: `isr2`가 음수일수록 대상이 마법 피해를 더 받는다.** 부호가 뒤집혀 있을 근거를 찾지 못했다 — 뒤집는 코드 자체가 없고, 있는 증거(이름 + `AOeq` 실측)가 전부 같은 방향을 가리킨다.
