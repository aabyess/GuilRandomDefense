# 펑크해저드 정의문 조사 (2026-09-01, 리서치담당)

> 조사 방법: 나무위키 "원피스 랜덤 디펜스" 문서(및 과거 판), 나무위키 "정의의 문" 문서,
> `weingchicken.com` 원랜디 팁 블로그, `ordsearch.net`(원랜디 캐릭터 검색기) 웹서치.
> 표기 규칙: **[원작]** = 확인됨(URL 필수) / **[추정]** = 근거 있으나 미확인 / **[미기재]** = 못 찾음

## ⚠️ 핵심 발견 — "펑크해저드"와 "부술 수 있는 문"은 원작에서 별개의 것일 가능성이 높다

원작 나무위키 문서에서 **"펑크해저드"는 부술 수 있는 문/게이트가 아니라 스토리 10번(스토리존의 한 스테이지)이다** [원작]:

> "스토리 10. 펑크해저드 격파시 초월위습 대신 초월쿠마 지급"
> — [원피스 랜덤 디펜스 - 나무위키](https://namu.wiki/w/%EC%9B%90%ED%94%BC%EC%8A%A4%20%EB%9E%9C%EB%8D%A4%20%EB%94%94%ED%8E%9C%EC%8A%A4)

반면 원작에서 **"부수면 보스가 나오는 문"은 "폐문(에니에스로비)"라는 별개의 맵 오브젝트**다 [원작]:

> "맵 우측 폐문(에니에스로비)을 부순 뒤 나오는 보스(아카이누, 아오키지, 키자루)를 잡으면 1포인트 획득 가능"
> — [\[원랜디 팁\] 특성포인트 얻기 - weingchicken.com](https://weingchicken.com/177)
> (동일 내용이 [ordsearch.net 특성포인트 얻기](https://ordsearch.net/tips/1) 페이지에도 있는 것으로 검색 스니펫에서 확인되나, 해당 페이지는 403으로 직접 열람은 못 함)

즉 원작 기준으로는:
- "펑크해저드" = 스토리존의 스토리 10 (일반 스토리와 동일하게 격파 대상, 문이 아님)
- "정의의 문을 부수는" 오브젝트 = 위치가 **에니에스 로비**로 명시돼 있고, 맵 **우측**에 있음. 부수면 3명의 원수(아카이누·아오키지·키자루)가 등장, 처치 시 **특성포인트 1점** 지급 [원작]

우리 게임은 이 둘을 "펑크해저드 정의문"으로 합쳐서 만든 것으로 보이는데, 이게 사용자의 의도적 재구성인지 원작 조사 과정에서 착오가 있었는지는 **미확인**. PM/사용자에게 확인 필요.

## 1. 정의문을 부수면 무슨 일이 일어나는지

- **[원작]** (단, "펑크해저드"가 아니라 "폐문(에니에스로비)" 기준) 부수면 **보스 3명(아카이누, 아오키지, 키자루)이 등장**하고, 이들을 처치하면 **특성포인트 1점**을 얻는다.
  출처: [weingchicken.com/177](https://weingchicken.com/177)
- 보상/개방 형태가 골드·목재·위습 같은 일반 자원인지, 특성포인트 같은 별도 시스템(우리 게임엔 "특성포인트" 개념 자체가 없음)인지는 우리 게임 설계와 안 맞을 수 있음 — **판단 필요**.
- 그 외 이벤트(구역 개방, 새 지형 등)에 대한 원작 서술은 **[미기재]**.

## 2. 언제 부술 수 있는지

- 라운드 조건, 시간 조건: **[미기재]**. "50라운드 이후 미션유닛 중 피카를 처치하면 특성포인트 획득" 같은 라운드 조건부 요소는 있으나, 이는 폐문과 별개의 특성포인트 획득 경로로 보임 [원작, 출처 동일: weingchicken.com/177 검색 스니펫].
- 특정 유닛이 필요한지: **[추정]**. "모건" 유닛이 "문건"이라는 별명이 붙을 만큼 **정의의 문을 빠르게 부순다**는 서술이 있음 — "'문건'이라는 별명이 있을 정도로 정의의 문을 굉장히 빠르게 부술 수 있어서 나온다면 온갖 미션을 빠르게 마무리할 수 있다" [원작]
  출처: [원피스 랜덤 디펜스 - 나무위키](https://namu.wiki/w/%EC%9B%90%ED%94%BC%EC%8A%A4%20%EB%9E%9C%EB%8D%A4%20%EB%94%94%ED%8E%9C%EC%8A%A4)
  이 서술은 "정의의 문을 부수는 것 자체가 시간이 걸리는 일반 몹처럼 취급되는 미션 콘텐츠"라는 뜻으로 읽히지만, 부수는 조건(체력? 방어력? 특정 라운드에만 등장?)은 **[미기재]**.

## 3. 문 뒤에 뭐가 있는지

- **[원작]** 폐문(에니에스로비) 뒤에는 **보스 3명(아카이누·아오키지·키자루)**이 있다. 출처: 위 weingchicken.com/177
- "펑크해저드" 자체 뒤에 뭐가 있는지(스토리로서의 펑크해저드 격파 시 지급물): **[원작]** "펑크해저드 격파시 초월위습 대신 초월쿠마 지급" — 즉 일반 스토리 클리어 보상(초월 등급 위습) 대신 "초월쿠마"라는 특수 아이템/유닛을 준다는 의미로 읽힘. 출처: [나무위키 원피스 랜덤 디펜스](https://namu.wiki/w/%EC%9B%90%ED%94%BC%EC%8A%A4%20%EB%9E%9C%EB%8D%A4%20%EB%94%94%ED%8E%9C%EC%8A%A4)
  - "초월쿠마"가 정확히 뭘 하는 아이템인지, 쿠마 계열 유닛 조합 재료인지는 **[미기재]** (문서 검색 스니펫엔 "쿠마 초월을 이용해 만들 수 있는 유닛군이 있다"는 언급만 있음, 상세 미확인).

## 4. 초록/빨강 두 구역으로 나뉜 이유

- **[미기재]**. 나무위키·weingchicken·ordsearch 어디에도 펑크해저드(또는 폐문)가 초록/빨강 두 구역으로 나뉜다는 서술을 찾지 못함.
- 원작 원피스 만화의 펑크해저드 편은 지형이 "얼음 지대(북쪽)"와 "화염/독가스 지대(남쪽)"로 나뉘는데(뇌전대 유폐된 카쿠섬·시노쿠니 등), 이건 만화 원작 지리 설정이지 게임(원랜디)의 시스템으로 확인된 바는 아님. 색상이 초록/빨강이라는 것도 만화 설정과 직접 대응되지 않음 — 이 항목은 **추측조차 근거 박약**이라 [미기재]로만 남김.

# 사용자 확정 (2026-09-01)

조사에서 원작의 `펑크해저드`(스토리 10번)와 `폐문(에니에스로비)`이 별개라는 게 밝혀졌고,
사용자에게 확인한 결과:

| 항목 | 확정 내용 |
|---|---|
| 우리 "정의문"의 정체 | **원작의 폐문(에니에스로비)** 이 맞다 |
| 접근 조건 | **비행 또는 텔레포트 능력이 있는 유닛만** 갈 수 있다 |
| 공격 방식 | 도착하면 **자동으로 문을 공격**한다 |
| 보상 | 미정 — 원작은 특성포인트인데 우리 게임엔 그 개념이 없다 |

> 접근 조건은 이미 지형으로 성립한다. 펑크해저드 섬은 바다로 둘러싸여 있고
> `UnitSpawner.ComputeAreaMask`가 지상 유닛의 areaMask에서 Sea 영역을 뺀다.
> 즉 **날거나 물 위를 걷는 유닛만 도달할 수 있다.**

- 초록/빨강 구역 구분 의미 (원작 근거 없음 — 새로 정해야 함)
