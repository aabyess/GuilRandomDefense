## 왜 우리 표 3종에서 0건이었나 — **채널이 하나 더 있었다**

PM의 의심이 맞았습니다. 우리 피해표 3종은 전부 **유닛의 `uabi`(보유 능력 목록)에서 출발**해 훑었습니다.
그런데 이 8개는 **유닛이 처음부터 들고 있지 않습니다.** `T_Ability_hero` 트리거가 **런타임에 `UnitAddAbilityBJ`로 붙입니다.**

```
call UnitRemoveAbilityBJ(GetSpellAbilityId(),GetTriggerUnit())
call UnitAddAbilityBJ('A10S',GetTriggerUnit())      ← 여기서만 등장
call UnitRemoveAbilityBJ('A0I3',GetTriggerUnit())   ← 기본 능력을 떼고
set udg_Law_Bool[...]=true                          ← 불리언을 켠다
```

→ **`uabi` 스캔으로는 영원히 안 잡힙니다.** 이게 「능력교체」 8건이 통째로 빠진 이유입니다.

### 그리고 더 중요한 것 — **불리언 게이트 채널**

`A10S`와 `A107`은 **능력 ID로 검색해도 피해가 안 나옵니다.** 능력을 붙일 때 켜는 **전역 불리언**이 진짜 게이트입니다:

| 능력 | 켜는 불리언 | 그 불리언을 읽는 곳 |
|---|---|---|
| A10S | `udg_Law_Bool[플레이어]` | `war3map.j:16008` — 평타 트리거가 기본판/강화판을 분기 |
| A107 | `udg_NamiT_Bool[플레이어]` | `war3map.j:17038`, `:17058` — 스킬 트리거 안에 추가 블록 |

**이건 지금까지 우리가 판 어느 채널에도 없던 5번째 채널입니다.**
(기존: ①1채널 `uabi`+w3a · ②2채널 트리거+더미 · ③절대쿨 버프 · ④`udg_HashAttack` 트리거등록)
→ **⑤ 불리언 플래그 채널**. 다른 특성에도 같은 방식이 더 있을 수 있으니 `T_Ability_hero`에서
`set udg_*_Bool[...]=true`를 켜는 지점을 전수 조사할 가치가 있습니다.

나머지 6건은 능력 ID로 직접 잡힙니다(`GetUnitAbilityLevelSwapped('A0JU',...)` 형태) — 다만
**그 조회가 「피해를 주는 분기」가 아니라 「피해를 다른 것으로 바꾸는 분기」**인 경우가 있습니다(A0JU).
