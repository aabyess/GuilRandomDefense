# 다단히트 118건 중 C형(가변 반복횟수) 조사 — 확정 1건, 전수는 못했다

조사: 리서치담당 / 2026-09-07, `MULTIHIT_INTERVAL_SPEC_2026-09-07.md`
후속. 118건(127개 트리거명) 중 C형(캐스터 스탯에 비례해 반복횟수
자체가 변하는 것)을 찾는다.

## 결론 — **정밀 신호로 확정된 건 `Tasigi_03` 1건뿐. 더 있을 수 있으나 이번 방법으로는 못 갈랐다**

## ① 확정 1건 — `Trig_Tasigi_03_Actions`(타시기 3번째 스킬)

```jass
function Trig_Tasigi_03_Func003Func002C takes nothing returns boolean
if(not(s__TrigVariables__get_integerB(GlobalTV)<(11+GetUnitAbilityLevelSwapped('Aamk',s__TrigVariables__get_unitA(GlobalTV)))))then
return false
endif
return true
endfunction
```
반복 상한 = **`11 + 캐스터의 Aamk 능력 레벨`**, 간격 0.10초, 타격당
400,000(단일) 또는 대상 최대체력×10%×(0.25+0.15×A11S레벨)(보스급
보정). **우리 자산은 `hitCount: 2`** — `SkillData_게이트_..._타시기...`류
파일(정확한 파일명은 구현 쪽 확인 필요, 이번엔 값만 확인). 원작
최소 반복(레벨0 기준 11회)의 5분의 1 이하다.

## ② 방법과 한계 — 왜 "확정 1건"에서 멈췄나

**시도 1(정밀)**: 127개 트리거명 전체의 조건함수(`_FuncXXXC`)를
훑어 `GetUnitAbilityLevelSwapped`/`GetHeroLevel`이 **반복횟수
비교식**(`카운터 < N+레벨` 꼴) 안에 있는지 직접 대조했다. **28개
트리거가 이 두 함수 중 하나를 어딘가에서 쓰지만, 반복횟수 비교식
안에 있는 건 `Tasigi_03` 하나뿐이었다** — 나머지는 `tahsigi`의
`GetUnitAbilityLevelSwapped('A0B7',...)==2`처럼 **단순 상태/티어
체크**(예: "이 폼인가 아닌가")였지 반복 상한이 아니었다.

**시도 2(넓은 휴리스틱)**: "`if Stage==N` 블록 안에 `SleepForStage(...,N)`(같은 N)이
있으면 자기 자신에게 되돌아가는 루프"로 39개 후보를 걸러냈다. **그런데
표본 확인(`Higma_Q`·`Minato_Q2`) 결과 이 후보 다수가 실제로는 "발사체가
0.02초 간격으로 위치를 갱신하며 날아가는 이동 애니메이션"(스테이지
10~33개, 각각 위치만 갱신)이었지 **반복 피해**가 아니었다 — **이
휴리스틱은 오탐이 너무 많아 신뢰 못한다.** 정규식으로 "이 반복이
`RRD`를 담고 있는지"까지 정확히 걸러내려면 각 함수의 중첩 구조를
제대로 파싱해야 하는데, 이 맵의 JASS가 `_FuncXXXC`류 헬퍼 함수로
조건을 잘게 쪼개놔서 텍스트 근접성만으로는 안 갈린다.

## ③ 결론 — PM 판단에 필요한 사실만

- **확정 C형: 1건**(`Tasigi_03`). 이 1건은 **hitCount가 지금
  고정값으로 틀려 있는 게 확실**하다 — 개별 수정이 필요하다(PM
  판단대로, 이건 축을 새로 만들 정도는 아니고 "이 건만 고치면
  되는" 규모로 보인다, 지금까지 찾은 걸로는).
- **나머지 117건 중 몇 건이 C형인지는 이번 방법으로 못 갈랐다** —
  정밀 신호(레벨스케일링이 반복상한에 직접 들어감)로는 0건
  추가, 넓은 휴리스미(자기루프 39건)는 오탐이 너무 많아 신뢰
  못한다. **"1건뿐이다"라고 단정하지 않는다 — "이번 방법으로 찾은
  건 1건"이라고만 말한다.**
- 전수(118건 각각을 손으로 열어 중첩 구조까지 확인)를 하면 더
  나올 수 있다 — 이번엔 시간상 못했다.

## 남은 것

- 117건 전수를 손으로(또는 더 정교한 파서로) 열어 C형을 마저
  찾는 작업 — `[미확인]`.

  정확한 파일명 확인 — 이번엔 값 확인만 하고 파일 대조는 안 함.
