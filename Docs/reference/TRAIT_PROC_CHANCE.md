# 특성 대상 26종의 발동 확률 — 전수 (2026-09-05, 리서치담당)

> **결론**: **26종 전부 게이트가 있다. 「매 타 발동(100%)」은 0종이다.**
> 지금 우리 `triggerChance: 1`(100%)은 **26종 전부 틀렸다.**
> 표: `Docs/reference/ORIGINAL_TRAIT_PROC_CHANCE.csv` (78행 · `번호·유닛ID·이름·트리거·게이트원문·확률·유형·등장횟수·비고`)

게이트는 **두 종류**다.

| 유형 | 건수 | 뜻 |
|---|---|---|
| **확률 게이트** | 54 | `GetRandomInt(1,N)==k` 또는 `GetRandomReal(1,100)<=X`. **1/80 ~ 1/2**로 폭이 넓다 |
| **게이지 누적** | 24 | 마나·체력이 **평타마다 +1**, 임계값 도달 시 발동. **확률이 아니라 결정론적 N타 주기** |

## ⚠️ 「게이지 누적」이 이번의 핵심이다

원작 코드가 이렇게 생겼다(쵸파):

```jass
if GetUnitStateSwap(UNIT_STATE_MANA,GetAttacker())==150.00 then
    call IssueImmediateOrderById(GetAttacker(),String2OrderIdBJ("metamorphosis"))
else
    call SetUnitManaBJ(GetAttacker(),(GetUnitStateSwap(UNIT_STATE_MANA,GetAttacker())+1))
endif
```

**마나가 평타 1회당 정확히 1씩 오르고, 150에 닿으면 발동한 뒤 0으로 돌아간다.**
즉 **「150타마다 정확히 1회」**다 — 확률이 아니다.

> 🚨 **`1/N` 확률로 넣으면 기댓값은 같지만 분산이 다르다.**
> 원작은 **35타째에 반드시** 터지고, 확률로 바꾸면 **100타 동안 안 터질 수도** 있다.
> 「가끔 강하게」가 아니라 **「정확히 주기적으로」**가 원작의 감각이다.

## 특성이 **확률 자체를 바꾸는** 경우 — 검은수염

```jass
if GetRandomInt(1,10)==5 then
    if GetRandomInt(1,udg_Tichi_TR_AddInt[플레이어])==3 then  → 강화판 Tichi_skill_4_tr
    else                                                    → 기본판 Tichi_skill_4
```

`udg_Tichi_TR_AddInt`는 **맵 시작 시 6**, **특성을 사면 3**이 된다(`InitGlobals`에서 `[i]=6`, 특성 분기에서 `=3`).

| | 강화판 진입 | 전체 |
|---|---|---|
| 특성 전 | 1/6 | 1/10 × 1/6 = **1/60** |
| 특성 후 | **1/3** | 1/10 × 1/3 = **1/30** |

**즉 검은수염 특성의 실체는 「강화판 발동 확률 2배」다.**
④ 보고에서 「값 차이가 없어 우리 축 밖」이라고 적었는데 **정정한다 — 차이는 확률 축에 있었고 우리 스키마에 담긴다.**

## 레벨 조건과 확률이 **함께** 걸리는 경우 — 후지토라 운석

```jass
if GetUnitAbilityLevelSwapped('A0GR',…)==2 then      ← 특성(레벨 2)
    if GetRandomInt(1,4)==3 then → Huji_meteor       ← 그 안에서 다시 1/4
```

`Huji_02` 자체가 평타에서 **1/24**로 도니, **운석 최종 = 1/24 × 1/4 = 1/96**이다.
표에는 두 게이트를 **갈라서** 적었다.

## 확률 게이트 분포 (54건)

가장 흔한 것이 **1/10(10%)**, 다음이 1/8·1/14·1/7·1/24다.
극단은 **루피 1/80**과 **시키 1/2**이고, 시키는 `1/10 × 1/16`, `1/10 × 1/33 × 1/2` 같은 **곱 게이트**를 쓴다(표에 각각 따로 적었다).
`GetRandomReal(1,100)<=7.25` 꼴(루치)은 **6.313%**로 환산했다 — `GetRandomReal(1,100)`은 하한이 1이라 단순 7.25%가 아니다.

## 조사 범위 공개

- 26종 **전수**. 각 유닛의 `udg_HashAttack` 등록 트리거 본문에서 게이트를 전부 뽑았다(등장 횟수도 표에 있다).
- **한 유닛의 트리거에 게이트가 여러 개인 것이 정상이다** — 스킬이 여럿이기 때문이다. 표는 **게이트 하나마다 한 행**이라
  「이 유닛의 어느 스킬이 어느 게이트냐」의 1:1 대응까지는 안 했다 `[미확인]`.
  특성 대상 스킬만 필요하면 `TRAIT_LEVEL2_SOURCES.md`의 트리거 이름과 대조해야 한다.
- 게이지형의 **발동 후 리셋 값**(0으로 돌아가는지)은 샹크스·쵸파 등 몇 개만 확인했다 — 전수는 아니다 `[미확인]`.
