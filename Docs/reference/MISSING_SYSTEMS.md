# 원작에 있는데 우리에겐 없는 것 — 전수 감사 (2026-09-04, 구현담당1)

> PM 요청: 원작(원랜디)에 있는 시스템 중 우리 게임에 전혀 없는 것의 완전한 목록. 하나씩 발견될
> 때마다 설계가 흔들리는 상태를 끝내려는 것 — "부분적으로 몇 개 더 있다"가 아니라 "이게 전부다"를
> 만드는 게 목적이다.
>
> **방법**: ① 기존 `Docs/reference/`·`Docs/design/` 전수를 훑어 "우리에겐 없다" 언급을 긁어모으고,
> ② 그 하나하나를 **지금 코드**로 직접 확인해 문서가 틀렸는지 검증하고(문서가 낡아서 "없다"고 했는데
> 실제로는 생긴 경우가 이 프로젝트에서 여러 번 있었다 — 예: 500엔 도박 해금, 방어력 시스템 전체),
> ③ ①②로 안 잡히는 것만 최소한으로 웹 조사했다. 각 행에 근거가 어느 단계에서 나왔는지 표시한다.
>
> 표기: **[문서]** = 기존 조사 문서 인용(①) / **[코드]** = 이번에 직접 코드로 확인(②) / **[웹]** = 이번에 새로 조사(③).
> 확신도: **높음**(여러 출처 교차확인 또는 코드로 확정) / **중간**(검색엔진 요약, 원문 미대조) / **낮음**(정황·추정뿐).
> **모르면 모른다고 적었다** — 추측을 사실처럼 적은 곳은 없다.

## 요약 — 가장 중요한 5개

1. **기여도(Contribution) 추적이 아예 없다** — 스토리 30% 기여도 보상, 보스 최다딜 보상, 도전과제 보상**셋 다** 이거 하나가 없어서 못 만든다. 코드가 스스로 "안 만들었다"고 적어 둔 유일한 항목이라 확신도가 가장 높다.
2. **세이브(누적 게임클리어) 시스템이 없다** — `CombineRecipe.requiredSaveCount`가 검사되지 않아 **영원 등급 조합 일부가 원작 조건을 못 건다**(지금은 그냥 통과됨). 특성포인트 8갈래 중 "누적 세이브 15/20/25회" 갈래도 이것에 걸려 있다.
3. **경험치/레벨업이 없다** — 해왕류 보상이 경험치인데 우리는 그 자원 자체가 없다. 원작은 이게 유닛 하나마다 붙는 힘/민첩/지능 스탯업 시스템이라 생각보다 크다(이번에 새로 확인).
4. **게임 모드(일반/변질됨/초고속) 선택이 없다** — 500엔 도박과 보물찾기 **둘 다** 이 개념에 게이트돼 있다. 이미 500엔 도박은 "10라운드 보스 처치"로 대체 조건을 확정했지만, 보물찾기는 아직 미정이고 원작에서 **같은 트리거(10라운드 보스)를 공유했을 가능성**이 새로 확인됐다.
5. **마법방어력이 없다** — 물리방어(`EnemyDummy.armor`/`ArmorShred`)는 이미 구현됐지만, 조합표의 `마방깍오라` 능력이 깎을 대상(별도의 마법방어 수치)이 없다. **설계 문서가 스스로 "일부러 뺐다"고 명시**한 유일한 항목이다.

## 조사 방법 메모

- **①(문서 스크랩)이 목록의 절반 이상을 채웠다.** `ORIGINAL_VS_OURS.md`(26항목 대조표)와 `UPGRADE_SHOP.md`(1~4차)·`ARMOR_SYSTEM_DESIGN.md`·`UNIT_STATS_RESEARCH.md`·`EVENTS_RESEARCH.md`·`ACQUISITION_RESEARCH.md`·`ROUNDS.md`·`ORIGINAL_GAME_RESEARCH.md`(§1~12)가 이미 방대하게 조사돼 있었다.
- **②(코드 검증)에서 실제로 문서-코드 불일치를 찾았다** — `ARMOR_SYSTEM_DESIGN.md`가 "설계안, 아직 구현 안 함"이라고 적어 둔 방어력 시스템이 실제로는 이미 `EnemyDummy`/`DamageTable`로 구현돼 있었다(2026-09-03 커밋). PM이 우려했던 "있는데 없다고 적힌 경우"가 이번에도 하나 나왔다 — 문서를 안 믿고 코드를 직접 읽길 잘했다. 반대로 "기여도 추적"·"폐문 보상"처럼 코드가 스스로 "안 만들었다"고 인정한 것도 확인했다.
- **③(웹 조사)은 최소로 했다** — ①②가 이미 방대해서, 이번엔 딱 두 가지만 새로 검색했다: 경험치/레벨업 시스템의 정체(힘/민첩/지능 3스탯 구조라는 걸 새로 확인), 조합의 "채팅 명령어" 입력 방식이 실제 메커니즘인지(확인됨 — Hidden 한정이 아니라 원작 조합 전체의 표준 인터페이스). `ordsearch.net`은 이번에도 시도 안 함(다른 세 조사자가 이미 403을 반복 확인함).
- **빠뜨린 게 있을 수 있는 영역**: 원작 자체가 서비스 종료 3년 가까이 됐고, 커뮤니티 문서화가 파편적이라는 게 모든 기존 조사의 공통 결론이다. 이 문서도 "기존 조사가 닿은 범위 + 오늘 확인한 것"의 합집합이지, 원작 전체를 새로 훑은 게 아니다 — 특히 **와포루·거프**처럼 이름조차 못 찾은 것은 이 문서로도 못 뚫었다.
