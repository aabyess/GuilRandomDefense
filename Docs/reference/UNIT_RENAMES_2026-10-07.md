# 유닛 이름 바꾸기 19기 (사장님 10-07, 웹 이름표)

규칙(사장님 확정): 새 이름이 **한 단어 = 앞 인물 이름만 바꾸고 칭호 유지**, **띄어 쓴 두 단어 = 인물+칭호 전체 교체**.
에셋(파일) 이름은 그대로(GUID·대응표·세이브 키). 인물 이름 = `UnitData.personOverride`(새 필드, 맨 뒤), 칭호 = `unitName`.
히든 5명은 이름이 곧 칭호라 `unitName`과 `personOverride`가 같다(한 번만 보임). 적용: `call UnitRenameApply.Apply`(Editor, 다시 불러도 안전).
⚠️ `Tools/low_grade_data.py` 등 생성기(옛 이름 키)를 다시 돌리면 로스터가 옛 이름으로 되돌아간다 — 생성기는 돌리지 말 것(돌리면 `UnitRenameApply.Apply` 재실행).
