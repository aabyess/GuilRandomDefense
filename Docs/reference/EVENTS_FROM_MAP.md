구현담당3·1이 어제 "이름조차 못 찾아서 원랜디 콘텐츠가 아닐 수도 있다"고 남긴 질문에 **확정 답**: **둘 다 실제로 있다.** 위 공통 패턴 표에 전부 정리했다. **거프 관련해서 덤으로**: 채팅 명령어(`"해군영웅거프"`/`"garp im"`)로 발동하는 **별도의 컷신성 트리거(`IM_garp1`)**도 있는데, 이건 60초 퀘스트와 무관한 **디버그/이스터에그성 트리거**로 보인다(거프·센고쿠 대사만 재생, 근처 유닛 제거) — 정상 플레이 콘텐츠인지는 불명확하다.
