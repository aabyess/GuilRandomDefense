# 게이트 1:1 대조 — 전설적인·제한됨·초월함·불멸·영원함 (2026-09-06, 구현담당1)

PM 지시 — 5등급 스킬 게이트를 파일에 인용된 원작 원문과 대조. 방법: 우리
생성기들이 게이트를 옮길 때 원작 원문을 description에 그대로 인용해 둔다
(`게이트 "..."` 자리) — 그 인용문을 다시 파싱해서 실제 저장된 필드
(triggerType·triggerChance·gaugeKind·hitCountThreshold)와 대조했다. 외부 CSV를
다시 매칭하는 것보다 이쪽이 더 정확하다(매칭 실수가 없다 — 파일이 자기 자신의
근거와 비교되는 것이라서).

## 결과 요약

- **원작 게이트 인용문이 있는 85건 — 불일치 0건.** 우리가 게이트를 "알고" 옮긴
  자리는 전부 정확했다. (⚠️ 처음엔 정규식이 `9.5e-05`(과학적 표기) 같은 값을
  "9.5"로 잘못 잘라 읽어 가짜 불일치 1건을 냈다 — 파일을 직접 열어 원본 계산이
  맞다는 걸 확인하고 정규식을 고쳤다.)
- **원작 게이트 인용문이 아예 없는 92건** 중 **14건**이 "효과는 있는데
  triggerChance=1.0(매 타)"였다 — 전부 **2채널(ORIGINAL_SKILL_DAMAGE_TABLE.csv)**
  경로다. 이 CSV 자체에 애초에 게이트 컬럼이 없다(구조적 한계, 개별 행 실수가
  아니다) — 그래서 그 채널이 만든 모든 효과가 예외 없이 "매 타 발동"으로
  근사됐다.
- **초월함은 이 14건에 0개다.** 초월함의 100%-발동 파일은 전부 06번① 특성
  스텁(효과 자체가 비어 있어 화력에 영향 없음, `EMPTY_EFFECTS_AUDIT.md`) 또는
  절대쿨(의도된 메커니즘, 버그 아님)뿐이었다 — **초월함의 "너무 빡빡함"은 이
  메커니즘으로는 설명되지 않는다.**

| 등급 | 2채널발 "매 타 근사" 건수 |
|---|---:|
| 전설적인 | 8 |
| 제한됨 | 2 |
| 불멸의 | 2 |
| 영원한 | 2 |
| 초월함 | **0** |

**PM이 예측한 방향과 맞다** — 전설적인·제한됨·불멸·영원함은 이 메커니즘 때문에
"헐거워질 수 있는" 자리를 갖고 있고, 초월함은 없다. 다만 불멸·영원함의 실측
헐거움(8.6배·14.65배)이 전설적인(2.34배)보다 훨씬 큰데 건수는 비슷하거나 더
적다 — **로스터가 작을수록(불멸·영원함 8종) 소수의 고피해 스킬이 평균을 크게
끌어올린다**는 뜻일 수 있다(개별 스킬 크기 확인은 후속 조사 필요).

## 조치

**14건 전부 description에 `[미확인: 원작 게이트]` 꼬리표를 달았다** —
PM 지시대로 "1.0으로 두되 미확인 표시 없이 방치"하지 않기 위해서다. 값은 안
바꿨다(추측으로 채우면 창작이 된다) — `Docs/reference/GATE_MISMATCH_2026-09-06.csv`
에 유닛·파일·방향과 함께 목록으로 남겼다.

## 못 한 것 — 실제 원작 게이트 역추적

이 14건의 트리거명(`Trig_Legend0`·`Trig_Legend23`·`Trig_Z_Attack` 등)을
`DUMMY_CHANNEL_GATES.csv`(부모트리거)와 `ORIGINAL_UNLISTED_SKILL_EFFECTS.csv`
(스킬트리거) 두 곳에서 찾아봤지만 **전부 매칭 실패** — 이 두 CSV가 커버하는
트리거 집합 밖이다. **이 14개는 아직 아무 데도 게이트가 연구되지 않은
트리거들**이다 — 내가 가진 자료로는 못 채운다. 리서치담당이 war3map.j에서
직접 이 14개 트리거명을 찾아야 실제 값을 넣을 수 있다.

## 참고 — 초월함의 "너무 빡빡함"은 왜인가(이번 조사에서 새로 안 것 없음)

이번 대조로는 초월함 쪽 원인을 못 찾았다 — 이미 문서화된 두 가지
(`TRANSCENDENT_DAMAGE_INVESTIGATION_2026-09-06.md`)만 남아 있다: 06번①
빈 스텁(화력 0, 발동률과 무관) · 히어로 비례항 소거(레벨 축은 `CasterSkillLevel`
로 일부 복구됨, 스탯 축은 사장님 판단 대기). OnHitCount 게이지 평균 임계값이
초월함(112)이 전설적인(80.5)보다 높고 게이지형 비중도 더 크다(37% vs 13%)는
분포 차이는 확인했지만, 이게 원작 대비 "옳게 옮겨진 결과"인지 "우리가 조인
결과"인지는 게이트 인용문 대조(위)에서 **불일치가 0건**이었으므로 — 있는 만큼은
원작 그대로 옮겨진 것으로 보인다. 즉 **초월함이 빡빡한 건 우리가 잘못 옮겨서가
아니라, 원작 자체에 게이지형(OnHitCount) 스킬이 많고 임계값이 크게 설계돼
있어서일 가능성이 높다** — 이 부분은 원작 원문과의 추가 대조가 필요하다.
