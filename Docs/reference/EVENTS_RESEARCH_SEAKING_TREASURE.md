# 해왕류·보물 조사 (2026-09-03, 구현담당2 — 리서치담당 요청으로 대신 조사)

> 조사 방법: 나무위키 "원피스 랜덤 디펜스" 문서, 디시인사이드 마이너 갤러리(ordc1) WebFetch.

## ① 해왕류

### 무엇인가 / 어디 있는가
- **[원작]** "맵 왼쪽에 위치"한다. 나무위키 문서 본문에서 "맵 왼쪽의 해왕류, 에니에스 로비를 부수면 등장하는 삼대장도 경험치를 주니"라는 서술로 확인.
  출처: [원피스 랜덤 디펜스 - 나무위키](https://namu.wiki/w/%EC%9B%90%ED%94%BC%EC%8A%A4%20%EB%9E%9C%EB%8D%A4%20%EB%94%94%ED%8E%9C%EC%8A%A4) (WebFetch 요약, 원문 문단 위치 미확인 — 재확인 필요)
- **[원작]** 게임 내 "미션" 요소로 존재하며, 여러 미션을 클리어해주는 유틸성이 있다고 함(어떤 미션인지는 [미기재]).
  출처: WebSearch 결과 요약(나무위키 기반으로 추정되나 특정 URL 문단 미확정)

### 언제 나오는가
- **[미기재]** — 특정 라운드/스토리 진행 조건은 못 찾음. "게임 진행 중 특정 시점"이라는 서술만 있고 정확한 라운드/트리거는 확인 못함.

### 잡는 방법 — 접근 제한이 있다
- **[원작]** "순간이동, 공중이동, 바다이동 능력을 가진 유닛만 해당 지역에 갈 수 있다" — 펑크해저드 정의문(에니에스로비)과 같은 접근 제한 방식으로 보임(우리 게임의 `UnitSpawner.ComputeAreaMask`가 지상 유닛 areaMask에서 Sea를 빼는 것과 정확히 같은 패턴).
  출처: 나무위키 문서 WebFetch 요약

### 보상
- **[원작]** 격파하면 **경험치**를 획득한다.
  출처: 나무위키 문서 WebFetch 요약
- **[정정, 재조사 결과]** 처음엔 "2단계 크립 보상"을 해왕류가 직접 주는 것처럼 요약됐는데, 재조사 결과 **"크립"은 해왕류와 별개의 시스템**이다 — 스토리 맵 아래쪽에 있는 별도의 특수 몹으로, 1/2/3단계로 나뉘고 각 단계마다 보상이 다르다:
  - 1단계: 목재1개 + 소량의 골드
  - **2단계: 목재7개, 또는 목재3개+"해적선"(숨겨진 유닛, 초월 위습 다음으로 가치 있는 것으로 서술됨)** — 그래서 2단계 크립이 가장 우선순위 높은 처치 대상으로 꼽힘
  - 3단계: 역시 목재와 골드
  - 잡으려면 **블링크 거리 1500 이상 / 공중 이동 / 사거리가 긴 유닛**이 필요 — 해왕류의 "순간이동·공중이동·바다이동 유닛만 접근 가능"과 유사한 접근 제한 패턴이지만, **동일한 대상이라는 근거는 없다**(원문에 해왕류와 크립을 직접 연결한 서술 없음).
    출처: [공략)크립 따는 방법 정리 - ordc1](https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=7820) [원작]
  - "해왕류를 잡으면 크립도 얻는다"는 초기 요약은 **부정확했다** — 두 시스템이 근처(스토리맵 인근)에 있고 접근 조건이 비슷해서 뭉뚱그려 설명됐을 가능성이 있다. **해왕류 자체의 직접 보상은 여전히 "경험치" 하나만 확인됨.**
- **[원작]** 경험치는 워크래프트3 원작 그대로 **레벨업 시스템**으로 이어진다 — "경험치를 모으면 자동으로 레벨이 오르고, 일정 레벨마다 힘/민첩/지능이 오르고 스킬을 획득한다"는 서술 확인.
  출처: WebSearch 요약(나무위키 기반으로 추정)
- 우리 게임엔 "경험치"도 "유닛 레벨업"도 개념 자체가 없다(유닛은 가챠·조합으로만 얻고 스탯 고정) — **판단 필요**: 해왕류 보상을 어떤 자원(골드/목재/위습)으로 대체할지는 전적으로 새로 정해야 하는 설계 문제, 원작에서 가져올 수 있는 게 없다.

### 안 잡으면 어떻게 되는가
- **[미기재]** — 직접적인 페널티 서술은 못 찾음.
- 다만 **[원작]** "무단으로 잡으면 팀원들에게 욕을 먹을 수 있다"는 서술이 있음 — 이건 게임 시스템이 아니라 **커뮤니티 매너 관습**(잡기 전에 라인별 플레이어에게 알려야 한다)으로 보인다. 에니에스로비(정의문) 격파도 경험치를 준다는 점에서, "해왕류·에니에스로비 모두 팀 전체가 나눠 갖는 경험치원이라 독단으로 잡으면 안 된다"는 맥락으로 읽힘.
  출처: 나무위키 문서 WebFetch 요약(원문 재확인 필요 — 아래 "미확인/재검증 필요" 참고)

## ② 보물

### 획득 방법
- **[원작]** "탐색"을 통해 발견되는 것으로 보인다 — "보물 찾기"라는 표현이 확인됨.
  출처: 나무위키 문서 WebFetch 요약

### 특수 모드와의 연관 — "초고속" 모드
- **[원작]** "초고속" 게임 모드에서는 "모든 플레이어가 탐색도구 아이템을 기본으로 지급받고 시작하며, 보물이 1라운드부터 생성되어 탐색할 수 있다"는 서술 확인. 이는 곧 **일반 모드에서는 탐색도구가 기본 지급이 아니고, 보물도 1라운드부터 바로 나오지 않는다**는 뜻으로 읽힌다(대조 서술이라 반대 상황이 일반 모드일 것으로 추정 — **[추정]**).
  출처: 나무위키 문서 WebFetch 요약
  - 참고: GAMBLING.md 4차 조사에서도 "초고속 모드"가 500엔 도박 해금 조건으로 별도 확인된 바 있다 — 원작은 "초고속"이라는 별도 게임 모드가 여러 시스템(도박·보물)의 해금을 동시에 여는 구조로 보인다. 우리 게임엔 모드 선택 개념이 없다(GAMBLING.md에서 이미 지적됨).

### 나미(초월)와의 연관 — 보상 배율
- **[원작]** "하위 패인 나미 전설 효과로 보물 찾기 보상이 두 배가 되고"라는 서술 확인 — 특정 유닛(나미 계열, "전설" 등급으로 보임)을 보유하면 보물 보상이 2배가 되는 효과가 있다.
  출처: 나무위키 문서 WebFetch 요약
  - "하위 패인"이 무슨 뜻인지는 **[미기재]**(오타 가능성, "하위 패시브인" 정도로 추정 — **[추정]**).

### 여는 조건 / 우연인지 정해진 시점인지 — 일반 모드 조건 확인됨
- **[원작]** **"10라운드 보스를 잡은 후 F1번을 눌러 100초마다 보물 탐색을 할 수 있다"** — 일반 모드(초고속 아닌) 기준 조건으로 보인다. 즉 (1) 10라운드 보스 처치가 선행 조건, (2) F1 단축키로 플레이어가 직접 실행하는 능동적 행동, (3) 100초 쿨타임이 있는 반복 가능 행동. **우연이 아니라 정해진 시점(10라운드 보스 이후)부터 플레이어가 주기적으로 발동하는 방식**이다.
  출처: WebSearch 요약(나무위키 기반으로 추정, 원문 문단 위치 미확인 — 재확인 권장)
  - 우리 게임의 GAMBLING.md 500엔 도박 해금 조건("10라운드 보스 처치 시 활성화")과 **정확히 같은 트리거 조건**이다 — 원작에서도 10라운드 보스가 여러 시스템(도박·보물)을 동시에 여는 공용 게이트였을 가능성이 있다.
- **[미기재]** — 탐색 자체의 성공 확률, 정확한 UI/조작 방식(F1을 누르면 무슨 일이 일어나는지)은 못 찾음.
- **[미기재, dcinside 미해결]** 탐색 가능 "범위"에 대해 커뮤니티에서도 의견이 갈렸다 — "초록색 빗금 부분(더 넓은 범위) 전체에서 등장하는지, 주황색 빗금의 '크립존'에서만 등장하는지" 질문하는 글이 있었으나 **답변이 없어 미해결**로 남아있다. 이 스레드는 "크립존"이 지도상 특정 구역으로 별도 표시된다는 것과, 보물 탐색 범위가 그와 겹치거나 인접해 있을 가능성을 시사한다.
  출처: [보물 탐색 범위 정확하게 어디임? - ordc1](https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=50889)

### 무엇을 주는가
- **[미기재]** — "보상"이 정확히 자원/위습/유닛 중 무엇인지 구체적 서술은 못 찾음. 다만 "나미 전설 효과로 보상이 두 배"라는 서술로 미루어 **수치화 가능한 자원(골드 또는 목재류)일 가능성이 높다** — **[추정]**(크립 보상이 목재/골드 위주였던 것과 유사한 패턴으로 추측).

### "아이템 도박 및 해왕류 드랍 확률" (120728) — 드랍 확률 확인
- **[원작]** 해왕류가 **아이템을 주는 확률 자체는 1/6(약 16.7%)** — 즉 해왕류를 잡아도 5/6 확률로 아이템이 안 나온다.
- **[원작]** 아이템이 나온다는 전제하에, 등급별 확률(이미지 기준, 총합 35.85로 정규화): **초월함 6.98% / 전설적인 18.55% / 희귀함 24.24% / 특별함 50.22%**. (이 표는 GAMBLING.md 4차 조사에서 "고도(목재4 유닛도박)와 안 맞는 별도 확률표"로 이미 발견된 바로 그 표다 — **이번 조사로 이 표의 정체가 "해왕류 아이템 드랍표"라는 게 확인됐다.** GAMBLING.md 쪽에 교차 반영 필요.)
- **[원작]** 특정 아이템("태양신의 흔적" 등 "니카 아이템") 하나를 뽑을 확률 예시: 약 3.49%. 해왕류에서 이 특정 아이템을 얻을 최종 확률 = 1/6 × 3.49% ≈ **0.58%**.
- **[원작]** 이 수치는 "버전 11.086 기준"이라고 명시됨 — 패치로 바뀔 수 있다는 단서가 원문에 있음.
- 이 확률표가 "아이템"(장비/소모품으로 보이는 별도 카테고리)에 대한 것이지, "유닛"이 나온다는 뜻은 아닌 것으로 보인다 — 우리 게임엔 "아이템" 카테고리 자체가 없어서(위습/유닛/자원뿐) **설계 판단 필요**: 해왕류가 우리 게임에서 아이템을 줄지, 위습이나 자원으로 대체할지.

### 우리 게임 설계에 필요한 판단 (조사로는 못 채우는 것 — 사장님 확정 필요)
1. 해왕류·보물 보상을 우리 게임의 어떤 자원(골드/목재/위습)으로 대체할지 — 원작의 "경험치·레벨업" 프레임이 우리 게임에 없어서 그대로 옮길 수 없다.
2. 해왕류·크립·보물탐색을 우리 맵의 어디에 배치할지(원작 "맵 왼쪽"·"스토리 맵 아래쪽"이 우리 맵의 어느 구역에 대응하는지는 별도 판단 필요 — 지금 우리 맵엔 물범(SealSpawner)·펑크해저드뿐).
3. "크립"을 우리 게임에 별도 시스템으로 만들지, 아니면 생략할지 — 원작엔 있지만 사용자가 아직 언급 안 한 개념이다.
