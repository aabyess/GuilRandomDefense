# 막힌 4종 + 제트 충돌 — 게이트가 어느 효과에 물리나 (2026-09-05, 리서치담당)

> **방법**: 평타 트리거를 **최상위 `if` 블록 단위로 잘라** 각 블록의 조건과 그 안의 효과를 1:1로 붙였다.
> 「같은 트리거 안에 있으니 같은 스킬」로 읽으면 전부 틀린다 — 실제로 제트·드래곤이 그 경우였다.

---

## ⚠️ 제트 `A09E` 충돌 — **둘 다 맞다. 별개 스킬 둘이다.**

`Trig_Z_Attack_Actions`는 **독립된 다섯 블록**이다:

| # | 게이트 | 효과 |
|---|---|---|
| 1 | 마나 게이지 **160** → 0 | `Z_Skill_Mana` |
| 2 | **시전자가 버프 `B00M` 보유** | **`Z_Skill_1` ← 여기가 `A09E`(차지 버스터)** |
| 3 | `GetRandomInt(1,10)==4` | 더미 `e03S` + `bloodlust`(버프, 피해 아님) |
| 4 | `GetRandomInt(1,16)==7` | `Z_skill_3` |
| 5 | **대상이 버프 `B06B` 보유** | **`RRD(대상 최대체력 × 0.025)`** |

- **`A09E`의 식은 `레벨×100,000 + 200,000`이 맞다**(`Z_Skill_1` 안, 레벨1 = 300,000 / 레벨2 = **400,000**).
  `Z_Skill_1`엔 그 값 외에 고정 **1,250,000**도 함께 있다.
- **`대상 최대체력 × 0.025`는 `A09E`가 아니다** — 5번 블록의 별개 효과이고, 게이트는 **대상이 `B06B` 버프를 가졌을 때**다
  (`B06B`는 신세계 광폭화 `A0VK`가 붙이는 버프다).
- **따라서 두 문서가 충돌한 게 아니라 서로 다른 스킬을 적은 것이다.**
- **제트의 확률 게이트 2개(1/10·1/16)는 둘 다 `A09E`와 무관하다.** `A09E`의 게이트는 **확률이 아니라 버프 보유**다.

→ 1/12 게이트는 이 트리거 밖(다른 스킬)이다.

### 시키 `h04B` / `A0T4` !함대

> ## 🚩 자체 정정 (2026-09-05, PM 대조) — **「확률 아님」이 틀렸다. 1/33이다.**
> `.j` 원문:
> ```jass
> if GetUnitAbilityLevelSwapped('A0T4',GetAttacker())==1 then
>     if GetRandomInt(1,33)==3 then      ← 진짜 게이트
> ```
> **능력 보유 검사 *안쪽*에 `1/33`이 있다.** 「능력 보유」는 모든 특성이 공통으로 갖는 레벨 검사일 뿐이고,
> **실제 발동률은 1/33 = 0.0303**이다.
> **원인**: 최상위 블록으로 자른 뒤 **그 블록 안쪽의 중첩 `if`를 다시 안 봤다.**

| 게이트 | 효과 |
|---|---|
| **`A0T4` 레벨==1 AND `GetRandomInt(1,33)==3` → 0.0303** | 더미 `h07R` ×2 ← `A0T4` 본체 |
| 마나 게이지 125 | `Shiki_Lion` — 별개 |
| `1/10==3` | 더미 `e026` — 별개 |
| `1/16==3` | `Shiki_champa2` — 별개 |
| `1/16==3`(두 번째) | `Shiki_SKill_item` — 별개 |

→ **시키의 확률 4개는 전부 `A0T4`와 무관하다.** 능력교체형이라 「능력 보유」 자체가 게이트다.
