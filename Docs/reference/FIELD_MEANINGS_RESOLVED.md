# 🔴 PM 경고 반영 — 필드 뜻과 실제 작동은 별개다

세 필드 전부 「피해 아님」으로 나왔으므로 **오더 검사까지 갈 필요가 없었다.**
만약 「피해였다」로 나왔더라도 **오더가 안 내려가면 안 도는 값**이므로 오더 검사를 통과해야 했다.
이 순서를 규칙으로 적어둔다:

```
1) 필드 뜻   — 형제 능력의 제작자 이름·툴팁으로 판정 (워3 지식 추측 금지)
2) atar      — 패시브류는 atar에 enemies가 있어야 돈다
3) 오더      — 시전형은 그 base에 맞는 오더가 실제로 내려가야 돈다
4) 게이트    — 그제서야 확률/게이지를 잰다
```

## 그리고 오더 검사 자체를 고쳤다 (앞서 예고한 건)

정규식이 창 안의 **첫 오더만** 잡고 있었다(`re.search`). `findall`로 고치고,
**오더 문자열이 그 능력의 base와 실제로 맞는지**까지 대조했다.

| | 이전 | **재검증** |
|---|---|---|
| 작동 | 36 | **31** |
| 작동 안 함 — 시각 이펙트 | 43 | **44** |
| 피해 아님 — 공격력 증가(`Nbr1`) | — | **4** |

**판정이 바뀐 3행** — 오더는 있는데 **같은 더미의 다른 능력**에게 갔다:

| 더미 | 능력 | 오더 | 실제 수신자 | 값 |
|---|---|---|---|---|
| `e01I` | `A0VA` (`ACca`) | `fanofknives` | **`A08J`**(`AEfk`) | 280,000 → 미발동 |
| `e01M` | `A088` (`AHtc`) | `firebolt` | **다른 더미 `e0K4`** | 300,000 → 미발동 |
| `e0NQ` | `A0OG` (`AHtc`) | `purge` | **`A10W`**(`Apg2`) | 350,000 → 미발동 |

→ **최종: 작동 31 / 미작동 44 / 피해아님 4.** 구현담당1은 **`실제작동 == "작동"`인 31행**만 이식하면 된다.

## 006 감마나이프 라벨 정정 (작은 것)

`TRAIT_REPLACEMENT_SKILLS`에 기본판 더미를 `e0NQ`로 적었는데 **`e09Q`가 맞다.**
- 기본판 `Trig_Law_Skill_2` → **`e09Q`**(thunderclap 오더 ✅) → `A0OG` **350,000**
- 강화판 `Trig_Law_Skill_2_reinforce` → `e0NQ`(purge 오더 → `A10W`만 발동) + **`e03T`**(thunderclap ✅) → `A140` **437,500**

**수치 비교(350,000 vs 437,500)는 그대로 맞다.** 더미 ID 라벨만 틀렸다.
