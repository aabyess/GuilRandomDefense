## ② 붕괴 라운드 — 4개 모델 × 연구 0/max

```
모델                  연구 0          연구 max
고정 10기/레인           붕괴 R54        붕괴 R54
안 조합                완주(75R)       완주(75R)
최대 조합(그리디)          붕괴 R63        완주(75R)
국소최적 조합             완주(75R)       완주(75R)
```

**「고정 10기/레인」이 연구 0/max에서 똑같이 R54인 것은 화력 문제가 아니다** — R51~R57
구간의 백로그를 직접 추적하면 `dps0 = dpsM = 327,113.5`로 소수점까지 정확히 일치한다.
이 구간의 티어(Tier=8)는 **다른세계**인데, 다른세계는 원작에 대응하는 연구소가 없어
우리도 잠가뒀다(`hasOriginalResearch=0`) — 그래서 이 구간만은 연구 축과 무관하게 항상
같은 값이 나온다. 백로그가 R51부터 새기 시작해 R54에 문턱(threshold)을 넘는다.

**최대 조합(그리디)은 연구 max에서 붕괴 없이 완주로 바뀐다** — 이 모델은 유닛을 계속
합성해 최종적으로 최고 등급(불멸·초월함 등, 전부 공속 축이 있다)에 도달하므로 공속
효과를 온전히 받는다.

### 🔴 별도 이슈 — 붕괴 라운드 모델의 티어 행진 자체가 검증되지 않은 가정 위에 있다

`tier_for_round(r) = min(MAX_TIER, (r-1) × TIER_COUNT // 75)` — **"라운드 N에 플레이어가
어느 등급을 갖고 있는가"를 "75라운드를 등급 수만큼 고르게 나눈다"로 정한다.** 원작에서
그걸 정하는 건 경제와 조합이지 균등 분할이 아니다.

**실측: 다른세계·랜덤유닛을 사다리에서 빼고(`IsLadderGrade` 기준, 03번) 남은 10개 등급으로
조밀하게 재색인해 다시 돌리면 — 더 좋아질 거라 예상했는데 정반대로 나왔다:**
```
지금(다른세계·랜덤유닛도 사다리 한 칸씩, 12칸)   고정10기: R54
빼고 조밀하게(10칸)                            고정10기: R8  ← 더 나빠짐
```
원인은 다른세계가 아니라 **칸 수 자체다** — 같은 75라운드를 12칸이 아니라 10칸으로
나누면 한 칸당 라운드 폭이 75/12=6.25 → 75/10=7.5로 오히려 넓어져 초반에 낮은 등급에
더 오래 머문다. **모델의 결론이 입력 데이터(로스터 실값)가 아니라 등급 개수에 지배되고
있다.**

> ⚠️ **붕괴 라운드 모델의 티어 행진은 75라운드 균등 분할이라는 검증되지 않은 가정 위에
> 있다. 칸 수를 12 → 10으로 바꾸면 붕괴가 R54 → R8로 이동한다 — 결론이 입력이 아니라
> 등급 개수에 지배된다. 이 모델로 낸 붕괴 라운드는 등급 개수가 같을 때끼리만
> 비교 가능하다.**

**이 문서가 지금까지 여러 날 인용해온 「R26에서 무너진다」·「R66까지 간다」류 붕괴 라운드
숫자 전부가 이 가정 위에 있었다는 뜻이다.** 오늘 네 축 수정과는 독립적인 문제라 이번
재측정 범위엔 안 넣었고, 후속 과제로 남긴다(어느 칸에 다른세계·랜덤유닛을 재배치할지는
창작 판단이 필요해 이 문서에서 결정하지 않는다 — PM 확정 대기).
