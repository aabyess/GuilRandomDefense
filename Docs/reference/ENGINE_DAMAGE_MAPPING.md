## ① 열 순서 — **밀리지 않았다. 확정.**

**결정적 증거는 맵 안에 있었다.** `war3mapSkin.txt`가 방어타입 툴팁을 재정의하고,
그 본문(`war3map.wts`)에 **맵 제작자가 배수를 숫자로 직접 적어놨다**:

```
ARMORTIP_LARGE  = 대형 <- 관통 125%  대형 <- 일반 100%  대형 <- 공성 75%  대형 <- 마법 85%
ARMORTIP_FORT   = 건물 <- 공성 125%  건물 <- 관통 100%  건물 <- 일반 75%
ARMORTIP_NORMAL = 일반 <- 일반 125%  일반 <- 건물 100%  일반 <- 관통 75%
```

이 값들이 `war3mapMisc.txt`의 **어느 열**과 맞는지 전 인덱스로 대조했다:

| 툴팁 | 0 | 1 | **2** | **3** | **4** | **5** | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 대형(Large) 4개 값 | 1/4 | 1/4 | **4/4** | 0/4 | 0/4 | 0/4 | 1/4 | 0/4 |
| 건물(Fort) 3개 값 | 1/3 | 1/3 | 0/3 | **3/3** | 0/3 | 0/3 | 1/3 | 0/3 |
| 일반(Normal) 3개 값 | 1/3 | 1/3 | 0/3 | 0/3 | **3/3** | 0/3 | 1/3 | 0/3 |
| 영웅(Hero) 5개 값 | 1/5 | 1/5 | 1/5 | 0/5 | 0/5 | **3/5** | 1/5 | 0/5 |

→ **Large=2 · Fort=3 · Normal=4 · Hero=5.** 지금 `Assets/Data/DamageTable.asset`이 읽고 있는 그대로다.
**PM 가설(3,4,5,6)이면 대형·건물·일반이 전부 0/4·0/3·0/3으로 어긋난다.**

**정정할 값은 없다.** `DamageTable.asset`은 손대지 않아도 된다.

> ⚠️ **덤 — 툴팁도 완전하진 않다.** 영웅 열만 3/5다. 「일반 100%」(실제 0.90)와 「공성 85%」(실제 0.80)가 어긋나고,
> `ARMORTIP_DIVINE`의 「일반 130%」는 어느 열에도 없다. **제작자가 툴팁을 쓴 뒤 값을 더 만졌다**는 뜻이다.
> **맞은 세 개(대형·건물·일반)가 12/12로 정확히 맞았기 때문에 열 순서는 확정**이고, 어긋난 둘은 값 수정 흔적으로 본다.
> (이 맵 툴팁이 낡는 패턴은 `A153`에서 이미 확인했다.)

## ② `ATTACK_TYPE_NORMAL` = Spells 인가 — **맵으로는 확정 불가, 다만 정황이 하나 늘었다**

**맵 안에 JASS 상수와 표 행을 잇는 증거는 없다.** 툴팁은 행을 **한국어 표시명**(일반·관통·공성·마법·히든)으로 부르지
JASS 상수로 부르지 않는다. `ATTACKTIP_*` 키는 `war3mapSkin.txt`에 **없다**.

**다만 툴팁에서 하나가 확정됐다**: `ARMORTIP_LARGE`의 「**마법** 85%」는 **`DamageBonusSpells`의 인덱스 2(=0.85)**와 맞는다.
`DamageBonusMagic`의 같은 자리는 1.00이다. → **맵 UI가 「마법」이라 부르는 행은 실제로 `Spells` 행이다.**
**행 이름과 표시명이 실제로 어긋나 있다**는 것이 맵 자체 데이터로 확인된 셈이고, 이는 ②의 전제(이름 어긋남)를 뒷받침한다.

**새로 확보한 정황 근거**: 유닛 공격타입(`ua1t`) 전수 census —
```
normal 127 · siege 89 · hero 28 · pierce 25 · chaos 1 · unknown 1
→ spells 0건 · magic 0건
```
**어떤 유닛도 Spells·Magic 행을 안 쓴다.** 그런데 두 행은 **따로 튜닝돼 있다**(Spells는 0.85/0.90/1.00/0.80로 다른 행과 다르다).
**쓰는 유닛이 없는데 값이 다르게 조정돼 있다면, 그 행을 쓰는 것은 유닛 평타가 아니라 능력·트리거 피해다.**
이는 「트리거 피해가 Spells 행을 탄다」를 지지한다 — **다만 그것이 `ATTACK_TYPE_NORMAL`이라는 특정 상수인지는 여전히 못 정한다.**

**판정: `[추정 — 엔진 지식 + 정황]`.** 정황은 셋이다.
(ⓐ) PM의 분포 근거 — `MELEE`가 18번 따로 쓰인다. `NORMAL`이 이미 「보통」이면 `MELEE`를 쓸 이유가 없다.
(ⓑ) 맵 UI가 Spells 행을 「마법」으로 부른다 = 이름 어긋남이 이 맵에 실재한다 `[파일확인]`.
(ⓒ) Spells·Magic 행을 쓰는 유닛이 0건인데 값은 따로 조정돼 있다 `[파일확인]`.

**정정이 필요하면 어디를 바꾸나** (②가 참일 때만):

| 파일 | 지금 | ②가 참이면 |
|---|---|---|
| 트리거 피해를 옮긴 우리 스킬 효과 **322건**(`attackType: Normal`) | Normal 행 (Large 1.00 / Fort 0.75 / Normal 1.25 / Hero 0.90) | **Spells 행** (Large **0.85** / Fort **0.90** / Normal **1.00** / Hero 0.80) |
| `ATTACK_TYPE_MELEE` 18건 | Melee(우리 표엔 별도 행 없음) | **Normal 행** |

→ **차이는 대형에서 1.00→0.85(−15%), 일반에서 1.25→1.00(−20%)**다. 작지 않다.
**②를 확정하기 전엔 옮기지 말 것.** 확정하려면 **맵 밖 자료(워크3 `common.j`)**가 필요하다.

## ③ `DAMAGE_TYPE_UNIVERSAL` — **불가**

피해타입(`DAMAGE_TYPE_*`)은 **`war3mapMisc.txt`의 표에 아예 없는 축**이다. 표는 **공격타입 × 방어타입**만 담는다.
맵 안에 `DAMAGE_TYPE_*`의 동작을 규정하는 데이터도, 그것을 설명하는 툴팁도 없다.
→ **`[불가 — 맵에 근거 없음]`.** 앞서 PM이 「엔진 지식」으로 답한 것을 그대로 두는 게 맞다.
