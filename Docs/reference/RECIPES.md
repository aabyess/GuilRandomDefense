## 전사하면서 확인된 것

1. **같은 유닛이 한 레시피에 2번 들어가는 경우가 있음**
   (초월 최상호 = 최상호 ×2 포함, 문필환 = 박은석 ×2, 전유라 = 강재규 ×2, 윤현모 = 상봉카 ×2)
   → 재료를 `Set`이 아니라 **개수를 세는 구조**로 만들어야 함
2. **아이템이 재료로 들어감** — `아이템[어둠의추천서]`, `아이템[분실된지갑]`
   → 유닛 외에 **아이템 개념 필요**
3. **조합 재료로 하위 조합 결과물이 쓰임** — 초월 재료에 히든(감탄떡볶이, 미소야, 호치킨)이 들어감
   → 조합 결과물도 다시 재료가 되는 **다단 조합 구조**
4. **조건부 조합** — 강보명은 41라운드 이전에만 가능
   → 레시피에 **조건(라운드 제한 등) 필드** 필요
5. **"랜덤전용유닛 1기"** 같은 **와일드카드 재료**가 있음 (특정 유닛이 아니라 조건을 만족하는 아무 유닛)
   → 재료를 "특정 UnitData" 외에 **조건 기반**으로도 지정할 수 있어야 함
