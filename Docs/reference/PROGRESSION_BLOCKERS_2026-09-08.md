# 진행 막힘 사냥 — 조합 도달 가능성으로 뒤졌다

조사: PM / 2026-09-08 (사장님 지시 「버그날만한 건 없어? 원작대비 막히는곳 없는지」)
방법: **뽑기·위습·퀘스트로 시작 가능한 유닛에서 조합식 207개를 반복 적용해 도달 집합을 구한다.**
도달 못 하는 유닛이 있으면 그 앞을 막는 재료가 진짜 병목이다.

---

## 0. 결과

| | 처음 | 고친 뒤 |
|---|---:|---:|
| 도달 가능 유닛 | 176 / 240 | **234 / 240** |

**고친 것 2건 · 아직 막힌 것 1건 · 오탐 3건**을 아래에 적는다.

## 1. 🔴 고침 — 초월위습 지급 경로가 통째로 없었다 (`1c9479c`)

`초월위습_박은석` **하나가 조합식 25개를 막고 있었다.** 초월 24기가 통째로 도달 불가.

```
원작 Trig_Story_reward10_Actions:
  골드 10000 + 나무 4 + CreateNUnitsAtLoc(1,'e01A',...)   ← e01A = 초월함위습
우리 Story10_동양미래대학교.asset:
  goldReward 10000 ✅   resourceRewards 나무 4 ✅   wispRewards: []   ← 🔴
```
13개 스토리 중 **10번만** 위습 보상이 비어 있었다. 게다가 초월위습용 `WispData` 자산도,
가챠 테이블의 grade 13 항목도 없었다. 셋 다 만들었다.

📌 weight 0이어도 된다 — `UnitPortal.RollReward`는 `RollFromGrade`로 등급을 직접 지정하고
weight를 안 본다(`GachaTable.cs` 주석이 그렇게 적어 뒀고 코드도 그렇다).

## 2. 🔴 고침 — 「희귀함 리롤」이 통째로 안 돌았다 (`eeff7a4`)

씬의 직렬화 필드를 전수로 훑어 나왔다. 원작 `Trig_unique_rerole`(능력 A0VX)다.

- `UniqueRerollAbilityData` **타입 자산이 0개** → `GamblingShop.uniqueRerollAbilityData`가
  씬 4곳 전부 비었고, `UniqueRerollAbility.Attach`가 `data == null`이면 조용히 null을 돌려준다.
- 씬에 `UniqueRerollState` 컴포넌트 **0개** → `Limit`·`FailChancePercent`가 전부 0으로 읽혀
  시도 자체가 성립 안 한다.

원작 값과 우리 기본값이 **정확히 일치**해서 그대로 자산화했다(목재 2 · 한도 2/도박 3 ·
실패 20%/도박 0%). 배선은 `MapGenerator.RepairUniqueReroll()`이 한다.

## 3. 🔴 아직 막힘 — 아이템 40종을 얻을 방법이 없다

**아이템 도박 풀은 채워져 있는데(35종) 그 풀을 여는 유닛이 0기다.**

```
UnitData.sellTriggersItemGamblePool  ← 이 필드가 있는 유닛 22기, 채워진 것 0기
```

원작 구조:
```
H0C4 「항해일지」        ← 플레이어별 상점. udg_Tech_Tree[플레이어]에 담긴다
  └ AddUnitToStockBJ('H0BS', udg_Tech_Tree[i], 재고, 최대)
       H0BS 「아이템도박-」  ← 5000골드 + 목재 3으로 산다
          └ 팔면 Trig_item_Gemble_Actions 가 아이템을 준다
```
우리엔 **「항해일지」 상점도, 「아이템도박」 유닛도 로스터에 없다.**
`UnitData.cs` 주석이 이미 「메타몽 유닛 자체를 손에 넣는 경로는 아직 없다」로 적어 뒀다 —
알려진 공백이고 이번에 그 영향 범위가 「아이템 40종 전부」로 확인됐다.

⚠️ **조합 도달에는 영향이 없다.** 아이템을 재료로 쓰는 조합식은 2건뿐이고(kind=1),
그 둘도 다른 경로가 있다. 그래서 234/240에는 안 걸린다.
다만 **아이템 시스템 자체가 죽어 있다** — 스토리 6~9 보상과 퀘스트 2종도 아이템을 요구한다.

## 5. 확인했는데 정상이던 것

- 조합식 207개: 결과·재료 참조 결손 **0건**, 로스터에 없는 guid **0건**
- 가챠 테이블: 등급 13개, weight 합 정확히 100, 테이블 grade와 유닛 grade **전부 일치**
- 마나 경제: 재생 0.3/초 · 상한 1000. 제일 비싼 해루석(700)도 상한 안에 든다
- 스킬 385개 중 378개가 로스터 배선. 안 붙은 7개는 **전부 능력교체형**이고 특성에 정상 배선돼 있다
- 특성 239개 중 26개만 유닛에 붙음 — 사장님 확정 사항(최상위 26명 전용)이라 맞다

## 6. 재현

```bash
# 도달 가능성
python3 - <<'PY'
# 가챠 weight>0 + 지급되는 위습의 등급 전체를 시작 집합으로 두고
# 조합식을 더 못 늘릴 때까지 반복 적용한다
PY
```
자세한 스크립트는 이 문서를 만든 세션의 명령 기록에 있다. 핵심은
**「시작 집합 = 뽑기 + 지급되는 위습의 등급」**이고, 위습 지급처를 빠뜨리면 가짜 병목이 잡힌다.
