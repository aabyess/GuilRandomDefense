# 거프 `Garp_Mana2` 분기 구조 + 스킬표 쿨다운 컬럼 (2026-09-05, 리서치담당)

## (2) 거프 `A0GY` — RRD 셋이 **레벨1 경로 하나 / 레벨2 경로 둘**로 갈린다 `[파일확인]`

`Trig_Garp_Mana2_Actions`는 스테이지 머신이다. **레벨 검사는 스테이지 0에서 딱 한 번** 한다:

```jass
Stage 0:
  integerA = GetUnitAbilityLevelSwapped('A0GY', 시전자)
  if integerA == 2 then          ← 특성 구매 후
      integerC = 0
      integerB = UnitCountBuffsExBJ(… 시전자 자신 …)      ← 자기 버프 개수
      realD    = 0.03 × integerB                          ← ★ realD의 정체
      더미 e0B5 + "stomp"
      ForGroup(반경 650) → Func004Func006Func008A          ← ① 6,000,000 + maxHP×0.05
      SleepForStage(0.05, 2)                              → Stage 2
  else                            ← 레벨 1(특성 전)
      더미 e0B6, A05Q 레벨2, "firebolt"
      RegisterUnitEvent(대상, EVENT_UNIT_DAMAGED, …)
      SleepForStage(1.17, 1)                              → Stage 1

Stage 1:  (레벨1 경로만 도달)
  integerB = 버프 개수 재계산 ; realD = 0.03 × integerB
  더미 e0B6 + "stomp"
  ForGroup(반경 650) → Func005Func008A                     ← ② 6,000,000 + maxHP×0.05
  Flush

Stage 2:  (레벨2 경로만 도달)
  integerC += 1
  if integerC == 1 then
      더미 e098 + e0B5
      ForGroup(반경 650) → Func006Func002Func011A          ← ③ 7,250,000 + maxHP×0.06
      Flush
  else  더미만 만들고 0.05초 뒤 Stage 2 반복
```

### 답 셋

| 물음 | 답 |
|---|---|
| **어느 블록이 레벨1/레벨2인가** | **①`Func004Func006Func008A`와 ③`Func006Func002Func011A`가 레벨2**, **②`Func005Func008A`가 레벨1**이다. 레벨 검사는 `integerA==2` 한 곳뿐이고 나머지는 스테이지 조건이다 |
| **`realD`가 무엇인가** | **`0.03 × 시전자 자신이 가진 버프 개수`**(`UnitCountBuffsExBJ`). 연구도 상수도 아니다 — **누적 스택 축**이라 우리 `SkillEffectBasis`엔 없다 |
| **앞의 둘이 왜 같은 식인가** | **조건이 다른 두 경로**라서다. ①은 레벨2의 **즉발** 타격, ②는 레벨1이 **1.17초 지연** 후 넣는 타격이다. **둘 다 적어야 한다** |

### 레벨1 → 레벨2 실제 차이

| | 타격 | 합계(버프 0개 기준) |
|---|---|---|
| **레벨 1** | 1.17초 뒤 **6,000,000 + maxHP×0.05** (반경 650) 1회 | 6,000,000 |
| **레벨 2** | **즉발 6,000,000 + maxHP×0.05** → 0.05초 뒤 **7,250,000 + maxHP×0.06** (둘 다 반경 650) | **13,250,000** |

→ 특성 효과는 **①선딜 1.17초 제거 ②두 번째 타격 7,250,000 추가**다. 셋 다 `[HERO/NORMAL]`, 반경 650.
→ **모든 타격에 `×(1 + 0.03×버프개수)`가 곱해진다.** 버프가 하나도 없으면 ×1.0이다.

## (1) `ORIGINAL_SKILL_DAMAGE_TABLE.csv`에 쿨다운 컬럼 추가

컬럼 셋을 덧붙였다: `absolute_cooldown_s` · `쿨근거버프` · `쿨근거능력`.

- **208행 중 26행에 절대쿨이 걸린다**(카이도 `B05Q` 11.0s 10행 · 에이스 `B017` 4.25s 6행 · 징베 `B00B` 7.0s 4행 ·
  빅맘 `B074` 6.25s 2행 · 비비 `B034` 6.0s 2행 · 레일리 `B070` 4.75s 1행 · 드래곤 `B00J` 8.5s 1행).
- **나머지 182행은 `0`**이다 — **「이번 전수로 조사했더니 절대쿨 게이트가 없다」**는 뜻이고,
  `쿨근거버프` 칸에 `조사함-없음`으로 명시했다. **빈 칸(미조사)과 구분된다.**
- 매칭 키는 **트리거 계열**이다(`출처` 컬럼의 `Trig_XXX`). 절대쿨 게이트가 걸린 트리거와, 그 게이트 안에서 호출되는 스킬 트리거 둘 다 잡았다.

⚠️ **한계**: 절대쿨 게이트는 **평타 트리거에 있고**, 스킬표의 행은 **그 아래 호출되는 스킬 트리거** 기준이다.
한 평타 트리거가 게이트 밖에서도 다른 스킬을 부르면 그 행까지 같이 잡힐 수 있다 —
**26행은 「이 쿨다운의 영향권에 있다」이지 「이 행 하나가 곧 그 쿨다운」은 아니다** `[미확인]`.
