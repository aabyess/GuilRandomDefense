## 🔑 「소환 77%」는 더미 시전자가 아니라 **조합 시스템**이다

`w3a`를 열어보니 다르다:

```
AHwe(Summon Water Elemental) 110개 중
  이름 "[조합]"          104개
  툴팁 "조합(Z)"         101개
```

**원작은 조합을 「소환」 능력으로 구현했다.** 핫키 Z를 누르면 결과 유닛이 소환된다.

### 🚨 정정 — **「스턴 → 추가피해」 축은 없다** (2026-09-04)

여기 원래 *"`B07H`를 능력 90개가 공유하고 트리거가 그걸 보고 추가 피해를 준다 —
원작 화력의 한 축, 규모 90개"*라고 적었다. **틀렸다. 리서치담당이 트리거 4곳을 다 열어봤다.**

`B07H`를 보는 4곳은 전부 **신세계 보스 스킬**(`Trig_sin_boss_skill1~4`)이고,
검사 대상이 **보스 자신**이며, 하는 일은 **피해가 아니라 시전 게이지 깎기**다:

```jass
if UnitHasBuffBJ(udg_Sin_Sboss[p],'B07H') then        // 보스가 스턴 중이면
   Stun_int[p] = IMax(0, Stun_int[p] - count*0.15)    // 시전 게이지 −15%/중첩
```

**피해는 1도 안 들어간다.** → **`Wrs1`만 세도 화력 합산에서 빠지는 몫은 없다.**

**대신 다른 것이 나왔다**: 원작에서 **스턴에 「보스 시전 끊기」라는 유틸리티 가치**가 따로 있다.
화력표가 아니라 설계 쪽 항목이다 — **우리에겐 그 개념이 없다.**
