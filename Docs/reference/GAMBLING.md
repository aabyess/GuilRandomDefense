# 도박소 (2026-09-01 사용자 확정 + 기존 기록 통합)

## 확정된 것

### 행운토큰의 유일한 출처는 도박 실패다

> **희귀함·특별함 도박이 있고, 실패하면 행운토큰이 나온다.** (사용자 확정)

이게 지금 게임의 **유일하게 비어 있던 자원 경로**였다.
목재는 물범, 골드는 적 처치로 들어오는데 행운토큰만 공급이 없었다.

**행운토큰을 요구하는 레시피 10개** — 없으면 이 조합들이 영원히 불가능하다:

| 결과 등급 | 레시피 수 |
|---|---|
| 다른세계 | 9 |
| 제한됨 | 1 |

예: `다른세계 무면허 라이더 = 주호페이크 + 구주호 + 임건웅 + 상붕카 + 골드 10,000 + 목재 7 + 행운토큰 1`

> 설계상 자연스럽다 — 실패해도 완전히 잃지 않고, 그 보상이 최상위 조합의 재료가 된다.
> 도박을 "돌려야 하는" 이유가 생긴다.

## 원작 조사 (2026-09-01, 리서치담당)

### ⚠️ 핵심 발견 — 원작에 "행운의 토큰"이 정확히 존재한다

사용자가 확정한 "희귀함·특별함 도박 실패 시 행운토큰 지급" 설계는 **원작에 그대로 대응하는 개념이 있다** [원작]:

> "행운의 토큰은 **고급 도박과 다른 세계 도박이 실패했을 때**의 디메리트를 큰 폭으로 줄여주며, 실패 한정이지만 **토큰을 2개나 주고 나무도 하나 지급**하여 실질적인 코스트를 나무 3개로 줄여줍니다. 토큰 지급량이 두 배가 되는 덕에 행운의 토큰 3개로 희귀 위습을 노리는 것도 충분히 가능합니다."
> — WebSearch가 인용한 나무위키/커뮤니티 요약 (원문 페이지 직접 대조는 못함, 여러 검색에서 동일 내용이 반복돼 신뢰도는 준수 수준)

주의할 점: 원작에서 토큰의 주 용도는 "행운의 토큰 2개 + 목재 3개로 업그레이드해 새로운 스킬 획득"이라는 서술이 있어, **우리 게임처럼 상위 등급 조합 재료로 쓰이는 것과는 정확히 같은 용도가 아닐 수 있다** [추정 — 용도 자체는 다르게 보이나, "실패해도 완전히 잃지 않고 다음 목표의 재료가 된다"는 설계 철학은 동일].

### 도박 종류 — 원작엔 최소 두 개의 분리된 시스템이 있다

1. **"돈 도박"(money gambling)** — 골드 전용, 유닛과 무관:
   - 초급: 60% 확률로 7~50골드 획득, 실패 시 3~5골드 반환
   - 중급: (패치로) "물품지원"으로 변경 — 2회 한정, 30골드 + 흔함~안흔함 랜덤 유닛 1기 지급
   - 고급: 기본 확률 +5%, 최대 금액 +500골드, 실패 시 반환 골드 증가
   - 초급·중급·고급 통틀어 누적 35,000골드 획득 시 "졸업"(더 이상 못 함) → 특성포인트 구매 가능해짐
   - [원작] (검색엔진이 나무위키/thewiki.kr을 요약한 결과, 원문 직접 대조는 못함 — [추정]에 가까운 [원작])
   - 기존 `GAMBLING.md`의 "도박소에서 골드를 불릴 수 있다"는 이 트랙에 해당하는 것으로 보인다.

2. **"유닛 도박"(아이템 도박, 목재 소모)** — 하도/중도/고도(하급/중급/고급) 3단계:

   | 단계 | 목재 소모 | 성공확률 | 성공 시 결과 |
   |---|---|---|---|
   | 하도 | 1개 | 85% | 흔함~안흔함 등급 (평균 가치 1.27흔함/목재) |
   | 중도 | 1개 | 70% | 특별함 등급 (평균 가치 1.54흔함/목재) |
   | 고도 | 4개 | 70% | 희귀함+특별함 혼합 (평균 가치 1.548흔함/목재) |

   출처: 디시인사이드 "도박별 1목재당 흔함 갯수" 게시글의 계산식 원문 직접 확인 — `하도 0.85x((1+2)/2)=1.275`, `중도 0.7x(4.4/2)=1.54`, `고도 0.7x((13.3+4.4)/2)/4=1.548` [원작]
   https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=182880

   1000회 실측 통계도 확인됨 [원작] (https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=167474):
   - 고도 1000회: 희귀함 371 + 특별함 323 = 694회 성공 (69.4%, 위 70%와 대체로 일치)
   - 중도 1000회: 특별함 675회 성공 (67.5%, 위 70%와 대체로 일치)

   → **사용자가 말한 "희귀함 도박"은 이 표의 "고도"에, "특별함 도박"은 "중도"에 대응하는 것으로 보인다** [추정 — 정확한 명칭 "희귀함 도박"/"특별함 도박" 자체가 원문에 그대로 쓰인 걸 확인하진 못했고, 결과물 등급으로 유추한 매핑이다].

3. **"다른 세계 도박"** — 별도 카테고리, 목재 5개 소모, **17% 확률** [원작]. 성공 시 "다른세계" 등급(원피스가 아닌 완전히 다른 작품 크로스오버 캐릭터, 최소 1전설급 성능) 획득. 실패 시 위의 행운의 토큰 지급 대상.
   출처: WebSearch가 인용한 커뮤니티 요약 (원문 직접 대조는 못함)

### 실패 시 보상 상세

- **고도 + 다른세계 도박**: 실패 시 행운의 토큰 2개 + 목재 1개 지급 [원작, 위 인용]
- **하도·중도 실패 시 행운의 토큰을 주는지는 [미기재]** — 검색에서 명시적 서술을 못 찾음. "고급 도박과 다른 세계 도박"이라고 콕 집어 말한 문장으로 미루어 **하도·중도는 토큰 지급 대상이 아닐 가능성**이 있다 [추정].

### 5번 초과 실패 시 비용 증가 — 구체적 배수는 여전히 미기재

`Docs/ORIGINAL_GAME_RESEARCH.md`에 이미 있던 "5번 초과 실패 시 비용 증가"를 재확인하려 했으나, 이번 조사에서도 **정확한 증가 폭(몇 %? 목재 몇 개 추가?)은 찾지 못했다** [미기재]. 이 항목은 1차 조사 때부터 지금까지 두 번 다 벽에 부딪힌 것으로, 원작 자체 문서에도 구체 수치가 없을 가능성이 크다.

### 도박소 위치

**[미기재]**. "도박소 위치", "도박소 맵" 등 여러 쿼리로 검색했으나 구체적인 맵 상 위치(섬 이름, 좌표, 주변 시설)를 서술한 자료를 찾지 못했다. 참고로 나무위키 요약 검색 결과 중 "맵 중앙에 위치한 천사(?)를 누르면 확장팩 인증"이라는 문장이 나왔으나, 이건 도박소가 아니라 확장팩 인증 오브젝트로 보여 관련이 없다 [추정 — 도박소와 무관해 보임].

### 플레이어별인가 공용인가

**[미기재]**. 명시적 서술을 찾지 못했다. 다만 "돈 도박"의 "35,000골드 누적 시 졸업" 시스템은 개인의 골드 획득 누적을 추적하는 것으로 보여 **개인별 진행 상태가 있다는 정황**은 있다 [추정 — 이게 "도박소 자체가 플레이어별 건물"이라는 근거는 아니고, 개인별 카운터가 있다는 것만 시사].
