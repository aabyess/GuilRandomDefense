# 도박소 (2026-09-01 사용자 확정 + 기존 기록 통합)

## 확정된 것

### 행운토큰의 유일한 출처는 도박 실패다

> **희귀함·특별함 도박이 있고, 실패하면 행운토큰이 나온다.** (사용자 확정)

이게 지금 게임의 **유일하게 비어 있던 자원 경로**였다.
목재는 물범, 골드는 적 처치로 들어오는데 행운토큰만 공급이 없었다.

**행운토큰을 요구하는 레시피 10개** — 없으면 이 조합들이 영원히 불가능하다:

| 결과 등급 | 레시피 수 |
|---|---|
| 다른세계 | 9 |
| 제한됨 | 1 |

예: `다른세계 고태훈 = 주호페이크 + 구주호 + 임건웅 + 상붕카 + 골드 10,000 + 목재 7 + 행운토큰 1`

> 설계상 자연스럽다 — 실패해도 완전히 잃지 않고, 그 보상이 최상위 조합의 재료가 된다.
> 도박을 "돌려야 하는" 이유가 생긴다.

### 그 외 기존 기록

| 항목 | 내용 | 출처 |
|---|---|---|
| 상붕카(배) | 도박소에서 **목재 1개** 소모 시 **40%** 확률 | 사용자 확정 |
| 골드 불리기 | 도박소에서 돈을 불릴 수 있다 | 사용자 확정 |
| 실패 누적 | 원작은 **5번 초과 실패 시 비용 증가** | [원작] |
| 하급·중급 도박 | 일정 확률로 특정 유닛 획득, 또는 10,000골드로 직접 구매 | `RECIPES.md` |

## 아직 정해지지 않은 것

- **도박 1회 비용** (희귀함 도박 / 특별함 도박 각각)
- **성공 확률**과 성공 시 무엇이 나오는가
- 실패 시 **행운토큰 몇 개**
- 원작의 "5번 초과 실패 시 비용 증가"를 따를 것인가
- 도박소가 **맵 어디에 있는가** — 아직 섬이 없다
- 도박소가 플레이어별인가 공용인가
