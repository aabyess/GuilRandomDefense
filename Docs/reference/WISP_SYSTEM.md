# 위습(영혼) 획득 시스템 · 유닛 생성 섬 (2026-08-29 사용자 제공)

> 참고 이미지: `map/02_유닛생성섬_상단.png`, `03_유닛생성섬_중단.png`, `04_랜덤유닛뽑기섬.png`
> ⚠️ 이미지는 **원작(원랜디 시즌 8)** 화면. 우리 게임 사양과 다른 부분이 있을 수 있음.

## ⚠️ 핵심: 뽑기는 "골드로 사는" 게 아니라 "위습을 걸어 넣는" 방식이다

현재 우리 코드는 **골드 60을 내고 즉시 유닛을 받는** 구조인데, 실제 설계는 다르다.

```
[조건 달성] → 위습(영혼) 획득 → 위습을 조종해 포탈로 이동 → 해당 유닛 획득
```

- **위습은 플레이어가 조종하는 유닛**이다 (이동시켜서 포탈에 넣어야 함)
- 위습에는 **종류**가 있고, 종류마다 들어갈 수 있는 포탈이 다르다
  예) `흔함선택위습`, `안흔함위습`, `희귀함(특수함)위습`, `랜덤위습`

### 위습 획득 경로 (이미지 채팅 로그 기준)
- **스토리 클리어** → 전체 플레이어에게 골드 + 위습 지급
  - "알라바스타까지의 스토리 진행완료 → 500골드 + 흔함유닛선택 위습 3기 + 안흔함 위습 1기"
  - "여인섬까지의 스토리 진행완료 → 9000골드 + 나무 5개 + 희귀함(특수함) 위습 3기"
- **보스에게 가장 많은 데미지를 넣은 플레이어** → 랜덤위습 1기
- **도전과제 완료** → 랜덤위습 1기

## 유닛 생성 섬 구조 (위 → 아래)

### 1. 흔함 — 개별 선택
- 포탈이 **여러 개 나란히** 배치되고, 각 포탈이 특정 흔함 유닛에 대응
- 플레이어가 **보고 고를 수 있다** (원하는 유닛의 포탈로 위습을 이동)

### 2. 안흔함 — 전체 랜덤
- 포탈 1개. `'안흔함'등급유닛 전체랜덤`

### 3. 특별함 — 전체 랜덤
- 포탈 1개. `'특별함'등급유닛 전체랜덤`

### 4. 희귀함 — 전체 랜덤 (+ 3% 확률)
- 포탈 1개. 원작 이미지 표기: `'희귀함, 특수함(3%확률)'등급유닛 전체랜덤`
- ⚠️ **우리 게임에 '특수함' 등급은 없다** (2026-08-29 사용자 확정 — 원작에만 있는 등급).
  → 3% 확률분을 어떻게 할지는 미정 (없애거나, 상위 등급으로 대체)

### 5. 특별 위습 포탈 (목재/초월)
- 목재 또는 초월을 뽑을 수 있는 특별한 위습용 포탈

### 6. 배 + 캐릭터
- 원작은 배 + 레일리. **우리 게임은 배 + 다른 캐릭터 예정** → 일단 레일리로 넣고 나중에 교체

### 7. 전설 + 히든 — 전체 랜덤
- `'전설&히든'등급유닛 전체랜덤`
- **65라운드에 신세계로 넘어가기 직전, 1분간 대기시간을 주고 이 위습 1기 지급**

### 8. 우측: 랜덤유닛 / 다른세계 스킨 전시
- 배치만. **조합식 없음**

## 랜덤유닛 뽑기 섬 (별도 작은 섬, 4방향 포탈)

| 방향 | 포탈 | 효과 |
|---|---|---|
| **북** | 유닛 랜덤 | 랜덤 유닛 획득 |
| **동** | 금화 랜덤 | `15 + (현재라운드 × 12~35)` 만큼의 금화 |
| **서** | 목재 랜덤 | **66% 확률로 목재 1개** 획득 |
| **남** | 도움소 마나 | `20 + (현재라운드 × 1.5)` 회복 |

→ 보상이 **현재 라운드에 비례**해서 증가하는 구조.

## 현재 코드와의 차이 (구현 필요)

| 항목 | 현재 코드 | 실제 설계 |
|---|---|---|
| 뽑기 방식 | 골드 60 지불 → 즉시 유닛 | **위습 획득 → 조종 → 포탈 진입** |
| 위습 개념 | 없음 | 종류별 위습 (흔함선택/안흔함/희귀함/랜덤...) |
| 포탈 | 없음 | 등급별 포탈 오브젝트, 위습 진입 판정 |
| 스토리 보상 | 없음 | 스토리 클리어 시 전체 지급 |
| 보스 기여도 | 없음 | 최다 데미지 플레이어에게 위습 |
| 라운드 비례 보상 | 없음 | 금화·마나가 라운드에 비례 |
