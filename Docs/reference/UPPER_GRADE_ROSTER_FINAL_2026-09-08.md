## 1. 분모를 정한 규칙 — **획득 경로가 등급이다**

오전에는 「이름에 등급 문자열이 있는가」로 셌다. 틀렸다. 원작은 등급을 **어떻게 얻는가**로 가른다.

| 등급 | 획득 경로 | 원문 근거 |
|---|---|---|
| 초월함 | 채팅언락 | `Trig_Eternal_*_Actions` 28개가 `CreateNUnitsAtLoc(...,'H0xx',...)`로 지급 |
| 불멸의 | 채팅언락 | `Trig_IM_*_Actions` 11개 |
| 영원한 | 채팅언락 | `Trig_Forever_*_Actions` 8개 |
| 전설적인 | **조합** | 능력 데이터 `atat`(조합 결과) 필드 — 아래 §2 |
| 제한됨 | 조합 16 + 다른세계 도박 3 | `atat` + `Trig_R_Johab` |

### 밴 레지스트리와 정확히 맞는다 — 독립 검증

`BAN_COUNT_MISMATCH_RESOLVED_2026-09-08.md`의 원작 실측과 견주면:

```
초월  28 = Ban_Trigger 27 + 밴에서 빠진 Nika 1        ✅
불멸  11 = Ban_Trigger_IM 11                          ✅
영원   8 = Ban_Trigger_ET 7 + 밴에서 빠진 uta 1        ✅
제한  18 ⊃ Ban_Trigger_Limited 8 (상점잠금 서브셋)     ✅ 포함 관계 맞음
```

밴 시스템은 이 조사와 **무관하게** 세어진 것이다. 두 독립 경로가 같은 수를 낸다.

## 2. 🔴 오전에 틀린 것 세 가지

**① 대문자 `H` 유닛을 안 봤다.** 채팅언락이 주는 초월 유닛은 `H090`처럼 **대문자**다.
정규식이 소문자 `h`만 잡아서 초월이 「참조 0건 25기」로 나왔다. 실제로는 28기 전부 지급된다.

**② 등급 이름이 붙은 소문자 `h` 유닛은 초월에선 전시본이다.**
`h04M` 「마샬.D.티치 지진과 어둠의 검은수염 - 초월함」은 `CreateUnitsForPlayer7`(Player 7 전시)
에서만 만들어지고 공격 트리거도 없다(32기 중 1기만 등록). 플레이어가 받는 건 `H090`
「지진과 어둠의 검은수염」이다. **이름은 같은 캐릭터인데 ID가 다르다.**
반면 불멸·영원·전설·제한은 등급 이름이 붙은 `h` 유닛이 곧 플레이어 유닛이다(공격 트리거 등록 100%).
등급마다 구조가 다르다 — 하나의 규칙으로 밀면 틀린다.

**③ 조합의 정체를 몰랐다.** 전설 40기가 「생성 0건」으로 나왔던 이유:
조합은 트리거가 아니라 **능력 데이터**다.
```
A011  base=Aroa  anam=[조합]
      acat = h02T,h03K        ← 재료 (마르코 + 히루루크)
      atat = h08O             ← 결과 (마르코 제한됨)
      areq = R03B             ← 필요 연구
```
`atat`를 가진 능력이 147개(base AHwe 106·Aroa 36·AHtc 3·AEfk 2)다. 이게 원작 조합식 전체다.
📌 우리 조합식은 **우리 창작**이라([[follow-original-everywhere]]) 이 표를 옮길 필요는 없다.
다만 「원작이 전설을 조합으로 준다」는 구조는 이제 근거가 있다.

## 3. 분모에서 뺀 것 — 전부 원문 한 줄씩

| 종류 | 예 | 근거 |
|---|---|---|
| 전시본(Player 7) | 초월 `h04I` 등 31기 | `CreateUnitsForPlayer7`에서만 생성, 공격 트리거 없음 |
| 소환물 | `h05J` 레일리소환 · `h0BH/I/J` 부유물 · `h04O/h088` 우타 · `h06H` 하쿠바 · `h085/h086` 시노부 | 다른 유닛의 스킬 트리거가 `CreateNUnits` |
| 변신폼 | `h04Y` 광분한 빅맘 · `h0AD` 카이도 용 | `Emeu`(변신 대상) 필드 / 생성 0건 |
| 장난감 | `h06N`·`h06P` | 슈가의 스킬(Trig_Legend*)이 소환 |
| 참조 0건 | `h0AE` 히그마 · `h0BU` 정체불명 병기 · `h05D` 장군좀비 · `h08Q` 아라마키 · `h09M` 후카 | 어떤 경로로도 등장 안 함. 미사용 데이터로 보이나 단정 못 함 |

⚠️ 소환물을 뺄 때 **그 소환물이 든 능력은 주인에게 귀속**시켰다. 시키는 본체가 RRD 0건이고
부유물 셋이 대신 때린다 — 소환물을 통째로 빼면 분자까지 사라진다.

## 4. 분자를 센 방법 (오전과 같다)

각 유닛에 대해 ① `uabi`의 능력 중 피해 필드(`Ucs1`·`Idam`·`Hbh*`·`Hcl1`…)가 0이 아닌 것 +
② `udg_HashAttack` 등록 트리거를 `ConditionalTriggerExecute`로 재귀 추적해 `RRD`/`UnitDamageTarget`이
직접 있는 함수 + ③ 그 트리거가 소환하는 더미(e/h/H)의 살아있는 능력(재귀 3단). 능력ID 단위 중복 제거.

「피해 아님」으로 이미 닫힌 11개 필드그룹(`Aroa·ANbr·AUfa·Asph·Ablo·ANht·AUls·Ainf·AOae·Apg2·AHad`)은 제외.

## 5. 남는 한계

- 전설 37기 중 **2기**(`h038` 시저 · `h03F` 카르가라)는 공격 트리거 등록이 없다.
  조합 결과로 얻긴 하는데 평타 트리거가 없으면 능력이 어디 있는지 이 방법으로 못 본다. [미확정]
- 「능력ID」와 「피해 스킬함수」는 **다른 축**이다. 초월은 33/36, 전설은 25/23으로 서로 비슷하지만
  같은 것을 세는 게 아니다. 우리 쪽과 비교할 때는 어느 축인지 먼저 정해야 한다.
- 🔴 **우리 쪽 값은 여전히 [미확정]**이다. `Tools/measure_skill_density.py`가 effect 단위로 세는데
  원작은 능력ID 단위다. **축을 맞추기 전에는 배수를 내면 안 된다.** 이건 오전 결론 그대로다.
