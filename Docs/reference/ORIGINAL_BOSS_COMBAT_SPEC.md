## ④ 캐스팅 게이지 (시전)

```
틱 주기      0.20초
틱당 증가    +5.00
최대치       100.00
→ 100 / 5 × 0.2초 = 4.0초  ·  초당 25.0
```

- **채우는 건 시간뿐이다.** 피해량·피격 횟수·플레이어 행동 어느 것도 시전 속도에 관여하지 않는다 `[파일확인]`.
- 다 차면 **광폭화 몬스터 1기 소환**(⑦) 후 보스·바 전부 숨기고 그 라운드 종료.
- 게이지가 부서지는 순간(⑥) 진행도는 **−5 되돌려지고**, 그 뒤 시전은 **재개되지 않는다** — 그대로 취소다.

## ⑤ 무적 (`Avul`)

| 항목 | 값 |
|---|---|
| 붙는 방식 | **유닛 데이터에 처음부터 박혀 있다** (`uabi = Avul,A11S,ACrk,A0TK,AIsr,Aegr,AId1`). 트리거가 켜는 게 아니다 |
| 풀리는 조건 | **스턴게이지 < 2**가 되는 순간 `UnitRemoveAbilityBJ('Avul', 사이드보스)` |
| 다시 붙는 조건 | 게이지가 **0에서 100까지 재충전 완료**되면 `UnitAddAbilityBJ('Avul', …)` (⑥의 재충전 4.0초) |
| **무적의 뜻** | **피해가 아예 안 들어간다.** 「1 밑으로 안 내려간다」가 아니라 **모든 피해가 무시(0 처리)**된다 |

> 🔧 **구현담당3께**: 우리 `EnemyDummy.invulnerable`은 「1 밑으로 안 내려간다」는 다른 뜻이라 **이것에 쓸 수 없습니다.**
> 필요한 건 **`DealDamage` 진입 자체를 막는 완전 면역 플래그**입니다.
> 「HP가 1로 남는다」와 「피해가 0이 된다」는 눈에 보이는 결과가 다릅니다 — 전자는 체력바가 바닥에 붙고, 원작은 **체력바가 100%에서 꿈쩍도 안 합니다.**
>
> ⚠️ 이 「무적 = 피해 0」은 워크래프트3 엔진 동작이다. **맵 파일 안에 이걸 정의하는 데이터는 없다**(스톡 능력 `Avul`) — 뿌리 ⑩에 따라 **엔진 지식이라는 것을 밝혀둔다.**
> 다만 맵 쪽 정황이 이를 뒷받침한다: 스턴 능력 90종 중 **88종의 `atar`(허용 대상)에 `invulnerable`이 명시**돼 있다.
> 무적 대상에게도 스턴만은 들어가게 일부러 열어둔 것이고, **그렇게까지 해야 했다는 것 자체가 다른 모든 것이 막혀 있다는 뜻**이다.

## ⑥ 스턴게이지

### 감소 (시전 중, 0.20초 틱마다)

```jass
IF 사이드보스가 버프 'B07H'(스턴)를 갖고 있으면:
    스택 += 1
    게이지 = IMaxBJ(0, R2I(게이지 - 스택 × 0.15))      ← R2I는 버림
    udg_Stun_int[플레이어] = 게이지                      ← 전역에 되쓴다
```

| 항목 | 값 |
|---|---|
| 최대치 | **100** |
| 스택 1당 감소량 | **0.15점** ← 「중첩당 15%」는 **100배 오류** |
| 스택 증가 | 스턴이 걸려 있는 **틱마다 +1** (스턴이 끊겨도 스택은 안 줄어든다) |
| 스택 리셋 | **게이지가 부서질 때만** 0으로 리셋 |
| 버림 | `R2I`가 내림이라 초반엔 1틱에 1점, 스택이 쌓일수록 2·3점씩 가속한다 |
| 초기화 | **맵 시작 시 100** (`InitGlobals`, 플레이어별) |
| 누적 범위 | **맵 전체 · 플레이어별 · 세 등장(R62·66·71)에 걸쳐 이어진다** — 라운드 사이에 리셋되지 않는다 |

### 파괴 시(게이지 < 2)

```
캐스팅 진행도 −5 · 스택 = 0 · Avul 제거 · 메시지 출력
→ 재충전 단계로 전환 (틱 0.08초)
```

### 재충전 (파괴 뒤)

```
틱 주기      0.08초
틱당 증가    +2
게이지 = IMinBJ(101, 카운터)
게이지 > 99 → 게이지 = 100 · Avul 복구 · udg_Stun_int[플레이어] = 100
```

→ **0 → 100까지 50틱 × 0.08초 = 4.0초. 초당 25.0.**
→ **딜 창은 정확히 4.0초**이고, 그 뒤 보스는 숨겨지며 그 라운드의 사이드보스전은 끝난다.

> 🔴 **여기가 기존 조사와 다르다**: 게이지를 부수면 **`udg_Stun_int`가 100으로 되돌아간다.**
> 즉 **부순 대가로 누적치가 초기화된다.** 기존 문서는 「라운드를 넘어 누적된다」만 적고 이 리셋을 빠뜨렸다(⑨).

## ⑧ 정산 — 다음 보스 라운드의 시작 체력

사이드보스전의 결과는 **R65·70·75의 라운드 보스 시작 체력**으로만 나타난다(`Trig_Enemy_Boss_sinsekai_Actions`).

```jass
if IsUnitAliveBJ(사이드보스) then
    보스 체력% = 보스 체력% × 0.85 + 사이드보스 체력% × 0.15
    KillUnit(사이드보스); KillUnit(캐스팅바); KillUnit(스턴바)
else
    보스 체력% = 보스 체력% × 0.85 + 0.00
```

새로 만든 보스는 100%이므로:

| 사이드보스를 어떻게 뒀나 | 라운드 보스 시작 체력 |
|---|---|
| 전혀 못 깎음 (100%) | **100%** |
| 절반 깎음 (50%) | **92.5%** |
| 0%까지 깎음 | **85%** |
| 죽여버림 | **85%** |

→ **최대 절감폭은 15%다.** 4초짜리 딜 창에서 6,200만~8,400만 체력을 얼마나 깎았느냐가 그대로 반영된다.

라운드 보스 유닛타입은 `udg_Round_UnitType[(udg_Boss_sin_number × 5) + 90]` → 95·100·105번 칸 = 도플라밍고·빅맘·카이도.
`A11S` 레벨은 **16**(=×1.00, 최대치)으로 세팅된다.

## ⑨ 이번에 잡은 기존 조사의 오류 2건

| # | 기존 문서 | 원문 | 왜 틀렸나 |
|---|---|---|---|
| 1 | 「게이지는 라운드를 넘어 누적된다」만 적음 | **게이지를 부수면 `udg_Stun_int`가 100으로 리셋된다** | stage 3(재충전) 끝의 `Setinteger(GlobalTV,3,100)` + `udg_Stun_int[p]=integerD`를 안 따라갔다. 「누적된다」는 맞지만 **부순 뒤엔 아니다** |
| 2 | 「스택은 끊겨도 리셋되지 않는다」 | 맞다. 다만 **게이지 파괴 시엔 스택도 0으로 리셋**된다 | 파괴 분기 안의 `Setinteger(GlobalTV,2,0)`을 빠뜨렸다 |

둘 다 **stage 3 이후를 안 읽어서** 생긴 누락이다 — 뿌리 ⑧(블록을 잘랐으면 안쪽까지)의 시간축 버전이다.

또 하나, 기존 문서가 stage 3의 조건 두 개를 **뒤바꿔** 읽을 뻔했다:
`Func005Func004C`는 **`PlayerDeath==1`**(정리)이고 `Func005Func004Func001C`가 **`게이지>99`**(재충전 완료)다.
이름이 더 긴 쪽이 더 안쪽이라 순서가 뒤집혀 보인다 — **조건 함수 이름의 길이는 중첩 깊이지 실행 순서가 아니다.**

## ⑩ 🔧 우리 쪽에 없는 것 — 구현담당3 정찰 반영

| # | 없는 것 | 왜 대체가 안 되나 | 필요한 것 |
|---|---|---|---|
| 1 | **완전 피해 면역** | `EnemyDummy.invulnerable`은 「1 밑으로 안 내려간다」는 **다른 뜻**이다 | 피해 적용 자체를 건너뛰는 플래그. 원작은 체력바가 **꿈쩍도 안 한다** |
| 2 | **시전 게이지 개념** | `AddFreeze`는 **이동 정지**일 뿐 게이지가 아니다 | 0→100을 4.0초에 채우고 도달 시 콜백을 부르는 타이머 + 그 값을 그리는 UI |
| 3 | **스턴게이지 컴포넌트** | `EnemyAuraCaster`는 **Aura 전용**이라 여기에 못 얹는다 | **별도 컴포넌트**. 상태 넷(시전중 / 파괴 / 재충전 / 종료)과 플레이어별 영속값 1개 |
| 4 | **스킬 효과로서의 스턴** | `SkillEffectKind.Stun`이 이름만 있고 읽는 코드가 없다 | 게이지를 미는 건 「스턴 버프가 붙어 있는가」다 — **버프 유무를 매 틱 조회할 수 있어야** 한다 |
| 5 | **대상별 피해 감수성**(`A11S`) | 없음 | 보스 ×1.00 / 잡몹 ×0.90 / 광폭화 소환체 ×0.25 |

### 상태 기계 (그대로 옮기면 되는 형태)

```
Stage0  진입: 게이지 = 저장값(플레이어별, 초기 100) · 스택 0 · 진행도 0
        → Stage1 (0.02초 뒤)

Stage1  0.20초마다:
            진행도 += 5 ; 캐스팅바 += 5
            if 보스에 스턴버프: 스택 += 1 ; 게이지 = max(0, floor(게이지 − 스택×0.15)) ; 저장
            if 게이지 < 2:   캐스팅바 −5 ; 스택 0 ; 무적 해제 ; 메시지     → Stage3 (0.05초 뒤)
            elif 진행도 >= 100:                                            → Stage2 (0.20초 뒤)
            else                                                           → Stage1 반복
```
