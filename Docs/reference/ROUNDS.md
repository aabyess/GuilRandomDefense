## 읽을 때 걸리는 것

- **이름이 아군 유닛과 겹친다.** 박은석·김용태·이태훈·이승우·신지우·정윤식 등은 로스터에도 있는
  이름이다. **적과 아군은 별개 데이터**이므로 `EnemyData`와 `UnitData`를 섞지 말 것.
- **「돌아온」·「간보는」·「긁힌」·「삐진」은 같은 적의 강화 재등장**으로 보인다. 스탯을 올린 별개
  `EnemyData`로 둘지, 배율만 다르게 줄지는 정해지지 않았다.
- **한 라운드에 몇 마리인지는 이 표에 없다.** 기존 조사값은 35마리다(`ORIGINAL_GAME_RESEARCH.md`).
- **60라운드 「졸업」이 무엇을 주는지** 이 표에 없다. 사장님 확인 필요.
