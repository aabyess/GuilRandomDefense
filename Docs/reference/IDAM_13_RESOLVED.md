# ② `Idam`(`AIfb`) 혼재 13건 — 전부 해결. 12건 유효, 1건 이미 확인된 죽은 값

조사: 리서치담당 / 2026-09-06(계속)

## 결론

`Idam`은 **매 타 발동하는 고정 추가 피해**다(확률 필드가 아예 없다 — `ACbh`의 `Hbh1`처럼
확률을 굴리는 자리가 `AIfb` 계열엔 없다). **트리거·오더가 필요 없다** — 오늘 하루 쓴 「오더 검사」
단계는 **더미에게 명령으로 시전시키는 스킬**에만 해당하고, `AIfb`는 그게 아니라 **유닛 자신이
평타를 칠 때마다 엔진이 알아서 얹는 네이티브 오브(Orb) 부착 효과**다. `Iob5=1`(13개 전부 동일)이
그 오브 플래그로 보인다.

**판정 기준은 "이 능력을 든 유닛이 실전에서 진짜로 평타를 치는가"였다.**

### ⚠️ 3건은 툴팁이 완전히 다른 능력(자석자석 열매)을 복붙한 것이다 — 그래도 `Idam`은 산다

`A0VM`·`A0YC`·`A102`는 `atp1`·`aub1`이 **글자까지 똑같이** 「자석자석 열매 - 레벨 2 / 이동속도
25% 감소」를 말한다. `A0YC`는 심지어 `anam`(제작자 내부명)이 **"오뎅 이도류"인데 툴팁은 자석자석
열매**다 — 명백한 복붙 실수(오늘 하루 여러 번 나온 툴팁 오류의 같은 부류). **그런데 그 텍스트는
UI 표시용일 뿐 `AIfb`가 네이티브로 도는 것과 무관하다.** 이동속도 감소는 **다른 능력·다른 필드**에서
따로 나올 것이고(이번 조사 범위 밖), `Idam`은 그거와 별개로 **그대로 매 타 터진다.**

## 🔴 미작동 1건 — `A0X3`(이미 오늘 확정된 것과 같은 결론)

`A0X3`는 **`e08G`(일회성 장식 더미)** 하나만 갖고 있다. `e08G`는 `stomp` 오더 한 번 받고
사라지는 더미이지 반복 평타를 치는 유닛이 아니다 — **오더가 붙는 `A0B3`(피해 50,000, `AOws`)로
이미 대체 확정된 자리**다(`STOCK_FIELD_RESEARCH_RESULT.csv`, 오늘 앞서 처리). `A0X3`의 `Idam`은
같은 이유로 **한 번도 안 켜진다**(평타 자체가 없는 더미라 오브 효과가 발동할 기회가 없다).
