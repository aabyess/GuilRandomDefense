## ② 그래서 초월함은 어느 쪽인가 — **「스킬이 약하다」**

## ④ 🔴 조사 중 발견 — 내 표의 등급 축이 둘 섞여 있었다

`ORIGINAL_UNLISTED_SKILL_EFFECTS.csv`의 `등급` 컬럼과 **원작 유닛 이름의 등급 라벨이 서로 다른 축**이었다.

```
CSV 등급별 고유 유닛의 ID 첫 글자
  초월함  24종 → 전부 H*     ← 대문자
  그 외   전부 h*            ← 소문자
```

**`H*`는 「영웅」 계열**이고 **이름에 등급 라벨이 없다**(`H07S 흔함영웅` · `H05N 해군의 홍일점` · `H08W CP.Zero`).
`H*` 68종의 DPS는 **38(흔함영웅)에서 403,229(밀짚모자 해적단 의사)까지** 넓게 퍼져 있다 — **등급이 아니라 별개 축**이다.

→ 그래서 **「원작 등급별 스킬 보유율」은 분모를 못 정한다** `[미확인]`.
이름 라벨로 세면 `H*` 68종이 통째로 빠지고, CSV 등급으로 세면 「초월함=H\*전부」라는 다른 정의가 된다.
**이 문서의 ①②는 우리 로스터 기준이고, 원작 쪽은 「가진 유닛의 피해 중앙값」만 비교했다.**

⚠️ **어제 쓴 `ORIGINAL_GRADE_LADDER.md`의 원작 DPS 표도 이름 라벨 기준이라 `H*` 68종이 빠져 있다.**
사다리의 **순서·단조성 결론은 유지**되지만(라벨이 붙은 245종 안에서는 성립), **「원작 초월함 67,191」 같은 개별 수치는 `H*`를 안 센 값**이다.
