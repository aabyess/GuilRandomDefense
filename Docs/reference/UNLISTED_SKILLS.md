> ### 🚩 방법론 함정 하나 더
> **게이트가 「블록 안의 `if`」가 아니라 「트리거 전체 조건」이나 「조건 함수」에 있을 수 있다.**
> 블록 스택만 걸으면 **트리거 실행 자체를 막는 조건은 영원히 안 보인다.**
> 이번 표에는 `_Conditions`를 따로 훑어 `[트리거조건]` 표시로 합쳐 넣었다(해당 1건).

## 조사 범위 공개

- **`udg_HashAttack`에 등록된 203종 전부**의 평타 트리거를 `if/else/endif` 스택으로 걸어
  `(Conditional)TriggerExecute` 대상을 전부 수집했다. 표본이 아니라 전수다.
- **커버 판정은 트리거/유닛 이름 문자열이 우리 CSV에 있는가**로 했다 — 이름이 달라도 같은 스킬일 가능성은 남는다 `[미확인]`.
- **안 본 것**: 스킬 트리거가 **또 다른 트리거를 부르는 2단계 이상**은 안 따라갔다 `[미확인]`.
  더미 소환만 하고 `TriggerExecute`를 안 쓰는 경로도 이 표엔 없다(그쪽은 2채널 더미 채널로 이미 잡혀 있다).
