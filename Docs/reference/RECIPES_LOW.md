# 하위 등급 조합표 (2026-08-29 사용자 제공)

> 상위 등급(초월/히든/불멸/영원/제한/다른세계)은 `RECIPES.md` 참고.

## 흔함 (확정, 2026-08-29)

**흔함이 모든 조합의 출발점이 되는 가장 기초 위습이다.**

`최상호` `노태현` `양재모` `강주혁` `강재규` `박민석` `문필환` `박민수` `임장혁`

> 같은 이름이 상위 등급에도 존재한다. 예) 강주혁은 흔함이면서 특별함(코알라)이기도 하고,
> 문필환은 흔함이면서 영원이기도 하다. 에셋에서는 등급 접두사로 구분한다.

### 동일 승급 (흔함 ×2 → 같은 이름의 안흔함)
| 재료 | 결과 | 별칭 |
|---|---|---|
| 강주혁 ×2 | 강주혁 | **알라** |
| 강재규 ×2 | 강재규 | **재규어** 라이딩 |
| 문필환 ×2 | 문필환 | **오네쇼타** |
| 박민수 ×2 | 박민수 | **로이킴** |

### 조합 불가 — 뽑기 전용
| 유닛 | 별칭 | 획득 |
|---|---|---|
| 이호준 | **볼보이** | 조합식 없음. **뽑기로만 획득** |

> 원작의 **압살롬 포지션**. 원작에서 압살롬은 도박과 엮인 유닛이었다
> (`ORIGINAL_GAME_RESEARCH.md` 5장: "압살롬 도박은 5번 넘게 실패하면 비용 증가").
> 추후 만들 **도박소**와 연결될 가능성이 있다.

## ⚠️ 별칭이 곧 재료 이름이다

특별함 레시피에 등장하던 정체불명의 재료 `알라` `재규어` `쇼타` `로이킴`은
**별도 유닛이 아니라 안흔함 유닛의 별칭**이었다.

| 별칭 | 실제 |
|---|---|
| 알라 | 안흔함 강주혁 |
| 재규어 | 안흔함 강재규 |
| 쇼타 | 안흔함 문필환 |
| 로이킴 | 안흔함 박민수 |

이 대응으로 특별함 레시피가 전부 해석된다. 예:
- `알라 ×2 → 강주혁(코알라)` = 안흔함 강주혁 2개 → 특별함 강주혁
- `쇼타 + 알라 + 노태현 → 김태영` = 안흔함 문필환 + 안흔함 강주혁 + 흔함 노태현

**데이터 모델 시사점**: 유닛은 `이름 + 등급`으로 식별하되, 등급별로 **표시용 별칭**을 따로 가진다.
같은 "강주혁"이 흔함·안흔함(알라)·특별함(코알라)에 각각 존재한다.

## 기본 규칙

- **안흔함** = 흔함 2개 조합
- **특별함** = 흔함 + 안흔함 조합

> ⚠️ 아래 실제 표에는 재료가 2~4개인 레시피가 섞여 있어, 위 규칙은 대략적인 설명으로 보인다.
> **실제 조합은 아래 표가 기준.**

### 재료 등급 해석 완료

`이호준`도 **안흔함**이다 — 다만 조합이 아니라 **뽑기로만** 얻는다 (별칭: 볼보이).

## 별칭 = 등급별 이름 (2026-08-29 확정)

**같은 인물이 등급이 오를수록 별칭이 바뀐다.** 원작에서 루피가 흔함부터 초월까지
계속 강해지는 것과 같은 구조.

조현규 예시 — 셋 다 같은 인물의 다른 등급이다:
| 별칭 | 등급 |
|---|---|
| 피즈 | 희귀함 ✅ |
| 외동조피즈 | ⚠️ 미확인 |
| 돌연변이외동조씨 | ⚠️ 미확인 |

→ 별칭만으로 등급을 특정할 수 없는 경우가 남아 있다.

## 남은 확인 사항

- 없음 — 모든 재료가 실제 등급 유닛으로 연결 완료 (2026-08-29)
- ⚠️ **특별함 신문철** — 최현우(마술사) 재료가 특별함 신문철이라고 하셨는데,
  받은 특별함 표에는 신문철이 없다. 신문철은 **안흔함**(박민석+임장혁)과 **전설적인**(장난꾸러기)에만 있다.
  → 특별함 신문철 레시피가 누락됐거나, 재료가 안흔함 신문철일 가능성

# 조합표 이미지의 색상 = 등급 (2026-08-29 사용자 확인)

조합표 이미지에서 **재료 이름의 글자 색이 곧 그 재료의 등급**이다.

| 색 | 등급 |
|---|---|
| 빨강 | 전설적인 |
| 보라색 | 희귀함 |
| 노란색 | 특별함 |
| 푸른색 | 히든 |
| 초록색 | 안흔함 · 흔함 (둘 다 초록) |
| 핑크색 | **변화됨** — 아직 미정의 등급, 추후 추가 예정 |

> 앞으로 조합표 이미지를 읽을 때는 **색을 먼저 보고 등급을 판정**할 것.
> 이름만 보고 추측하면 같은 이름의 다른 등급과 헷갈린다.

## 박은석 = 초월 위습

초월 레시피 25개 중 24개의 **마지막 재료가 `박은석`**인데, 이는 일반 유닛이 아니라
**초월 조합에 필요한 특수 위습**이다 (원작의 **쿠마 위습** 포지션).

→ 일반 유닛 `박은석`(희귀함/전설적인/불멸)과는 **별개 개념**이므로 데이터에서 구분해야 한다.
   `WISP_SYSTEM.md`의 "특별 위습 포탈(목재/초월)"과 연결되는 항목.
