# 하위 등급 조합표 (2026-08-29 사용자 제공)

> 상위 등급(초월/히든/불멸/영원/제한/다른세계)은 `RECIPES.md` 참고.

## 흔함 (확정, 2026-08-29)

**흔함이 모든 조합의 출발점이 되는 가장 기초 위습이다.**

`최상호` `노태현` `양재모` `강주혁` `강재규` `박민석` `문필환` `박민수` `임장혁`

> 같은 이름이 상위 등급에도 존재한다. 예) 강주혁은 흔함이면서 특별함(코알라)이기도 하고,
> 문필환은 흔함이면서 영원이기도 하다. 에셋에서는 등급 접두사로 구분한다.

### 동일 승급 (흔함 ×2 → 같은 이름의 안흔함)
| 재료 | 결과 | 별칭 |
|---|---|---|
| 강주혁 ×2 | 강주혁 | **알라** |
| 강재규 ×2 | 강재규 | **재규어** 라이딩 |
| 문필환 ×2 | 문필환 | **오네쇼타** |
| 박민수 ×2 | 박민수 | **로이킴** |

### 조합 불가 — 뽑기 전용
| 유닛 | 별칭 | 획득 |
|---|---|---|
| 이호준 | **볼보이** | 조합식 없음. **뽑기로만 획득** |

> 원작의 **압살롬 포지션**. 원작에서 압살롬은 도박과 엮인 유닛이었다
> (`ORIGINAL_GAME_RESEARCH.md` 5장: "압살롬 도박은 5번 넘게 실패하면 비용 증가").
> 추후 만들 **도박소**와 연결될 가능성이 있다.

## ⚠️ 별칭이 곧 재료 이름이다

특별함 레시피에 등장하던 정체불명의 재료 `알라` `재규어` `쇼타` `로이킴`은
**별도 유닛이 아니라 안흔함 유닛의 별칭**이었다.

| 별칭 | 실제 |
|---|---|
| 알라 | 안흔함 강주혁 |
| 재규어 | 안흔함 강재규 |
| 쇼타 | 안흔함 문필환 |
| 로이킴 | 안흔함 박민수 |

이 대응으로 특별함 레시피가 전부 해석된다. 예:
- `알라 ×2 → 강주혁(코알라)` = 안흔함 강주혁 2개 → 특별함 강주혁
- `쇼타 + 알라 + 노태현 → 김태영` = 안흔함 문필환 + 안흔함 강주혁 + 흔함 노태현

**데이터 모델 시사점**: 유닛은 `이름 + 등급`으로 식별하되, 등급별로 **표시용 별칭**을 따로 가진다.
같은 "강주혁"이 흔함·안흔함(알라)·특별함(코알라)에 각각 존재한다.

## 기본 규칙

- **안흔함** = 흔함 2개 조합
- **특별함** = 흔함 + 안흔함 조합

> ⚠️ 아래 실제 표에는 재료가 2~4개인 레시피가 섞여 있어, 위 규칙은 대략적인 설명으로 보인다.
> **실제 조합은 아래 표가 기준.**

### 재료 등급 해석 완료

`이호준`도 **안흔함**이다 — 다만 조합이 아니라 **뽑기로만** 얻는다 (별칭: 볼보이).

> 조합식 표에 나오지 않으므로 UI에서도 별도 취급이 필요하다.

## 확인 필요 (희귀함 표)

1. **별칭 없는 재료의 등급** — 대부분의 재료는 특별함 별칭이 붙어 있는데, 두 곳만 이름만 있다:
   - 최현우(마술사)의 `신문철`
   - 이상혁(거권)의 `김용태`
   두 이름 모두 **안흔함과 특별함에 각각 존재**한다. 어느 쪽인가?
2. **"예비"의 의미** — `왕승환(왕싱싱 예비)`, `이병준(불법체류자 예비)`에 붙은 "예비"가 무슨 뜻인가?
3. **이승우** — `이승우(악의근원)`과 `이승우(악질)` 두 개가 언급됐다.
   악질 = 뽑기 전용으로 이해했는데, **악의근원**은 별개 유닛인가? 조합식이 있는가?
