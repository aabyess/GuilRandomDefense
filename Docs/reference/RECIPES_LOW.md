# 하위 등급 조합표 (2026-08-29 사용자 제공)

> 상위 등급(초월/히든/불멸/영원/제한/다른세계)은 `RECIPES.md` 참고.

## 흔함 (확정, 2026-08-29)

**흔함이 모든 조합의 출발점이 되는 가장 기초 위습이다.**

`최상호` `노태현` `양재모` `강주혁` `강재규` `박민석` `문필환` `박민수` `임장혁`

> 같은 이름이 상위 등급에도 존재한다. 예) 강주혁은 흔함이면서 특별함(코알라)이기도 하고,
> 문필환은 흔함이면서 영원이기도 하다. 에셋에서는 등급 접두사로 구분한다.

## 기본 규칙

- **안흔함** = 흔함 2개 조합
- **특별함** = 흔함 + 안흔함 조합

> ⚠️ 아래 실제 표에는 재료가 2~4개인 레시피가 섞여 있어, 위 규칙은 대략적인 설명으로 보인다.
> **실제 조합은 아래 표가 기준.**

## 특별함 조합

오른쪽이 결과 유닛(특별함)이고, 괄호 안은 별칭이다.

| 재료 | 결과 | 별칭 |
|---|---|---|
| 최상호 ×3 | 최상호 | 일진 |
| 노태현 ×3 | 노태현 | 노티 |
| 양재모 ×3 | 양재모 | 늑대 |
| 박민석 ×3 | 박민석 | 빡빡이 |
| 임장혁 ×3 | 임장혁 | 장애인 |
| 김용태 ×2 | 김용태 | 흑화 |

### 재료로만 등장하는 유닛 (등급 미확인)

특별함 레시피의 재료 중 **흔함 목록에 없는** 이름들이다.
규칙이 "특별함 = 흔함 + 안흔함"이므로 **안흔함으로 추정**되나, 확인 필요:

`황정기` `박준희` `김용태` `김경현` `김민준` `신문철` `김수빈` `이재윤` `엄태웅`
`알라` `재규어` `쇼타` `로이킴` `이호준`

결과로 등장 = **특별함 확정**:
`최상호` `노태현` `양재모` `박민석` `임장혁` `김용태` `황정기` `임채준` `박기찬` `이현빈`
`조세민` `왕승환` `이병준` `김정래` `이정범` `유재헌` `주영호` `고우선` `이지원` `서아인`
`박예원` `조성진` `박진웅` `노건완` `최동준` `강주혁` `정승준` `배성령` `김태영` `최준우`
`송형성` `박민수` `조도연`

> ⚠️ 같은 이름이 여러 등급에 존재한다. 예) 최상호는 흔함·특별함·초월·영원에 모두 있다.
> 에셋에서는 `특별함_최상호` 처럼 등급 접두사로 구분한다.
