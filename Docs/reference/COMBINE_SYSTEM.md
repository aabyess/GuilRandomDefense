# 조합 시스템 / 등급 체계 (사용자 제공, 2026-08-29)

> 출처: 사용자가 직접 제공한 조합표 이미지 4장 (`Docs/reference/combine-table/`)
> ⚠️ 이 문서는 **구조·규칙**만 정리한 것. 개별 유닛 스탯은 이미지 원본을 볼 것.
> 원본 이미지가 정본이며, 이 문서와 다르면 이미지가 맞다.

## 1. 등급 체계 (확정)

```
흔함 → 안흔함 → 특별함 → 희귀함 → 전설적인 → 제한됨 → [초월 = 불멸 = 영원함]
                          ↑                              ↑
                       히든 동급                  다른세계(랜덤유닛) 동급
```

- **흔함 ~ 전설적인**: 한 단계씩 올라가는 기본 라인
- **제한됨**: 전설적인보다 위, 초월/불멸/영원보다 아래
- **초월 · 불멸 · 영원함**: 셋이 서로 **동급**이며 최상위
- **히든**: 희귀함과 동급 (별도 라인)
- **랜덤유닛**: 확률로 획득하는 유닛 (조합 라인 밖)
- **다른세계(랜덤유닛)**: 초월/불멸/영원과 동급

## 2. 유닛 타입: AD / AP

모든 유닛에 **AD**(물리) / **AP**(마법) 표기가 붙는다. 일부는 **AD+AP** 겸용.
→ 원작 조사의 "물뎀 / 마뎀 / 방무뎀" 분류와 대응 (`ORIGINAL_GAME_RESEARCH.md` 4장).
→ 현재 `UnitData`에는 이 개념이 없음. **추가 필요.**

## 3. 조합 규칙 (등급별로 다름) ⚠️

**통일 공식이 없다.** 등급마다 재료 구성·부가 비용이 전부 다르다.
현재 코드의 "동일 유닛 3개 → 상위 1개" 단일 규칙과 **구조적으로 다름.**

| 등급 | 재료 구성 | 부가 비용 | 비고 |
|---|---|---|---|
| **초월** | 지정 유닛 4~8개 (레시피별로 다름) | — | 대부분 마지막 재료가 `박은석` |
| **히든 (사람)** | 지정 유닛 3~5개 | — | |
| **히든 (장소)** | 지정 유닛 + `상봉카` | — | 호치킨, 이삭토스트, 미소야, 맥주만땅, 감탄떡볶이 |
| **히든 (개)** | 조합 아님 | 10,000골드 | 하급·중급 도박에서 확률 획득 **또는** 10,000골드 구매 |
| **불멸** | 지정 유닛 3개 | **나무 10개** | |
| **영원** | 지정 유닛 3~5개 | **나무 5개** + **Save 횟수** | 아래 별도 설명 |
| **제한** | 지정 유닛 3~5개 | **5,000골드 + 나무 5개** | 첫 번째 캐릭터에 조합 버튼. **김강민 제외** |
| **랜덤유닛 강화** | — | **10,000골드 + 목재 3 + 토큰 1** | |
| **다른세계** | 지정 유닛 3~5개 | **행운의토큰 + 10,000골드 + 나무 7개** | 랜덤유닛에 조합 버튼. 확장팩 |

### 3-1. 영원 등급의 "Save 횟수" 조건 ⚠️ 특수 메커니즘

영원 등급은 재료 외에 **누적 Save 횟수**를 요구한다. 유닛마다 요구치가 다름:

| 유닛 | Save 요구 |
|---|---|
| 최상호 | 0회 |
| 김영원 | 5회 |
| 조세민 | 10회 |
| 이지원 | 15회 |
| 문필환 | 20회 |
| 서민성 | 25회 |
| 김정래 | 30회 |
| 윤현모 | 35회 |

**Save = 게임 클리어 횟수** (2026-08-29 사용자 확정).
게임을 한 판 깰 때마다 +1 누적된다. 즉 **판을 거듭할수록 해금되는 장기 진행 요소**.
→ 세이브 데이터 저장 기능이 필요하며, **나중에 추가할 기능**. 지금은 조합식 구조만 반영하면 된다.

## 4. 자원 종류

조합표에서 확인된 자원:
- **골드** (5,000 / 10,000 단위로 사용)
- **나무 / 목재** (3, 5, 7, 10개 단위)
- **행운의 토큰** (다른세계 조합에 필요)
- **토큰** (랜덤유닛 강화)

→ 현재 코드는 **골드만** 있음. 나무·토큰 자원 추가 필요.

## 5. 명령어(커맨드) 시스템

각 조합에 한글/영문 명령어가 붙어있다.
예) `킹카가될뻔했던사나이` / `Sangho tr`, `구일의지배자정윤식` / `Yunsig im`

접미사 규칙(관찰):
- `tr` = 초월(transcend)
- `im` = 불멸(immortal)
- `et` = 영원(eternal)
- 히든은 `〇〇조합` 형태

→ 원작이 WC3 유즈맵이라 채팅 명령어로 조합했던 흔적.
   **Unity에서는 UI 버튼이 맞으므로, 명령어는 식별자(ID)로만 쓰고 입력 방식은 UI로 갈 것.**

## 6. 현재 코드와의 차이 (전부 구현 필요)

| 항목 | 현재 코드 | 실제 설계 |
|---|---|---|
| 등급 수 | 4단계 (Common/Rare/Epic/Legendary) | 7단계 + 동급 라인 |
| 조합 규칙 | 동일 유닛 3개 → 상위 랜덤 | **지정 레시피** (유닛별로 재료가 다름) |
| 조합 비용 | 없음 | 골드 / 나무 / 토큰 / Save 횟수 |
| 유닛 타입 | 없음 | AD / AP / AD+AP |
| 스킬 | SkillData 껍데기만 | 유닛마다 고유 특성 다수 |

→ `CombineSystem`을 **레시피 기반으로 전면 재작성** 필요.
   (구현담당2가 이미 확장 대비해 로직을 격리해둠 — 그 위에 얹으면 됨)

## 7. ⚠️ IP 확인 필요

`랜덤유닛` / `다른세계` 카테고리에 **타사 IP 캐릭터**가 다수 포함되어 있다:
카마도 탄지로, 이타도리 유지, 고죠 사토루, 손오공, 브로리, 미도리야 이즈쿠, 올마이트,
한마 바키, 리바이 아커만, 호시노 아이/루비, 모몬가, 가사이 유노, 야사카 카나코 등.

**결정 (2026-08-29): 그대로 사용한다.** 친구들끼리 비공개로 즐기는 용도라 실질적 문제 없음.

다만 아래 시점에는 재검토가 필요하다:
- Steam / itch.io 등 **공개 배포**하거나 수익화할 때
- **GitHub 저장소를 public으로 전환**할 때 (현재 private)
- 유튜브·스트리밍으로 게임 화면을 공개할 때

데이터가 ScriptableObject 기반이라 그때 **이름·이미지만 교체**하면 되도록 설계되어 있다.
사람 이름(최상호, 노태현 등)은 본인·지인이므로 별개 사안.
