## (2) 마법저항 축 — **죽지 않았다. 다만 「마법저항」이 아니다** `[파일확인]`

| 확인 항목 | 결과 |
|---|---|
| `DAMAGE_TYPE_MAGIC` 사용 | **0건** (PM 집계와 일치) |
| `ATTACK_TYPE_MAGIC` 사용 | 62건 |
| 적 유닛에 `Aegr`가 붙어 있나 | **붙어 있다** — 라운드 몹 `uabi`에 `Aegr` 포함 |
| 레벨은 누가 정하나 | **난이도 모드**가 `udg_magicDP_Rine`로 정하고, 스폰 시 `SetUnitAbilityLevelSwapped('Aegr', 몹, magicDP_Rine)` |
| 그 레벨을 **읽는** 코드 | **0건.** 9개 지점이 전부 **쓰기**(`레벨+3/+5/+7/+10/+18`)다 |

**난이도별 값** `[파일확인]`: **쉬움 16 · 지옥 11 · 악몽 6** (초기값 0).

→ **정리**: 원작의 이 축은 **피해타입(magic)이 아니라 「`Aegr` 능력 레벨」**이고, **엔진이 직접 처리**한다.
`Aegr` 파생인 `A0P9`(해왕류 관통 방어)가 `Def1=0.85`·`Def5=0.90`을 갖는 걸 보면
**`Aegr` = 공격타입별 피해 감쇄** 계열이다 — **「마법 저항」이 아니라 「특정 공격타입 감쇄」**다.

- **난이도가 어려울수록 레벨이 낮다**(쉬움 16 → 악몽 6). `Aegr`가 감쇄 능력이라면
  **레벨이 높을수록 감쇄가 적어야** 이 방향이 말이 된다 `[추정 — 스톡 정의 없음]`.
- **여러 스킬이 대상의 `Aegr` 레벨을 올린다**(핸콕 석화 +5, 우타 +5, 히든9 +3, 히든14 +7, 에넬 +18, 파이러츠도킹 +10).
  **「맞을수록 그 대상이 감쇄를 더/덜 받게 되는 스택」**이고, `A11S`와 같은 꼴이다.

**판정**: 우리 `EnemyDummy.EffectiveMagicMultiplier`가 모델한 「마법 저항」은 **원작에 대응이 없다**
(`DAMAGE_TYPE_MAGIC` 0건). 대응되는 실제 축은 **`Aegr` 레벨(난이도 + 스킬 스택)**이고 **감쇄량은 스톡 정의라 맵에서 못 읽는다** `[미확인]`.
**지우지 말고 「원작 대응 없음 · 실제 축은 Aegr 레벨」로 표시해 두는 게 맞다.**
