# 원작 수치 모음 (ORD 11.089)

원작 맵 파일에서 직접 뽑은 값이다. **아직 게임에 적용하지 않았다** — 사장님이
*"일단 정보를 숙지해두고 이후 유닛별로 추가"* 하기로 하셨다(2026-09-04).

뽑는 도구는 `Tools/w3x/`, 파일은 사장님이 갖고 계신 `ORD11.089.w3x`.

## ⚠️ 통째로 옮기면 게임이 멈춘다

넷은 한 세트다. **하나만 가져오면 깨진다.**

| | 우리 | 원작 |
|---|---|---|
| 적 체력 | R1 10 → R75 5,882 (588배) | R1 135 → R75 1,621만 (12만배) |
| 적 방어력 | 전부 0 | R1 0 → R75 395 |
| 유닛 공격력 | 5 ~ 1,247 (250배) | 22 ~ 217,500 (1만배) |
| 유닛 체력 | 100 ~ 6,122 | **전부 10** |

실제로 계산해봤다 — **적 방어력만 원작 값으로 넣으면** 우리 유닛으로 R75 적 하나 잡는 데
**75초**가 걸린다(지금은 3초). 적이 38마리씩 나오는 라운드라 절대 못 막는다.

원작은 **아군이 한 대도 안 맞는 전제**로 짜인 밸런스다(체력 10). 그대로 옮기면 게임의
성격 자체가 바뀐다.

## 등급별 유닛 스탯

**⚠️ 이 표는 한 번 크게 틀렸다.** 처음에 전설적인을 3종으로 세서 중앙값이 217,500으로 나왔고,
그 탓에 *"전설 > 초월"*, *"등급이 높다고 공격력이 높지 않다"*고 적었다. 실제로는 **전설이 42종**이고
중앙값은 30,252다 — **등급 순서대로 단조 증가한다.**

공격력은 워크3 공식 `기본 + 주사위수 × (면수+1)/2`로 계산했고, **필드를 명시하지 않은 유닛은 뺐다**
(상속이라 0이 아니다). 그 필터를 안 걸면 표본이 확 줄어 중앙값이 튄다.

| 원작 등급 | 수 | 공격력(중앙) | 최소~최대 | 등급 내 편차 | 우리 등급 |
|---|---|---|---|---|---|
| 흔함 | 9 | 24 | 19~27 | 1배 | 흔함 |
| 안흔함 | 14 | 112 | 49~185 | 4배 | 안흔함 |
| 특별함 | 33 | 425 | 86~777 | 9배 | 특별함 |
| 희귀함 | 46 | 4,200 | 1,111~20,000 | 18배 | 희귀함 |
| 특수함 | 6 | 8,502 | 7,000~50,002 | 7배 | 특수함 |
| 전설적인 | 42 | 30,252 | 6,252~250,000 | 40배 | 전설적인 |
| 제한됨 | 11 | 42,527 | 32,502~205,002 | 6배 | 제한됨 |
| 초월함 | 32 | 43,002 | 1,502~515,002 | **343배** | 초월 |
| 랜덤전용 | 17 | 125,002 | 50,002~625,002 | 12배 | 랜덤유닛 |

## 🔑 등급은 스탯을 정하지 않는다

**우리 구조와 원작이 근본적으로 다른 지점이다.** 우리는 `generate_unit_stats.py`가 등급에서
스탯을 일괄 산출한다 — 같은 등급이면 239종이 전부 같은 값이다. 원작은 그렇지 않다.

**등급이 오를수록 편차가 커진다**: 흔함 1배 → 희귀함 18배 → 전설 40배 → **초월 343배**.

편차의 정체는 밸런스 실수가 아니라 **역할 차이**다. 초월함 안에서:
```
브룩 소울 킹          공격력   1,502   ← 소환·이감·버프 유닛. 평타로 안 싸운다
쵸파 슈퍼 쵸파 탱크    공격력 515,002   ← 평타 딜러
```

→ **등급은 "얼마나 센가"가 아니라 "얼마나 귀한가"다.**
→ 등급으로 스탯을 산출하는 우리 모델로는 이걸 담을 수 없다. 239종을 옮기려면
**유닛마다 값을 따로 주는 구조**로 바꿔야 한다.

## 체력·이속·공속은 등급으로 안 나뉜다

| 항목 | 원작 | 우리 |
|---|---|---|
| **체력** | **전 등급 10** | 100 × 1.8^티어 (흔함 100 → 초월 6,122) |
| **이동속도** | **전 등급 522 동일** | 전 등급 22 동일 — 구조는 같다 |
| **공격 쿨다운** | **전 등급 1 동일** | 1.0 + 0.08 × 티어 |
| 사거리 | 420~700, **등급 비례 아님** (특수함 475 < 희귀함 600, 제한됨 700이 최고) | 6 + 0.5 × 티어 |

**아군 체력은 원작에서 사실상 쓰이지 않는다 — 전부 10이다.** 우리가 씌운 1.8배 곡선은 근거가 없다.
(다만 우리도 아군이 죽는 경로가 아직 없어서 결과적으로 문제가 드러나지 않고 있었다.)

**우리 게임의 히든·불멸·영원·다른세계·초월위습·변화됨은 11.089에 없다.**
사장님 조합표는 인물이 다른 별개 버전이다(원작은 나미·조로·루피, 우리는 최상호·박은석).

**⚠️ 이름이 전부 개명돼 있어 원작 유닛과 우리 239종을 1:1로 붙일 수 없다.**
유닛별로 값을 옮기려면 **이 매핑이 먼저다.** 지금은 등급 단위로만 대응된다.

**사거리(420~700)와 이동속도(522)는 옮기지 말 것** — 워크3 좌표계라 우리 맵(레인 165)과
축척이 다르다. 체력·공격력처럼 비율로 의미가 있는 값만 가져온다.

## 공격 타입 × 방어 타입 — **상성이 실제로 작동한다**

방어 타입은 `udty`(문자열)다. `udea`(정수)는 다른 필드이므로 읽지 말 것 — 한 번 잘못 읽어
"상성이 작동하지 않는다"고 결론냈다가 뒤집혔다.

실제로 쓰이는 것: 공격 `normal / siege / pierce / hero / chaos`, 방어 `large / fort / normal / hero`.

|  | large | fort | normal | hero |
|---|---|---|---|---|
| **normal** | 1.00 | 0.75 | **1.25** | 0.90 |
| **pierce** | **1.25** | 1.00 | 0.75 | 0.90 |
| **siege** | 0.75 | **1.25** | 1.00 | 0.80 |
| hero | 1.05 | 1.05 | 1.05 | 1.05 |
| chaos | 1.00 | 1.00 | 1.00 | 1.00 |

**3각 상성이다** — 셋이 서로 하나에 1.25, 하나에 0.75다. 남은 기본값이 아니라 짜인 구조다.
워크3 표준 상성 넷(`siege↑fort`, `normal↓fort`, `pierce↑large`, `pierce↓normal`)으로
열 순서를 검증했고 전부 맞았다.

**「보스」라는 방어 타입은 없다** — 보스도 위 넷 중 하나를 쓴다.
1,559종 중 119종만 방어 타입을 명시하고 나머지는 베이스 유닛 값을 상속한다.

## 방어력 감폭

워크3 공식 그대로다. `war3mapMisc.txt` 확인.
```
양수:  배율 = 1 − (0.06 × 방어력) / (1 + 0.06 × 방어력)
음수:  배율 = 2 − 0.94^(−방어력)
```

## 난이도

난이도는 적 체력을 직접 바꾸지 않고 **적 플레이어(6)에게 업그레이드를 걸어서** 올린다.
그래서 스크립트에서 체력 대입을 찾으면 안 나온다 — 한 번 "난이도가 체력을 안 바꾼다"고
잘못 결론냈다.

```
쉬움 · 보통 · 어려움 · 지옥 · 신 · 악몽    (6종)
```

| 업그레이드 | 효과 | 비고 |
|---|---|---|
| `R00A` | 전체 체력 % | 보통 +10 / 어려움 +50 / 지옥 +100 / 신 +140 |
| `R00J`·`R00O` | 방어력 +10% | **레벨과 무관하게 고정.** 악몽만 보스 방어 보너스 없음 |
| `R00V`·`R00U`·`R00T`·`R00W` | 라운드 구간별 체력 % | 어려움 +27~200 / 지옥 이상 +450~800 — **후반 난이도의 실제 원천** |
| `R00K`·`L`·`M`·`B`·`N` | 보스 전용 추가 체력 % | 쉬움 −15 / 보통 0 / 어려움 +200 / 지옥 +450 / 신·악몽 +725 |
| `R024` | 이동속도 | 어려움 +29 / 지옥 +58 / 신 +87 |

**솔로/파티 보정**: 솔로는 스토리 체력 −40%(와노쿠니 추가 −25%), 방어력 −5%, 골드 +10.
파티는 인원 1명당 어려움 +3% / 지옥 +8% / 신 +14% / 악몽 +15%.

**난이도별 패배 조건**: 쉬움은 보스를 안 잡아도 안 짐. 어려움 51R 「어인섬」,
지옥 41R 「드레스로사」(카운트 60), 신 41R 「홀케이크섬」(카운트 55).
**유닛 카운트 한계는 전 난이도 공통 70** — 우리는 100으로 잡았다.

상세는 `Docs/reference/DIFFICULTY_RESEARCH.md`.

## 피해가 % 기반이다

조합표 능력 표기가 **「대상 × 기준」** 구조다.
```
대상   단일 · 범퍼(범위) · 보잡(보스) · 라인딜(라인 전체)
기준   현재체력 · 전체체력 · 잃은체력 · 최대체력
```
`단일(현재체력11%)`, `범퍼(잃은체력3%)`, `보잡(전체체력5%)` 같은 식이다.

**우리 `UnitAttacker`는 고정 피해만 낸다.** 239종의 개성이 이 % 체계에 들어 있는데
받을 구조가 없다. 보스 체력이 일반의 15배라 고정 피해로는 애초에 안 잡히는 구조다.

`전체체력`과 `최대체력`이 같은 것인지는 아직 미확정.
