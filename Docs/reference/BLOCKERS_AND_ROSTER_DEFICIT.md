## 두 게이지의 정체가 풀렸다 — 둘 다 「가득 찼을 때」다

로우 `H096`의 유닛 필드:

| | 값 |
|---|---|
| `uhpm` (최대 체력) | **250** |
| `umpm` (최대 마나) | **135** |
| `uhpr` (체력 재생) | 0.15/초 |

```
여는 조건  MANA == 135.00   ← umpm = 135. 마나가 가득 찼을 때
쓰는 조건  LIFE >= 250.00   ← uhpm = 250. 체력이 가득 찼을 때 (AND B03Z 보유)
```

**두 게이지가 다른 게 아니라, 둘 다 각자의 최대치다.** 체력·마나가 각각 평타마다 +1씩 쌓이고,
마나가 차면 버프를 걸고(5초), 체력이 차 있으면서 버프가 있으면 소모한다(체력 1로 리셋 + 버프 제거 + `e0RR` 소환).

→ **구현: 마나 게이지 135칸 / 체력 게이지 250칸, 버프 창 5초.**
5초 안에 체력 게이지가 250에 있어야 하므로, **체력 게이지를 미리 채워둔 상태에서 마나가 차야 발동**한다.
영구가 아니므로 무한 누적은 재현되지 않는다.

# ㉢ `B045`(카타쿠리) — 게이지가 맞다. 최대 체력이 **50**이다

```jass
if GetRandomInt(1,7)==4 then                                   ← 1/7 (14.3%)
    if GetUnitStateSwap(UNIT_STATE_LIFE,GetAttacker())>36.00 then
        CreateNUnitsAtLoc('e0FA') → IssueTargetOrderById(…,"bloodlust", 시전자)   ← B045 부여
        SetUnitLifeBJ(시전자, LIFE - 17.00)                      ← 17 소모
    else
        SetUnitLifeBJ(시전자, LIFE + 1.00)                       ← 못 쓰면 1 충전
```

`h07I` 「샬롯 카타쿠리 장성 밀가루 대신 - 제한됨」: **`uhpm = 50`** · `uhpr = 0.5/초`

| 질문 | 답 |
|---|---|
| `LIFE > 36`이 바닥 조건인가 | **그렇다.** 체력이 **36 초과**일 때만 발동한다(37 이상) |
| `LIFE −17`이 정확한가 | **정확하다.** `SetUnitLifeBJ(LIFE - 17.00)` |
| 게이지인가 진짜 체력인가 | **진짜 체력인데 최대치가 50이라 게이지로 설계된 것**이다. 초당 0.5씩 자연 재생도 있다 |

**동작 요약**: 평타마다 1/7을 굴린다 → 체력 37↑이면 발동하고 −17, 아니면 +1 충전.
최대 50에서 시작하면 50→33(발동) → 33은 36 이하라 다음부터 충전 → 37 도달까지 4회.
**연속 발동은 최대 1회**이고, 그다음은 최소 4번의 「1/7 성공」 또는 8초의 자연재생이 필요하다.
`B045` 자체 지속은 `A0R7`의 `adur = 1.25초`(공격력 `Blo1 = +4.0`).
