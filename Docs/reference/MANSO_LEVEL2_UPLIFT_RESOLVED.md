# "도움소 강화" 항법이 올리는 3종(A0ID/AOeq/A0JR) 레벨1↔레벨2 전수 — 원문 확정

조사: 리서치담당 / 2026-09-06
요청: PM — 「도움소 3종 레벨2 수치, 우리가 옮겨온 값이 레벨1인지 레벨2인지가 핵심」
전제: [[navigation-routes-full]](NAVIGATION_ROUTES_FULL.md) ④"도움소 강화"(`A17D`)가
`udg_Manso[플레이어]`의 `A0ID`(해루석)·`AOeq`(대지진)·`A0JR`(버스터콜) 능력을
전부 **레벨 2**로 만든다는 사실이 확인된 데 이어지는 조사.

## 방법

`war3map.w3a`를 바이트 단위로 직접 파싱. **뿌리 ㊲(등차구간+플래토 경고)에
따라 "몇 점 뽑기" 금지 — 각 능력의 레벨1·레벨2 필드를 전부, 그리고 해당
능력의 실제 레코드 경계(다음 `oldId` 블록이 시작되는 지점)까지 전부 덤프해서
잘림(truncation)이 없는지 확인했다. 특히 `AOeq`는 `oldId=AOeq`인 블록이
파일에 **3개**(진짜 대지진 자기 자신 + `A0SH`/`A0VC`라는 별개 커스텀 능력
2개가 대지진을 베이스로 복사됨) 있어서, 진짜 대상 블록(`newId=0`, 즉
"원본을 직접 수정"인 블록 하나)만 골라 그 블록의 끝(다음 블록 `newId=AIbm`
시작 지점, 33개 필드 전부 포함)까지 전수 확인했다.

## ① `A0ID`(해루석) — **레벨1↔레벨2 다르다. 우리는 레벨1이다.**

| 필드 | 레벨1 | 레벨2 |
|---|---|---|
| `mls1`(지속 마법피해, 초당) | **2,500,000** | **3,000,000** |
| `amcs`(마나 비용) | 700 | 600 |
| `acdn`(쿨타임) | 300초 | 300초(동일) |
| `abuf`(부가 버프) | (없음) | **`Bmlc`,`Bmlt` 2종 추가**(레벨1엔 아예 없던 효과) |

레벨1 툴팁(`aub1`) 원문: `"◎첫 타격 전체 체력의 7% 데미지+초당
2,500,000데미지 ◎5초지속 ◎쿨타임 300초"` — **2,500,000은 레벨1 필드값
그 자체이며 툴팁에서 베낀 임의값이 아니다.** (기존 `[미확인]` 우려—
"툴팁에서 그대로 옮겼을 가능성" — 는 절반만 맞다: 값 자체는 필드로 뒷받침
되지만, 그 값은 딱 **레벨1** 값이다.)

**현재 `SupportSkill_해루석.asset`: `damageBase=2500000`, `manaCost=700`
→ 정확히 레벨1과 일치.** 즉 **우리는 항법 선택과 무관하게 전원에게 레벨1을
주고 있다** — "도움소 강화"를 고른 원작 플레이어는 3,000,000 피해·600
마나·버프 2종 추가를 받는데, 우리 구현엔 그 분기 자체가 없다.
**→ 결측 확정** (레벨1을 옮겼고, 레벨2 분기가 없다).

## ② `AOeq`(대지진) — **레벨1=레벨2, 스케일링 자체가 없다.**

같은 블록(33개 필드) 전수 확인 결과, **모든 수치 필드가 레벨1·레벨2에서
바이트 단위로 동일**했다:

| 필드 | 레벨1 | 레벨2 |
|---|---|---|
| `amcs`(마나) | 320 | 320 |
| `acdn`(쿨타임) | 150 | 150 |
| `aran`(사거리) | 99999 | 99999 |
| `adur`/`ahdu`(지속시간) | 2.5 | 2.5 |
| `aare`(범위) | 625 | 625 |
| `Oeq1`(마법피해 증폭) | 0.12 | 0.12 |
| `Oeq2` | 1.0 | 1.0 |
| `Oeq3`(이속 감소율) | 0.85 | 0.85 |
| `Oeq4` | 625 | 625 |
| `aub1`(전체 툴팁 텍스트) | "100만의 고정데미지+2.5초 이동속도 85%감소…" | **완전 동일 텍스트** |

`alev`(최대레벨)=2로 선언돼 있지만 실제로는 레벨2가 레벨1과 완전히
같은 스킬이다 — "도움소 강화"가 대지진 레벨을 올려봤자 **아무 것도
바뀌지 않는다.**

**현재 `SupportSkill_대지진.asset`: `damageBase=1000000`, `manaCost=320`,
`cooldownSeconds=150` → 레벨1(=레벨2)과 정확히 일치.**
**→ 결측 아님.** 항법 선택 여부와 무관하게 원작 자체가 값이 하나뿐이다.

## ③ `A0JR`(버스터콜) — **피해는 고정, 쿨타임·마나만 레벨차 있다** (기존 조사 재확인)

[[helpshop-3-unconfirmed-resolved]](HELPSHOP_3_UNCONFIRMED_RESOLVED.md) §②에서
이미 확인된 내용을 이번 요청 맥락에서 재확인:

| 필드 | 레벨1 | 레벨2 |
|---|---|---|
| `Ncs1~6`(피해 관련) | 7,000,000 | **동일**(7,000,000) |
| `acdn`(쿨타임) | 100초 | 66초 |
| `amcs`(마나) | 500 | 333 |

**현재 `SupportSkill_버스터콜.asset`: `damageBase=7000000`,
`manaCost=500`, `cooldownSeconds=100` → 마나·쿨타임이 레벨1과 일치.**
**→ 부분 결측.** 피해량은 레벨과 무관하니 바꿀 게 없지만, "도움소 강화"를
고른 플레이어는 원작에서 쿨타임 100→66초·마나 500→333으로 더 자주 쓸 수
있는데 우리는 그 QoL 차이가 없다.

## 결론 — PM 질문 ②·③·④에 대한 답

- **② 우리가 옮겨온 값이 레벨1인지 레벨2인지**: **셋 다 레벨1**이다
  (`A0ID`/`A0JR`은 명확히 레벨1=레벨2와 다른 값 중 레벨1 쪽, `AOeq`는
  애초에 레벨1=레벨2라 구분 자체가 무의미).
- **③ 해루석 2,500,000이 레벨2 값인지**: **아니다, 레벨1 값이다.** 레벨2는
  3,000,000 + 버프 2종 추가.
- **④ 마나 비용도 레벨별로 다른가**: `A0ID`(700→600)·`A0JR`(500→333)는
  다르다. `AOeq`(320→320)는 같다.

**결측 방향 정리**: "도움소 강화" 항법을 만들려면 → 해루석(피해+버프 2종),
버스터콜(쿨타임·마나)에 분기가 필요하다. 대지진은 손댈 게 없다. 이 항법을
구현하지 않는 한(=전원 레벨1 취급) **지금 우리 수치가 "과대"인 경우는
없다** — 셋 다 레벨1이거나 레벨1=레벨2이므로, 항법 미구현 상태의 기본값은
원작 "항법 미선택" 플레이어와 정확히 같다.
