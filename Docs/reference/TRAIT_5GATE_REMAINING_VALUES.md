# 특성 5명 게이트스킬 — 나머지 값 확정 (루치·로우·나미) + 우솝×항법 겹침 확인

조사: 리서치담당 / 2026-09-07, `Tools/w3x` 표준 도구로 진행
요청: PM — 루치 기본판(`carrionswarm`) 수치, 로우 true/false 값, 나미
Skill_1/Skill_4 값 + `Item_nami` 게이트와의 겹침, 우솝×"도움소 강화" 겹침.

## ① 루치 기본판(`Kick`) — `carrionswarm` 더미의 실제 능력은 `A0R6`

더미 `e0F4`("루치 더미 31")의 `uabi=A0R6,Aloc,Avul` — 주문 오더스트링
`"carrionswarm"`은 껍데기고 **실제 능력은 `A0R6`**("장풍 루치초월
람각개조", base `ACca`)이다:
```
aran=1700 aare=225 acdn=0(쿨없음) amcs=0
Ucs1=600,000  Ucs2=700,000,000  Ucs3=1100  Ucs4=450
```
⚠️ `aub1`/`atp1`(툴팁)이 이 오브젝트엔 없다 — `Tools/w3x/README.md`의
"필드 없으면 기본값" 경고대로 **베이스(`ACca`) 텍스트를 물려받는 것으로
보이나 한국어 커스텀 텍스트는 확인 못했다.** `Ucs1=600,000`이 데미지로
보이나(다른 캐릭터들의 Ucs1 필드가 전부 데미지였던 패턴과 일치),
`Ucs2=700,000,000`은 이례적으로 커서 정체 불명 — 데미지가 아니라 다른
용도(예: 최대사거리 제곱값 등 내부 계산용)일 가능성이 있다, 단정 안 함.

### 기본판 vs 강화판(`Kick2`) 나란히

| | 기본(`Kick`) | 강화(`Kick2`) |
|---|---|---|
| 데미지 방식 | 더미(`e0F4`)의 `A0R6` 능력 위임, `Ucs1=600,000`(추정) | **명시적 `RRD`** — `대상최대체력×0.04`(대상 포인트값<200일 때만, 즉 **보스 제외**), `ATTACK_TYPE_CHAOS`(방어 무시) |
| 범위 | `A0R6`의 `aare=225`(단일 대상 위주로 보임) | `ForGroupBJ` AoE 495범위 + 조건부 2차 AoE 585범위(콤보 이어치기) |
| 구조 | 단발 | 2단 콤보(조건 충족시 "육왕건" 추가타) |

**결론: 배수 스케일링이 아니라 완전히 다른 데미지 산출방식(고정값→%최대체력 방어무시)으로
바뀐다.** 어제 낸 구조적 결론 그대로, 이번에 기본판 수치까지 채웠다.

## ② 로우(`Law_Bool`) — RRD는 동일, **증원 AoE 히트가 하나 더 붙는다**

`Trig_Law_Skill_2_Actions`(false) vs `_reinforce_Actions`(true) 원문 대조:

**공통(둘 다 동일)**: `if UnitHasBuffBJ(대상,'B06B')==true then RRD(...,대상현재체력×0.2,...,ATTACK_TYPE_CHAOS,...)` — 이 부분은 **양쪽 다 완전히 똑같다.**

**차이는 소환하는 더미 구성**:
- 기본: `e09Q`(능력 `A0OG`, base `AHtc`, **Htc1=350,000**, 485범위 thunderclap형 AoE) + `e09D`(능력 `A12S`, "purge" 계열, 직접데미지 없음·디버프제거/무장해제용)
- 강화: `e0NQ`(**같은 `A0OG`, 350,000, 동일**) + `e03T`(능력 `A140`, base 같은 `AHtc`, **Htc1=437,500**, 485범위) + 장식용 더미 2개 추가(`e0GQ`/`e0NO`, 유의미한 능력 없음)

**즉 기본판 AoE 데미지 350,000(1회) → 강화판 350,000+437,500=787,500(2회 합산)
로 약 2.25배가 된다.** B06B버프 대상 전용 20%현재체력 데미지는 안 바뀐다 —
**바뀌는 건 AoE 뇌격(thunderclap) 파트뿐이다.**

## ③ 나미(`NamiT_Bool`) — Skill_1·Skill_4 둘 다 **순수 추가타**, `Item_nami`와 안 겹친다

**Skill_4**: `NamiT_Bool==true`일 때만 추가로 `e09I` 더미 소환 + 500범위
그룹데미지(`Func018A`: `RRD(...,350,000,...,ATTACK_TYPE_NORMAL,...)`) —
**기존 블리자드 효과는 그대로 두고 350,000 고정 AoE가 통째로 더 붙는다
(순수 추가, 대체 아님).**

**Skill_1**: 마찬가지로 `NamiT_Bool==true`일 때만 추가로 `e0NI` 더미 +
400범위 그룹데미지(`Func035A`: `RRD(...,450,000+realD×1.5,...,ATTACK_TYPE_NORMAL,...)`) —
**역시 순수 추가.**

### 🔴 `Item_nami`(아이템게이트)와의 겹침 — **안 겹친다, 완전히 분리된 스킬**

`udg_Item_nami` 리터럴 전수(5회: 선언·초기화·`Trig_Eternal_Nami`전제조건·
`Trig_item_up_Actions`저장·**`Trig_Nami_Skill_2_Actions`뿐**) — `Item_nami`는
**Skill_2 딱 하나만 건드린다.** `udg_NamiT_Bool` 전수(5회: 선언·초기화·
구매SET·**Skill_1·Skill_4** 둘) — **Skill_2엔 안 나온다.**

```
Item_nami(아이템 I00U 게이트) → Skill_2만(33%/67%[800k/400k] 배타쌍)
NamiT_Bool(특성강화 게이트)   → Skill_1·Skill_4만(둘 다 순수 추가타)
```

**둘이 겹치는 스킬이 하나도 없다** — PM이 걱정한 "Skill_2/Skill_4를
둘 다 건드린다"는 확인 결과 **Skill_4는 `NamiT_Bool`만 건드리고
`Item_nami`는 안 건드린다.** 서로 다른 스킬을 하나씩 맡고 있어
중복·충돌 걱정은 없다.

## ④ 우솝 특성 × 항법 "도움소 강화" — **다른 능력이라 안 겹친다**

우솝(`H09B`) 특성강화: `IncUnitAbilityLevelSwapped('A0IE', udg_Manso[전체4명])`.
`A0IE`를 직접 확인(`Tools/w3x/w3a.py`):
```
anam = "9도움소 독약1"
레벨1: 초기폭발 200,000 + 2차데미지 200,000, 방어력-20, 지속5초
레벨2: 초기폭발 300,000 + 2차데미지 300,000, 방어력-25, 지속7.5초
```
**"도움소 강화" 항법이 레벨2로 세팅하는 건 `A0ID`(해루석)·`AOeq`(대지진)·
`A0JR`(버스터콜) 셋뿐, `A0IE`(독약)는 그 목록에 없다.** 완전히 다른
능력이다 — **겹치는 게 아니라 우솝 특성이 원작 "도움소" 4번째 스킬
(독약)의 존재를 이번에 새로 밝힌 것**이다(`A0ID`/`AOeq`/`A0JR`/`A0IE`
4종 세트로 정정).

**결론: 우솝 특성과 항법은 서로 다른 도움소 스킬을 하나씩 올린다 —
겹쳐서 두 번 오르는 일은 없다.** 단, **우솝 특성은 전체 4명의 Manso에
적용되고, 항법은 그 항법을 고른 플레이어 자신의 Manso에만 적용된다**는
점은 이미 확인된 그대로다(범위가 다르다는 것 자체는 별도로 기억해둘 만함).
