# 원작 vs 우리 게임 — 종합 대조표 (2026-09-03)

> ⚠️ **이 문서는 2026-09-03 기준이다.** 그 뒤 원작 이식이 크게 진행돼 **"우리" 열 상당수가
> 낡았다.** 아래 표에서 **09-05 정정**이라고 표시된 자리는 2026-09-05에 확인된 현재값으로
> 인라인 정정을 붙였다(구현담당3, 값 일치 감사). 표시가 없는 나머지 항목은 09-03 이후 다시
> 확인한 적이 없다는 뜻이니 **"지금도 이렇다"로 믿지 말 것** — 특히 밸런스를 잡을 때는
> 이 문서 대신 에셋·코드를 직접 열어 확인한다.

> **이 문서는 새로 조사한 게 아니라 기존 조사 결과를 종합한 것이다.** 각 항목의 상세 근거·출처는 "상세 문서" 칸이 가리키는 원 문서를 봐라. 목적은 「다르다」와 「틀렸다」를 구분하는 것이다 — 오늘 하루에도 "의도적 축소"(총 라운드)와 "프로젝트 오류인 줄 알았는데 원작에도 있던 구분"(랜덤유닛/랜덤위습)이 섞여 나왔다. 다음 사람이 의도적 선택을 버그로 오해하고 되돌리지 않도록, 항목마다 "의도적인가" 판정을 명시한다.
>
> 표기: **의도적(사용자 확정)** = 사용자/PM이 명시적으로 결정한 것 / **의도적으로 보임(추정)** = 결정 문장은 없지만 정황상 의도적일 가능성이 높음 / **모름 — 확인 필요** = 왜 다른지 아직 아무도 확인 안 함 / **설계 제안(원작 근거 없음)** = 원작에 애초에 없어서 리서치담당이 자체 설계로 제안한 것.
> 확신도는 **원작 값 자체의 신뢰도**다(우리 값의 정확성이 아니다) — 여러 출처 교차확인=높음, 검색엔진 요약만=중간, 벽에 부딪힘/정성적 서술뿐=낮음.
