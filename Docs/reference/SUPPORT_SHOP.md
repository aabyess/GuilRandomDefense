# 도움소 (2026-08-30 사용자 설명)

## 무엇인가

**각 플레이어의 레인 안에 있는 상점형 건물.** 클릭하면 광역 스킬을 쓸 수 있고,
스킬은 **마나**를 소모한다.

| 항목 | 내용 |
|---|---|
| 위치 | 플레이어별 레인 안 (4개, 플레이어당 1개) |
| 조작 | 건물을 클릭 → 스킬 목록 |
| 비용 | 마나 |
| 효과 | 자기 필드에 버프를 주거나 적에게 광역 피해 |

## 알려진 스킬 이름

불비 · 버스터콜 · 지진 · 해일 (그 외 추가 예정)

> 각 스킬의 피해량·범위·쿨다운·마나 비용은 **미정**. 사용자 확정 필요.

## 마나 수급

**자원 칸(뽑기 섬)의 남쪽 포탈**에서 위습을 넣어 회복한다.
원작 공식: `20 + (현재 라운드 × 1.5)`

## 현재 구현 상태

| 요소 | 상태 |
|---|---|
| `ResourceType.Mana` | ✅ 추가됨 (enum 맨 뒤 — 앞에 끼우면 저장된 값이 밀린다) |
| 마나 지급 포탈 | ✅ 자원 칸 남쪽, `20 + 라운드×2` |
| 도움소 건물 | ❌ 없음 |
| 스킬 시스템 | ❌ 없음 (`SkillData` 에셋도 0개) |
| 광역 피해 | ❌ 없음 — 지금 공격은 `UnitAttacker`의 단일 대상뿐 |

## 만들 때 필요한 것

1. **레인마다 건물 배치** — `LaneMarker`가 이미 레인 위치를 알고 있으므로 그걸 쓴다.
2. **클릭 → UI** — 하단 HUD의 명령 카드 12칸이 이 용도로 비어 있다.
3. **광역 피해** — 범위 안의 `EnemyDummy`를 모두 때리는 코드가 필요하다.
   지금은 단일 대상 공격만 있다.
4. **스킬 데이터** — `SkillData`에 마나 비용·범위·피해·쿨다운 필드가 있어야 한다.

## 미확정

- 스킬이 플레이어별인가, 팀 공유인가
- 도움소가 파괴될 수 있는가

### 사용자가 알려준 스킬명과 실제로 찾은 스킬명이 다르다

사용자 설명의 "불비·버스터콜·지진·해일" 중 **버스터콜과 지진(어쓰퀘이크)만 원문에서 확인**했다.
"불비"·"해일"이라는 정확한 이름은 나무위키·디시·검색 어디에서도 찾지 못했다. 가장 가까운 후보는
"폭우"(비 관련 광역기)와 "해적선충돌"(바다 관련 광역기)이지만, 이름 자체가 다르므로 동일 스킬이라고 단정할 수 없다.
→ 원작 버전(시즌1/시즌2/원랜디R 등)에 따라 스킬명이 개편됐을 가능성이 있다. **사용자 확인 필요.**

### 마나 상한

두 가지 다른 개념이 섞여서 언급된다 — 혼동 주의:
1. **도움소 자체의 마나 총량 상한**: "항법: 도움소 잠그기"라는 페널티형 항법을 선택하면 "도움소 최대 마나 100으로 감소"된다는 문장이 나무위키에 원문으로 있다 [원작] (https://namu.wiki/w/원피스%20랜덤%20디펜스). "감소"라는 표현으로 볼 때 **기본 상한은 100보다 크다** — 정확한 기본값은 [미기재].
2. **위습 1회로 채울 수 있는 마나량 상한**: 검색 결과 "원랜디R에서 위습 1개로 회복 가능한 마나의 양이 최대 100으로 고정(버프)"이라는 서술이 있다 [추정] — ordsearch.net 원문 미확인, 검색엔진 요약만 확보.

### 마나 회복 수단

자원 포탈(`20 + 라운드×1.5`, 기존 조사) 외에 도움소 안에 있는 것으로 추정되는 **흡수**·**마나포션** 스킬 자체가 마나를 회복시켜 준다는 서술을 찾았다 [추정, 원문 미확인]. 마나가 자원 포탈로만 채워지는 게 아니라 도움소 스킬로도 순환된다는 뜻인데, 이게 "도움소 스킬을 쓰려고 마나를 쓰는데 동시에 마나를 버는" 구조인지는 [미기재] — 앞뒤가 안 맞아 보이는 부분이라 원문 확인 전엔 신뢰하지 않는 게 낫다.

### 도움소 파괴 여부

여러 검색어로 시도했으나 **[미기재]**. "도움소가 공격받는다"거나 "파괴된다"는 서술은 어디서도 나오지 않았다. 오히려 도움소는 항법(패시브 버프 선택지)과 스킬 소모 UI에 가까운 서술만 나와서, **건물이 아니라 UI/메뉴에 가까운 시스템일 가능성**도 있다. 확실치 않으므로 판단은 사용자에게 넘긴다.

### 스킬이 개인용인가 팀 공유인가

**[미기재]**. 도움소가 "레인 안에 하나씩" 있다는 건 우리 쪽 기존 설명(SUPPORT_SHOP.md 상단)이고, 원작에서 이게 플레이어 개인 소유인지 4인 파티 공유 자원(마나 포함)인지 명시한 문장은 찾지 못했다. "마리당 100씩 차기 때문에 60라부터 다 모아두는게 아니면 마나가 부족하다"는 QnA성 문장을 하나 찾았으나(디시 갤러리) [추정, 신뢰도 낮음] 개인/팀 여부와는 무관한 내용이었다.

### 확인 못한 항목 정리 (`[미기재]`)

- 각 스킬의 정확한 범위·쿨다운 (전부)
- "불비"·"해일"이라는 정확한 스킬명 자체 (원작에 없거나 버전별 개칭 가능성)
- 지진(어쓰퀘이크)·해루석의 기본(비버프) 마나 비용·피해량
- 도움소 자체 마나 총량의 기본 상한값 (100은 "감소된" 값)
- 도움소가 파괴 가능한 건물인지, UI에 가까운 시스템인지
- 스킬/마나가 플레이어 개인 소유인지 4인 팀 공유인지
