# 도움소 마나 예산 · 붕괴 라운드 재측정 — 2026-09-06

측정: 구현담당2 / `Tools/simulate_balance.py` §3(도움소). 전제: 오늘 마나 재생
(`ResourceWallet.ManaRegenPerSecond = 0.30f`, 원작 `umpr`)이 처음 구현됐다(구현담당3) —
그 전엔 마나가 차는 경로가 코드에 없어 도움소 10종(당시)이 전부 발동 불가였다.

**핵심: 표기 쿨다운은 사실상 의미가 없다. 진짜 제약은 마나 재생이다.**

## ① 마나 예산 — 시간 재생만(하한)

```
75라운드 총 길이 = 3,162.6초
예산 = 3,162.6 × 0.30 + 시작마나 15 ≈ 963.8
마나 상한 = 1,000 (예산이 상한 밑이라 저축해도 안 넘친다)
```

⚠️ **마나 채널이 둘이다.** ⓐ 위 시간 재생 ⓑ **자원교환 포탈**(`20 + 라운드×1.5`, 랜덤유닛
등급 위습 소비, 2026-09-04 원작 확정값). **위 963.8은 ⓐ만 센 하한이다** — ⓑ는 위습을
유닛뽑기에 안 쓰고 마나로 바꾸는 선택이 들어가는 자원교환이라 모델에 안 넣었다(위습
획득량·배분까지 모델링해야 해서 창작 영역, PM 지시).

## ③ 붕괴 라운드 재측정 — 피해형 7종, 각각 단독 사용(고정10기 모델)

배분을 지어내지 않기 위해 **능력 하나만 쓴다고 가정하고 7종을 각각 독립으로** 쟀다
(같은 마나를 여러 능력이 나눠 쓰는 조합은 창작이라 안 냄). 스턴·소환·즉사형
4종(지진·흡수·능력치증가·선택위습제조)은 "백로그를 얼마나 줄이는가"를 새로 정의해야
해서 이번엔 안 냈다. 출항이다(공격력 버프)는 별도로 뒀다 — ③-보강② 참고.

### ⚠️ 2026-09-06 정정(PM 지적) — "한 방 킬" 게이트가 부분 기여를 0으로 세고 있었다

최초 모델은 `e.hp <= damageBase`(그 라운드 대표 몹을 한 방에 죽일 수 있어야 발동)
게이트를 썼다. **대지진(100만)이 156만짜리 몹의 64%를 깎아도 한 방에 못 죽이면
기여를 통째로 0으로 셌다** — "그 능력이 안 쓰인다"가 아니라 "모델이 부분 기여를 못
센다"는 결함이었다(PM 지적). ⚠️ **확인 결과 이 게이트는 도움소 이 절 전용이다**
(`grep`으로 전체 재확인 — `skill_dps_for_unit`/`DealSkillDamage` 등 일반 스킬 피해
경로엔 이런 게이트가 없고, 런타임 `SupportShop.cs`도 `enemy.TakeDamage(damage,...)`를
그냥 부른다, 한 방 킬 조건이 없다). **범위 스킬 전체가 과소 계상되는 문제는 아니다.**

**세 가지를 나란히 낸다** — 몇 마리가 실제로 맞는지 원작 라운드당 35마리 분포를
모르니(지어내지 않는다) "전부 맞는다"(상한)와 "한 마리만 맞는다"(하한) 두 끝을 준다.

```

  AD: 기본 R54 -> 한방킬(기존)=R54(2회) / 부분기여-전부맞음(상한)=R54(9회) / 부분기여-한마리만(하한)=R54(9회)
  AP: 기본 R55 -> 한방킬(기존)=R55(1회) / 부분기여-전부맞음(상한)=R55(9회) / 부분기여-한마리만(하한)=R55(9회)

  AP: 기본 R55 -> 한방킬(기존)=R55(0회) / 부분기여-전부맞음(상한)=R56(3회) / 부분기여-한마리만(하한)=R55(3회)

  AP: 기본 R55 -> 한방킬(기존)=R55(0회) / 부분기여-전부맞음(상한)=R55(1회) / 부분기여-한마리만(하한)=R55(1회)
```

**대지진이 게이트를 걷어내자 캐스트 0회 → 3회로 바뀌었다** — PM 지적이 실측으로
확인됐다(정확히 예측한 그 방향). "전부 맞음" 상한에서는 붕괴도 1라운드 뒤로 민다
(R54→R55/R55→R56). 독약은 부분 기여를 줘도 여전히 붕괴를 못 미룬다(캐스트 1회뿐 —
비용 620이 너무 커 예산이 그 시점까지 못 쌓인다). **버스터콜·해루석은 세 모드 다
비슷하게 붕괴를 1라운드씩 민다** — 이 둘은 애초에 한 방 킬 조건을 넉넉히 만족해서
게이트 정정의 영향이 작다.

**전체적으로 도움소 단독 투입(배분 없이 한 종만)은 이 특정 붕괴 지점(다른세계
구간)을 크게 못 바꾼다** — 예산이 워낙 작고(전 게임 1~9회), 붕괴가 시작되는 구간의
적 체력(156만~284만)도 여전히 크다. 원작 밸런스가 나쁘다는 뜻이 아니라, 이 붕괴
지점은 도움소보다 연구소 결손(`RESEARCH_AXIS_REMEASURE_2026-09-06.md` ②) 문제라는
어제 발견과 결이 같다.

## ③-보강② 출항이다(공격력 버프, 피해 0)

전군 공격력을 **map-wide로 10초간 ×1.5** 올린다(`buffAttackPowerMultiplier=1.5`,
`duration=10`, `mapWide=1`) — 범위 안 몇 마리가 맞는지 추측할 필요가 없는 축이다
(map-wide라 전군에 적용, 몹 쪽 마릿수와 무관). 라운드 길이(37~40초)가 지속시간(10초)
보다 훨씬 길어 버프가 라운드 안에 다 들어간다고 보고, 그 10초 동안 dps가
+50%(=×0.5)만큼 더 나온 것으로 그 라운드 킬 능력치에 더했다.

```
[출항이다] mana=150 cd=135s buff=×1.5 10초
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 6회, 예산상 최대)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 6회, 예산상 최대)
```

**예산이 허락하는 최대(6회)를 다 써도 이 특정 붕괴 지점을 못 옮긴다** — 10초짜리
+50% 버프의 순간 기여가 버스터콜류의 즉발 대미지보다 작기 때문이다("총량이 클 수도
있다"는 가설은 이 측정 지점에서는 확인되지 않았다 — 다른 붕괴 지점에서는 다를 수
있다).
