# 도움소 마나 예산 · 붕괴 라운드 재측정 — 2026-09-06

측정: 구현담당2 / `Tools/simulate_balance.py` §3(도움소). 전제: 오늘 마나 재생
(`ResourceWallet.ManaRegenPerSecond = 0.30f`, 원작 `umpr`)이 처음 구현됐다(구현담당3) —
그 전엔 마나가 차는 경로가 코드에 없어 도움소 10종(당시)이 전부 발동 불가였다.

**핵심: 표기 쿨다운은 사실상 의미가 없다. 진짜 제약은 마나 재생이다.**

---

## ① 마나 예산 — 시간 재생만(하한)

```
75라운드 총 길이 = 3,162.6초
예산 = 3,162.6 × 0.30 + 시작마나 15 ≈ 963.8
마나 상한 = 1,000 (예산이 상한 밑이라 저축해도 안 넘친다)
```

⚠️ **마나 채널이 둘이다.** ⓐ 위 시간 재생 ⓑ **자원교환 포탈**(`20 + 라운드×1.5`, 랜덤유닛
등급 위습 소비, 2026-09-04 원작 확정값). **위 963.8은 ⓐ만 센 하한이다** — ⓑ는 위습을
유닛뽑기에 안 쓰고 마나로 바꾸는 선택이 들어가는 자원교환이라 모델에 안 넣었다(위습
획득량·배분까지 모델링해야 해서 창작 영역, PM 지시).

## ③ 붕괴 라운드 재측정 — 피해형 7종, 각각 단독 사용(고정10기 모델)

배분을 지어내지 않기 위해 **능력 하나만 쓴다고 가정하고 7종을 각각 독립으로** 쟀다
(같은 마나를 여러 능력이 나눠 쓰는 조합은 창작이라 안 냄). 스턴·버프·소환·즉사형
5종(지진·출항이다·흡수·능력치증가·선택위습제조)은 "배틀로그를 얼마나 줄이는가"를
새로 정의해야 해서 이번엔 안 냈다.

```
[낙뢰]    mana=100 dmg=22,500     cd=17s
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 2회)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 1회)

[대지진]  mana=320 dmg=1,000,000  cd=150s
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 0회)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 0회)

[독약]    mana=620 dmg=200,000    cd=170s
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 0회)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 0회)

[버스터콜] mana=500 dmg=7,000,000 cd=100s
  AD(고정10기): 기본 R54 -> 도움소 R55 (캐스트 1회)
  AP(고정10기): 기본 R55 -> 도움소 R56 (캐스트 1회)

[불비]    mana=210 dmg=50,000     cd=60s
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 1회)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 0회)

[폭우]    mana=25  dmg=1,600      cd=5s
  AD(고정10기): 기본 R54 -> 도움소 R54 (캐스트 5회)
  AP(고정10기): 기본 R55 -> 도움소 R55 (캐스트 4회)

[해루석]  mana=700 dmg=2,500,000  cd=300s
  AD(고정10기): 기본 R54 -> 도움소 R55 (캐스트 1회)
  AP(고정10기): 기본 R55 -> 도움소 R56 (캐스트 1회)
```

**버스터콜·해루석만 붕괴 라운드를 1라운드 뒤로 미룬다.** 대지진·독약은 캐스트가 0회다
— 붕괴가 실제로 시작되는 구간(R51~R57, 다른세계 등급, 엔피 HP 약 156만~284만)에서
이 두 능력의 데미지(각 100만·20만)로는 이 트리거 조건(`e["hp"] <= damageBase`, 즉
한 방에 그 라운드 대표 몹을 죽일 수 있어야 발동)을 못 만족해서다 — 다른세계 등급의
엔피 HP가 이미 커서, 이 둘은 "한 마리를 즉시 지운다"는 이 모델의 발동 조건 자체를
거의 못 채운다(원작 밸런스가 나쁘다는 뜻이 아니라, 이 붕괴 지점이 도움소 화력보다
연구소 결손(§`RESEARCH_AXIS_REMEASURE_2026-09-06.md` ②) 문제라는 걸 다시 보여준다).

**전체적으로 도움소 단독 투입은 이 특정 붕괴 지점(다른세계 구간)을 크게 못 바꾼다** —
예산이 워낙 작고(전 게임 1~4회), 붕괴가 시작되는 구간의 적 체력도 이미 도움소
한 방으로 못 지울 만큼 크다.
