## 방법/검증
war3map.j 전체에서 4개 ID 리터럴 검색 - 각각 정확히 1회만 등장(Trig_T_Ability_hero_Actions의 
IncUnitAbilityLevelSwapped 구매줄 자체뿐). 다른 트리거 참조 0건 - 완전 네이티브 능력,
JASS 트리거 구현 없음. w3a 툴팁/필드가 곧 실제 효과 전부로 확정.
base 능력 = ACbh(4종 전부, A0LZ와 같은 stock 계열).
IncUnitAbilityLevelSwapped는 기존레벨+1이므로 레벨1(기본)->레벨2(구매후) 전환.
레벨3+는 이 4명과 무관한 다른 캐릭터가 같은 ACbh 슬롯 상위레벨을 재사용하는 것(교차오염 없음).
