## ② 🔴 내 발동률 모형이 **`cooldown`을 빠뜨렸다** (뿌리 ⑲ 자기 적용 4)

`UnitAttacker.cs:444`:
```csharp
if (level.cooldown > 0f && Time.time < state.onHitChanceLockedUntil) continue;
```
**`OnHitChance`에도 `cooldown`이 절대쿨로 걸린다.** 내 모형은 `triggerChance × attackSpeed`만 썼다.

올바른 식: **`rate = min(triggerChance × 초당타수, 1 / cooldown)`**

### 게다가 쿨다운 스캔도 처음엔 틀렸다

처음 세었을 때 **`cooldown > 0`이 1개**로 나왔는데 **실제로는 4개**다.

`^  - cooldown:`(줄 시작 앵커)로 바꾸니 4개가 나왔다.
