## 핵심 구조 요약

1. **4인 협동, 플레이어마다 자기 레인 1개(총 4개, 2×2 배치)**. 적(P6)은 레인 네 모서리를 **무한 순환**한다 — 끝점이 없고 쌓이면 진다.
2. 라운드 = **40.65초**, 레인마다 **0.65초 간격 35마리**. 보스 라운드(10·20…60)는 라인몹 없이 레인마다 보스 1기, 75.4초 제한, 못 잡으면 **그 플레이어만** 탈락(쉬움 제외).
3. 패배 = 레인 생존 적 ≥ 70(41R 이후 지옥60/신55/악몽50)인 **0.65초 틱마다** 데스카운트 9→0. 신세계(61R~)는 1.
4. 종료 = 쉬움 50R · 보통 60R · 어려움 이상 75R(신세계 61~75R, 라운드 35초, 65/70/75R 신세계 보스). **Victory 호출은 없다** — 클리어 = 세이브코드(클리어 횟수) 발급.
5. 유닛은 **영웅이 아닌 일반 유닛**(base hrif). 위습(유닛)을 **발판 사각형으로 걸어가 밟아** 뽑는다. 흔함 9종만 종류별 고정 슬롯, 나머지는 레인 상자 중심에 생겨 자유 배치.
6. 조합 = **유닛 위의 "[조합]" 능력 버튼**(Fusion3, 144식, 재료는 보유 전체에서 셈) + **채팅 조합**(히든 23·이터널 27·불멸 11·영원 9 = 70).
7. 매 라운드 보상 = 랜덤위습 2개. 적 처치 = 1/4 확률 골드.
8. UI = 멀티보드 1개(레인별 유닛 카운트/풀카운트) + 타이머창. 리더보드·퀘스트 로그 없음.
