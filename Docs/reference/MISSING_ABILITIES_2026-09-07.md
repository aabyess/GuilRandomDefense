### 🔴 `w3a` 직접 조회 결과 — 대부분 "필드값 0", 목록을 다시 갈라야 한다

`Tools/w3x/w3a.py`로 `war3map_new.w3a`를 열어 위 능력들의 실제 필드를
전부 확인했다. **두 가지 큰 오류를 잡았다:**

1. **각 캐릭터의 "두 번째·세 번째" ID 상당수는 능력이 아니라 `[조합]`
   레시피 버튼**(base `Aroa`/`AHwe`, `anam="[조합]"`)이었다 — 캐릭터
   전용 스킬이 아니라 게임 공용 조합 UI다. `A02R`·`A02T`·`A01J`·`A00X`·
   `A00U`·`A0NF`·`A013`·`A0IO`·`A02J`·`A02N`·`A02L`·`A02W`·`A00R`·`A01F`
   **전부 이 부류다 — "빠진 능력"이 아니라 "빠진 조합 레시피"에 가깝고,
   이번 밀도(전투 능력) 집계 대상이 아니다.** 목록에서 뺀다.
2. **남은 진짜 캐릭터 능력(`ACbh` 계열) 대부분이 `Hbh1`=`Hbh3`=0.0이다**
   — 툴팁(`aub1`)엔 "800의 데미지"·"1500의 마법데미지" 같은 숫자가
   있지만 **실제 필드는 0**이다. 이건 이 세션이 이미 여러 번 잡은
   패턴(뿌리 ㉒, "제작자 툴팁의 숫자를 옮기지 말 것 — 실제 필드와
   다르다")과 **정확히 같다.** 안흔함에서 확정된 6명(`A06P` 등)은
   `Hbh1`/`Hbh3`가 **툴팁과 정확히 일치하는 0이 아닌 값**이었는데,
   여기 특별함 후보들은 **필드 자체가 0이라 안흔함과 같은 방식으로
   "발동 확정"이라고 못 부른다.**
