조합표 색 점검 — 초월·불멸·영원·제한·다른세계

조합표 이미지(01·03·04)를 확대해 재료 이름 + 글자 색으로 등급을 읽고, 지금 게임에 들어간 재료와 맞춰 봤습니다. 이름은 거의 맞는데 등급이 색과 다른 칸이 많습니다. 식 60개 · 재료 칸 279개 중 39칸 불일치.

칸마다 「이름 · 이미지 색 → 색대로라면 들어가야 할 유닛」이고, 붉은 칸은 「지금:」에 실제 들어간 유닛이 있습니다. 이미지 색을 잘못 읽은 칸이 있으면 알려 주세요(육안 판독이라 보라/핑크, 초록/검정이 헷갈릴 수 있음). 히든 22종은 히든 점검표에 따로 있습니다.

빨강 = 전설적인보라 = 희귀함금 = 특별함초록 = 안흔함(없으면 흔함)검정 = 흔함하늘 = 히든(상붕카=안흔함_상붕카·이승우=희귀함_이승우 관례)핑크 = 변화됨남색 = 초월위습/초월갈색 = 제한랜덤 = 랜덤유닛
수정은 준비만 해 뒀고, 확인 뒤 넣습니다.
