조합표 검색 — 스킨 초상 넣은 시안

친구 피드백: 「원랜디는 스킨이 곧 캐릭터라 조합표에서 눈으로 찾는데, 구랜디는 친구 이름이라 하나씩 다 읽어야 한다」. 그래서 결과마다 스킨 초상을 붙이고, 보이는 캐릭터 이름(쵸파·마히토·빅맘)으로도 찾게 했습니다.

초상은 게임 안 실제 모델을 대기 자세로 찍은 것입니다. 캐릭터 이름은 스킨 원본에서 뽑은 표(242종 중 221종 확인)를 씁니다. 예시 검색어는 「강재규」입니다. 밝은 초상은 이미 가진 재료, 회색 초상은 없는 재료입니다.

A오른쪽 서랍 + 초상

오른쪽 끝 탭이나 F5로 엽니다. 싸우면서도 켜 둘 수 있는 크기입니다. 결과를 누르면 카메라가 조합판의 그 식으로 이동합니다.
