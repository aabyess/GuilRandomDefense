굳은 규칙:

- 🔴 **작업 폴더**: 메인 폴더는 구현담당1이 밤새 `map/s2` 브랜치로 쓰고 있다. 너는 **worktree**를 만들어 거기서만 일한다: `git worktree add ../GuilRandomDefense-ui -b ui/castle main`. 메인 폴더의 파일은 건드리지 않는다. 커밋은 `git add -- 경로` 뒤 `git commit -- 경로`(경로 없는 commit 금지). **push·main 병합은 PM만** — 사장님이 전/후 그림을 보고 승인한 뒤.
- 🔴 **유니티 에디터는 main 하나뿐이고 오늘 오전은 구현담당1이 전담한다.** 너는 오전엔 코드·그림만 만들고, 에디터로 봐야 할 때는 구현담당1에게 「시작 화면 확인 10분 쓰고 싶다」고 물어 허락받은 시간에만 쓴다(refresh·플레이·Assets 쓰기 전 「씁니다」, 끝나면 「끝났습니다」. 남의 판 중 소스 편집·refresh 금지). 두 번째 에디터를 띄우지 마라(이중 실행 에러가 사장님 화면에 뜬다). 워크트리 폴더로 에디터를 열어도 안 된다 — 에디터는 메인 폴더 하나다. 화면 캡처는 게임 안 캡처(gameshot·브리지)로만, macOS screencapture 금지.
