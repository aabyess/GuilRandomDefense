## 3. 오늘 굳은 규칙
- **새 파일은 `git commit -- 경로`에 안 담긴다.** 폴더 단위로 `git add` → `git status --untracked-files=all`에 `??` 0 확인.
  `git add a b c`는 없는 경로 하나에 통째로 실패한다(오늘 두 번 빠졌다).
- **7z는 RAR5를 못 풀고 0바이트를 에러 없이 만든다.** opfp/opbw rar는 unar·bsdtar로.
- **zip 바깥 textures/는 위아래가 뒤집힌 경우가 잦다**(R21·R51·R59). 모델 안/rar 안 그림이 정본.
- **이름이 비슷하면 확인하고 붙인다**(이지누→이진수, 박창영→박찬형, 이태훈 R50/R59). 이름 없이 온 파일은 묻는다.
- 원작 수치 옮길 때 **w3q 필드 뜻**(gglb/gglm 골드, glmb/glmm 목재)과 **그 줄이 어느 if 분기 안인지**까지 본다.
- 판 수치는 **난이도를 함께 적는다**(쉬움/보통).
