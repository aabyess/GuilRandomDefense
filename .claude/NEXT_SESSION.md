## 4. 굳은 규칙 (누적)
- **새 파일은 `git commit -- 경로`에 안 담긴다.** 폴더 단위 `git add` → `git status --untracked-files=all`에 `??` 0.
  `git add a b c`는 없는 경로 하나에 통째로 실패한다.
- **파이썬으로 C# 문자열을 넣을 때 `\n`은 실제 줄바꿈이 된다**(CS1039, 09-26 PM이 당함 — 구현담당1이 잡음). raw 문자열이나 `\\n`.
- 7z는 RAR5를 0바이트로 푼다 → unar·bsdtar. zip 바깥 textures/는 위아래 뒤집힘이 잦다.
- 이름이 비슷하면 확인하고 붙인다(이지누→이진수, 박창영→박찬형).
- 원작 수치는 w3u 필드 뜻과 j의 if 분기까지. 빈 필드는 **기반 유닛 기본값**(UnitBalance.slk)이다 — 0이 아니다.
- 판 수치는 난이도를 함께 적는다(gameshot `mode:`, 기본 보통).
